# ArticleWriter 使用说明

> 本文档由 ArticleWriter 插件在设置工作目录后自动生成，可自由编辑；「生成使用说明」命令仅在文件缺失或为空时写入最新内置版本，不会覆盖你已修改的内容。

## 一、快速上手

1. **设置工作目录**：首次使用任何 ArticleWriter 命令会弹出文件夹选择器，从 vault 已有文件夹中选定一个作为工作目录（work_dir）。每本小说都是 work_dir 下的一个子文件夹；之后可随时用「选择工作目录」命令或设置页改换（切换后清空上次选书记忆）。确认后若该目录下还没有《使用说明.md》会自动创建并打开（插件每次启动也会自检补建）。
2. **创建新小说**：输入标题 / 题材 / 编写类型，自动建 <书名>/ 目录与全套模板文档（故事状态.md、大纲.md、世界观.md、卷.md、伏笔.md、笔记.md 等）；已存在的文档跳过不覆盖。
3. **配置 LLM 模型**（可选）：Obsidian 设置 → ArticleWriter，在预置的 local / deepseek / qwen-dashscope 三组模板中填 api_key 与模型名、「设为激活」，再用「LLM 连接测试」验证。只用文件管理功能可不配。
4. **开始写作**：在 大纲.md 写总纲要点 → 「新建章节」→ 打开该章 章节大纲.md 写细纲 → 「创作章节」按两级大纲+指令流式生成正文并自动去AI味 → 「统计当前章节字数」「保存当前章节」。

### 章节管理
| 命令 | 用法说明 |
| --- | --- |
| 新建章节 | 输入标题 → 建 第NN章-标题/ 目录及 6 份文档（正文 `NN-标题.md`、`NN-标题-大纲.md` 等，文件名前缀为纯数字章号）；编号在当前卷（无当前卷则书根）容器内自动顺延，并设为当前章 |
| 插入章节 | 选参照章与「之前/之后」位置建新空章；参照章所在容器内 ≥插入位的各章编号整体 +1、文档引用与伏笔.md 同步重写，完成后聚焦新章 |
| 章节列表 | 扫描章节目录列出全部章节，选择后打开正文并切为当前章 |
| 下一章 / 上一章 | 按阅读序切换（书根在前、各卷按卷顺序、组内本地号升序）并打开正文；无当前章时 next→第一章、prev→最后一章；到边界提示不切 |
| 删除章节 | 移入回收站并清理元数据与归属引用；**被删号之后同容器仍有章节时自动补洞重新排号**（后续各章 -1、引用同步改写） |
| 重命名章节 | 改章名，同步目录名与文档内引用 |
| 重排章节编号 | 每个容器（书根/每卷）内部各自改为连续序号并改写交叉引用（手动兜底用；日常插删已自动维护连续性） |
| 打包章节合集 | 所选章节正文合一 MD：留空=当前章；`all`=全书；区间如 `3-7`/`3到7` 自动升序；列表如 `1、4、5`（逗号/顿号/空格分隔）；多卷同号裸号会先让你选卷。章标题行格式「## 第N章 章节名」（中文章节号），多章之间以 --- 分隔；无正文章跳过并在结果中列出。输出路径留空=`<书名>-第X章-合集.md`（多章 `-第X-Y章-合集.md`）、`.md` 结尾=指定文件名、否则视为目录（弹窗在输入框上方显示详细用法说明） |
| 导出卷合集 | 某卷全部章节正文合一 MD（与打包同款格式）；默认存小说目录下 `<书名>-<卷名>-合集.md`，输出路径规则同上（弹窗在输入框上方显示详细用法说明）。**写字台卷节点右键为「导出…」**：只问一个范围输入框（不预填、留空/all=该卷全部章节，区间/列表按卷内本地号），不问输出路径、不支持自定义文件名——所选章节正文经书稿引擎合一 MD（文件首行带 `# 第N卷 · 卷名` 标题行），默认存 `<书名>-<卷名>-范围.md`（单章 `-第N章`、连续 `-第X-Y章`、离散 `-第1、4、5章`） |
| 导出书稿 | 「书稿」小节标题右键：所选范围全部章节《章节.md》正文按阅读序合一 MD——留空/all/全部=整本、区间如 `3-7`、列表如 `1、4、5`（多卷可加卷名前缀限定，裸号跨容器时选所在卷）。**有卷模式每个卷组前带「# 第N卷 · 卷名」标题行（无章的空卷也照样输出其卷名）**（卷号按卷顺序），无卷模式平铺不带；章标题行同为「## 第N章 章节名」。**默认文件名按口径区分**：限定某卷=`<书名>-<卷名>-范围.md`（单章 `-第N章`、连续 `-第X-Y章`、离散 `-第1、4、5章`），整本/书根域=`<书名>-书稿.md`（重导覆盖同名文件），输出路径规则同打包。两问弹窗均在输入框上方显示详细用法说明 |
| 统计当前章节字数 / 全书字数 | **只计纯文字字符**（不含标点符号/空白）；全书模式逐章输出并给合计，指定章节不存在计 0 |
| 保存当前章节 | 聚焦编辑器内容强制落盘 |

### 卷 / 场景 / 人物 / 伏笔 / 世界观

**卷（分组容器）用法**：每卷是书根下以卷名命名的实体目录，归属该卷的章节存放其中、**各卷独立从第01章连续编号**；未归卷章节留书根。**新书默认「无卷模式」**（纯「书籍→章节」扁平结构，写字台隐藏全部建卷入口），需先启用有卷才能建卷/归卷——可显式执行下表「启用有卷模式」，或直接跑任一卷命令：**v0.0.16+ 起，无卷模式下触发「新建卷 / 管理卷 / 按卷整理目录 / 导出卷合集」会自动切到「有卷」模式并提示《书名》已启用『有卷』模式，继续…**再正常执行。想回到扁平用「设为无卷模式」（破坏性需确认）。

| 命令组 | 说明 |
| --- | --- |
| 启用有卷模式 / 设为无卷模式 | 启用＝仅置位允许建卷/归卷/按卷整理（不改盘）；禁用＝破坏性拍平——所有已归卷章节移回书根并重排号、删除全部卷目录与元数据（二次确认，幂等可续跑）。v0.0.16+ 无卷模式下直接跑任一卷命令也会自动转为 on |
| 卷列表 / 新建卷 / 管理卷 | 分组容器；每卷在书根下有同名实体目录，归属章节存放其中（**v0.0.15：每卷独立从第1章起编号**，命令里输入裸章号会自动按上下文解析到具体卷，多卷同号时逐个确认）；**新建弹批量建卷页：手动把要建的卷名逐行加入列表（可上移/下移调整创建顺序、删除），确定后按列表顺序依次创建并自动设为当前卷，单个重名失败不中断其余（末尾汇总提示），最后成功的卷可顺带建章归属**（卷描述建成后可在「管理卷→编辑描述」补填）；管理含启用/改名（同步移动实体目录）/改描述/分配章节（支持 all、区间如 3-7、列表如 1，4，5，批量时二次确认；章节目录物理移入卷目录）/删除（章节先移回书根） |
| 按卷整理目录 | 把仍留在书根的已归属章节一次性移入对应卷实体目录（幂等可重复执行）；**书里一个卷都没有时会先弹出同一个批量建卷页**（手动加名单、取消 = 跳过直接继续——已有同名章节目录时，其内章节立即归属该卷）；整理后对仍留书根的未归属章节会逐个让你选择归入哪个卷（仅一卷时一次确认整体移动）；切换书籍时若检测到平面结构会自动强制执行，**全书无卷时同样只弹这一次建卷页**，不弹逐章分配框 |
| 场景列表 / 新增场景 / 管理场景 | 全部章节 + 全局未归属；ID/简介/角色/正文/归属章节；切换/查看/编辑/移动/删除 |
| 人物列表 / 新增人物 / 管理人员 | 身份/性别/性格/外貌/背景/能力等；改名=预览命中后全小说替换并备份 _backup/ |
| 伏笔列表 / 添加伏笔 / 管理伏笔 | 全书 伏笔.md，按「章节+序号」标记完成/取消/删除 |
| 世界观总览 / 设置世界观字段 | 世界/类型/规则/势力/地点/历史/力量体系 |

### 创作规范（三层 WRITING_GUIDE.md）
优先级：小说级 <书名>/WRITING_GUIDE.md > 用户级 work_dir/WRITING_GUIDE.md > 系统级（插件数据目录内固定文件）。每书自动生成《写作指南汇总.md》并注入 LLM 提示词。
| 命令 | 说明 |
| --- | --- |
| 查看创作规范 | 选层直接打开对应文件 |
| 编辑创作规范 | 选层后全量保存，刷新该书《写作指南汇总》 |
| 生成写作指南 | 在用户级与当前书各建一份同格式空骨架；已存在非空则跳过 |
| 重新生成系统写作指南 | 二次确认后按内置默认覆盖系统级文件 |

### LLM 写作
| 命令 | 说明 |
| --- | --- |
| 创作章节 | 目标章解析→大纲覆盖率检查→流式生成+自动去AI味→预览确认保存 |
| 续写当前章 | 末尾 1000 字衔接继续写；本章无正文时回落为「创作章节」 |

| 审阅本章 | 全局视角查逻辑/连贯性问题出报告，可另存 审阅笔记.md |
| LLM 连接测试 | GET /models 验证激活配置 |

## 三、常驻面板（侧边栏图标快捷入口）

- **写字台**（书本图标）：工作目录 + 书籍列表（下拉选书即切换）、当前小说概要、案头资料与书稿（点击打开编辑器，行尾单选钮才激活）；分组可折叠，**「小说状态」概要区点标题行也可折叠/展开**；字数行同时显示纯文字总字数与**含标点符号的总字符数**（形如「总字数 N字（含标点 M 字）」，M 含标点/符号、不含空白）。「书稿」小节内归属了卷的章节挂在「第N卷 · 卷名（X章）」卷树节点下（点行折叠/展开，行尾单选钮选中=启用该卷并跳到其最后一章），未归属章节平铺在卷节点之后。右键条目有快捷菜单——书籍列表标题行：书级「新建小说… / 新建卷…（仅当前激活书、有卷模式）」；案头资料组：「补全资料」（按模板补缺缺失的默认资料——大纲/世界观/伏笔/笔记/人物/人物关系/场景，已存在不覆盖）+「新建资料…」（在书根目录建资料文件）；书稿小节标题：无卷（平铺）模式为「新建章节…」（新建落书根）、有卷模式为「新建卷…」，另恒有「导出书稿…」（全部/所选章节正文合一 MD，有卷模式每卷组前带卷号·卷名标题行、空卷也出卷名）（建章也可右键具体章节行或卷节点）；各章节块与文件行：目录级「新建文章… / 新建章节…（在当前容器末尾顺延编号）」；**各级别文件列表中，不参与写作提示词生成的文件以主题强调色显示、标准模板文档正常显示**（随你的主题配色走，悬停有说明）；**新建资料/文档/文章只弹一个窗口：顶部全宽输入框（内部提示「自定义文件名…」）、中部标准模板文档名均可点击选中回填、底部「确定」按钮统一触发创建**——选中的是标准文档且该文件已存在时弹出存在性提示、你确认后才用模板空内容替换其现有文字；不存在则直接按模板创建；自定义名称直接建空文件；卷节点：「在本卷新建章节… / 新建卷… / 重命名本卷… / 导出…（只问范围——留空/all=该卷全部章节，也可区间/列表；将该卷所选章节正文合一 MD，默认存 <书名>-<卷名>-范围.md）/ 删除本卷（级联删其全部章节，确认后连同章节目录移入回收站，其余章节自动补洞排号）」；章节行另含「在此章前/后插入章节…」「编写本章… / 续写本章… / 润色本章…」及「重命名本章…」「删除本章…」（危险操作二次确认，删除进回收站）。故事状态.md 与磁盘脱节时用命令面板的「扫描重建小说状态文档」手动同步。**切换书籍时若检测到旧格式模板文档（裸名如 章节.md / 卷大纲.md，或旧前缀如 初见-章节.md），会弹确认框提示批量更新为新格式（NN-标题-后缀 / 卷名-后缀），确认后自动重命名。**
- **LLM 对话窗口**（消息图标）：多轮流式聊天，Enter 发送 / Shift+Enter 换行，顶部下拉切换已保存模型（**这里的切换同时就是「设为激活模型」**——会写回 data.json，写作命令/连接测试此后都用它，重启后仍保持；设置页改激活模型时本下拉也会跟着变）、「停止生成」只中断当前轮。支持 @ 引用 vault 任意文件：键入 @ 弹候选列表，或手输 @路径；范围写法 :12、:3-8、@a/b.md 5-9——发送时引用被原位展开为对应内容再发给模型。每轮自动携带创作规范与当前小说上下文快照；历史不落盘。
- **人物关系面板**（人物图标）：汇总当前小说**书籍级 / 卷级 / 章级三层《人物关系.md》**的关系卡片——每张卡片显示「角色A ↔ 角色B」、类型徽章（按类型配图标）、状态指示点（进行中绿 / 铺垫中黄 / 已结束灰）与关系描述；**双击卡片**（或单击分组命名头右侧的「打开文档」）在编辑器打开该层来源 md。顶部有「卡片 / 图表」两个按钮切换展示方式（会话内保持）：**卡片**＝按层级分组的关系卡片（角色对 + 类型徽章 + 状态点 + 描述），**图表**＝角色为节点、关系为连线的环形网络图（连线颜色＝关系类型〔师徒/敌对/情缘/亲族/主从/门派/朋友/同伴/其它，图例随图给出〕、线型＝进行中实线 / 铺垫中虚线 / 已结束点线、加粗＝同一对角色在多处登记；悬停角色高亮其全部邻接、悬停连线只高亮该条，**单击**节点选中它——图表下方的「人物状态」区随即显示该人物的**设定信息**（来自《人物.md》）〔每块＝层级标签（书籍级／卷 · X／章 · 第N章）＋「打开文档」链接＋身份/年龄/性别/性格/外貌/背景/能力/备注字段行（只显示已填项，能力多项以顿号连接）；同名角色在多层登记时逐层各出一块；《人物.md》里还没有该角色时提示可用顶部「添加人物」补录；× 清除选中〕，选中节点带强调色描边；**双击**节点或连线在编辑器打开来源文档；整张图可**滚动滚轮缩放**（以鼠标位置为不动点——鼠标下的图点缩放前后不动；向下滑=缩小、上滑=放大；累计 50 像素切一档），图与角色名一起等比缩放。放大后面板装不下的部分**按住图面拖动即可平移查看**——面板不出滚动条，拖动带边界限位（图不会被拖出视野找不回来））；另有「筛选角色 / 类型 / 状态」输入框、**「添加人物」**与「刷新」按钮（不显示工作目录与小说列表，面板只呈现关系本身——要换书请用「切换当前小说」命令或在写字台里点小说）；卡片方式下各层级分组可折叠；关系文档在编辑器里改动后面板自动刷新。条目写法：`## 角色A - 角色B` + `- 类型：` / `- 状态：` / `- 描述：`（描述也可直接跟一行文字或 ```text 围栏），也兼容旧的「标题带角色对 + 描述围栏」写法。**「添加人物」按钮**：弹窗内填姓名、选**人物级别**（书籍级＝写书根《人物.md》／卷级＝写该卷目录《人物.md》／章级＝写该章目录《人物.md》，默认落在当前写作位置）与身份/年龄/性别/性格/外貌/背景/能力/备注；下方「+ 添加关系」每点一次新增一行关系（**关系对象下拉**＝该级别范围内已有角色名优先、其余层级角色追加在后，**关系类型下拉**＝师徒/同门/朋友/同伴/恋人/亲族/主仆/敌对/对手/盟友），可加多行、每行可单独删除；点最下方「确定」后先写人物、再把关系条目按同一级别追加进对应《人物关系.md》（书根／卷目录／章节目录，均按模板格式 `## A - B` + `- 类型：` + `- 状态：`；文件缺失时按该层模板起底、已有内容原样保留）。

 - **时间线面板**（历史图标）：把当前小说**书根 / 卷目录 / 章节目录三层《时间线.md》合并成一条**自上而下的纵向时间轴——全部条目按时间点升序排列（支持 `年` / `年-月` / `年-月-日`，如 `-129-06-15`；负数、小数、科学计数也可），每条带来源层级标签（书籍级／卷 · X／章 · 第N章 Y）标明出自哪个文件；底部汇总行给出总条数与各层分布。顶部筛选框可按人物/事件关键字过滤，**双击条目在编辑器打开该文档并定位到对应的 `## <时间点>` 标题行**。某份《时间线.md》有内容但没有有效条目时，列表下方给可点击提示（点开检查格式）。时间线文档是手写参考资料，不参与写作提示词生成：放书根 `时间线.md`、卷目录 `<卷名>-时间线.md`（裸 `时间线.md` 亦可）、章节目录 `NN-<标题>-时间线.md`（裸名亦可）——已列入各层默认文档模板清单，新建书/卷/章自动播种空模板，写字台「补全资料」等动作同样补缺；写法＝每个 `## <时间点>` 标题一个时间点（`年` / `年-月` / `年-月-日`），块内 `- 人物：A、B` 字段行记涉及角色、`- 事件：<文字>` 记事件（其后还可跟自由文本或 ```text 围栏多行正文），非时间点标题的块整块忽略。文档改动后面板自动刷新。
 - **每本书独立工作区**：每本书自动维护一份以其书名命名的窗口布局存档（打开的标签页/分栏/停靠的面板位置）。切换书籍或加载书籍时先归档旧书的当前窗口状态、再恢复目标书已存的工作区（弹「已加载『X』的工作区」提示）。**显式切换到一本还没有工作区存档的书时（切书选择器、写字台下拉框、新建小说），会关闭主编辑区内所有打开的文档页签，用空编辑器开始新书**——避免把上一本书的章节标签带进新书；命令运行时隐式解析当前书不会触发此清理。侧栏停靠的面板与浮动窗口不受影响；日常开合标签、调整分栏也会防抖自动存入当前书。存档位于 `.obsidian/plugins/articlewriter/workspaces/<书名>.json`，随书改名迁移、删书清理；桌面与移动端布局互不恢复。Obsidian 重启后仍按自身全局会话恢复上次布局（此时即最近一次已存档的状态），不做额外干预。

## 四、设置项（Obsidian 设置 → ArticleWriter）

- **工作目录（work_dir）**：写小说的文件夹，首次使用自动弹出选择器初始化。
- **创建后自动打开文档**：建书打开 大纲.md、建章打开 章节.md。
- **前文参考章数 prevN**：写作命令提示词注入【前文内容】的最近 N 章（每章取 AI 摘要；0=不注入）。留空=默认 3。有卷模式下窗口限本卷，不再拉取他卷章节细节。所有摘要均为**延迟生成**：组装提示词需要时才检查并补全（只生成本次提示词实际用到的章节，不遍历其他章节逐个生成；缺失/正文已改即经 LLM 重新生成落盘）。生成工作过程在「生成过程」面板中实时展示——先逐行列出摘要生成的带时间戳日志，完成后同一面板内继续流式显示本章正文（打字机效果），最后在该面板点「保存 / 不保存」决定是否写盘（Esc 或「停止生成」可随时中断）。
- **注入整卷《卷摘要》**（开关，默认关）：开启后写作上下文额外包含当前卷完整《卷摘要》，跨卷缺口另以各前卷《卷摘要》由近及远填充（均按该卷已生成的章节摘要为输入整体重建、随更多摘要陆续生成而变全，其中任一变化即自动失效重算）；关闭＝严格只注入最近 N 章单章摘要（推荐保持默认）。
- **LLM 配置**：多组 OpenAI 兼容端点（本地 Ollama/LM Studio 或 DeepSeek/DashScope 等），每组含 base_url/api_key/模型名/temperature/max_tokens 等；「设为激活」「测试连接」。数据存插件 data.json，api_key 仅发往你自己配置的端点。

## 五、数据约定（目录结构）

```
<工作目录>/<书名>/
├── 故事状态.md        # YAML frontmatter 运行态（标题/类型/当前卷场景章节/各章元数据），正文可自由笔记
├── WRITING_GUIDE.md   # 小说级创作规范
├── 写作指南汇总.md     # 三层合并自动生成（哈希变更检测），注入提示词的唯一来源
├── 使用说明.md         # 本文档（位于工作目录根，非每书一份）
├── 大纲.md / 世界观.md / 卷.md / 伏笔.md / 笔记.md
├── 第NN章-<标题>/      # 未归属任何卷的章节直接放书根
└── <卷名>/              # 卷实体目录：每卷一个、以卷名命名（卷名须唯一），归属该卷的章节存放其中
    └── 第NN章-<标题>/   # 与书根同构（各卷独立编号：每卷从第1章起，互不复用）
        ├── NN-<标题>.md            # 正文（文件名前缀为纯数字章号）
        ├── NN-<标题>-大纲.md
        ├── 章节摘要.md             # AI 自动维护的章节摘要（写盘后刷新、上下文组装时缺失即生成；非模板、不带前缀）
        └── NN-<标题>-人物.md / -人物关系.md / -场景.md / -信息.md
```

卷实体目录内的模板文档同样以卷名开头（如 `<卷名>-大纲.md`、`<卷名>-人物.md`、`<卷名>-人物关系.md`、`<卷名>-场景.md`）。

三层《时间线.md》为**手写参考资料**（不参与提示词注入）：书根 `时间线.md`、卷目录 `<卷名>-时间线.md`（裸 `时间线.md` 亦可）、章节目录 `NN-<标题>-时间线.md`（裸名亦可）——已列入各层默认文档模板清单，新建书/卷/章时随模板播种空文件，缺失时可经写字台「补全资料 / 补全卷文档 / 新建文章…」等动作补齐，已有内容一律原样保留；由「时间线面板」把三层合并成一条时间轴只读展示。格式：每个 `## <时间点>` 标题＝一个时间点（支持 `年` / `年-月` / `年-月-日`，如 `-129-06-15`；负数/小数/科学计数也可），块内 `- 人物：A、B` 字段行记涉及角色、`- 事件：<文字>` 记事件描述（其后还可跟自由文本或 ```text 围栏多行正文）；非时间点标题的块整块忽略。详见「三、常驻面板 · 时间线面板」。

新建时缺失文档自动创建为模板；已存在则跳过不覆盖用户内容。**旧格式文档（裸名如 `章节.md`/`卷大纲.md`，或旧前缀如 `初见-章节.md`、`第01章-初见-大纲.md`）在切换书籍时会自动检测并提示批量更新**——确认后仅重命名文件为「NN-标题-后缀」/「卷名-后缀」格式，不改动内容。

## 六、常用标记速查

- **大纲详略**：[详] 重点展开 / [扩] 扩展细节 / [补] 补充小情节 / [略] 简略带过 / [跳] 可不写；[/] 或 [/详] 等结束作用域，可在同一行分段控制。
- **伏笔提取**：大纲中 [伏]...[/] 包裹的内容会被解析入全书 伏笔.md。
- **创作规范分类区块**：<!-- 写作指南分类:禁用词|故事风格|个人特色 --> ... <!-- /写作指南分类 -->；未包裹内容归「通用」。
