# ArticleWriter 使用说明

> 本文档由 ArticleWriter 插件在设置工作目录后自动生成，可自由编辑；「生成使用说明」命令仅在文件缺失或为空时写入最新内置版本，不会覆盖你已修改的内容。

## 一、快速上手

1. **设置工作目录**：首次使用任何 ArticleWriter 命令会弹出文件夹选择器，从 vault 已有文件夹中选定一个作为工作目录（work_dir）。每本小说都是 work_dir 下的一个子文件夹；之后可随时用「选择工作目录」命令或设置页改换（切换后清空上次选书记忆）。确认后若该目录下还没有《使用说明.md》会自动创建并打开（插件每次启动也会自检补建）。
2. **创建新小说**：输入标题 / 题材 / 编写类型，自动建 <书名>/ 目录与全套模板文档（故事状态.md、大纲.md、世界观.md、卷.md、伏笔.md、笔记.md 等）；已存在的文档跳过不覆盖。
3. **配置 LLM 模型**（可选）：Obsidian 设置 → ArticleWriter，在预置的 local / deepseek / qwen-dashscope 三组模板中填 api_key 与模型名、「设为激活」，再用「LLM 连接测试」验证。只用文件管理功能可不配。
4. **开始写作**：在 大纲.md 写总纲要点 → 「新建章节」→ 打开该章 章节大纲.md 写细纲 → 「创作章节」（/write）按两级大纲+指令流式生成正文并自动去AI味 → 「统计当前章节字数」「保存当前章节」。

## 二、命令一览（命令面板搜 "ArticleWriter"）

### 基础
| 命令 | 说明 |
| --- | --- |
| 选择工作目录 | 初始化/更换 work_dir（对齐 CLI --work-dir / /dir） |
| 切换当前小说 | 列出全部小说（含章数/当前章），选中即加载其状态 |
| 创建新小说 | 建书：小说文件夹 + 全套模板文档 |
| 小说状态 | 标题/题材/编写类型/当前卷场景章节/章节数/总字数 |

### 章节
| 命令 | 说明 |
| --- | --- |
| 新建章节 | 建 第NN章-标题/ 目录及正文/大纲/人物等 6 份文档，并设为当前章 |
| 插入章节 | 选参照章与「之前/之后」位置建新空章（写字台右键章节行也有同义入口）；≥插入位的各章编号整体 +1、文档内引用与伏笔.md 同步重写，完成后自动聚焦到新章 |
| 章节列表 | 扫描章节目录，选择后打开正文并切为当前章 |
| 下一章 / 上一章 | 无当前章时 next→第一章、prev→最后一章；到边界提示不切 |
| 删除章节 | 移入回收站并清理元数据与归属引用；**被删号之后仍有章节时自动补洞重新排号**（后续各章 -1、引用同步改写，保持连续编号） |
| 重命名章节 | 同步改目录名与文档内引用 |
| 重排章节编号 | 全部改为连续序号，改写交叉引用（手动兜底用；日常插删已自动维护连续性） |

| 保存当前章节 | 聚焦编辑器内容强制落盘 |

### 创作规范（三层 WRITING_GUIDE.md）
优先级：小说级 <书名>/WRITING_GUIDE.md > 用户级 work_dir/WRITING_GUIDE.md > 系统级（插件数据目录内固定文件）。每书自动生成《写作指南汇总.md》并注入 LLM 提示词。
| 命令 | 说明 |
| --- | --- |
| 查看创作规范 | 选层直接打开对应文件 |
| 编辑创作规范 | 选层后全量保存，刷新该书《写作指南汇总》 |
| 生成写作指南 | 在用户级与当前书各建一份同格式空骨架；已存在非空则跳过 |
| 重新生成系统写作指南 | 二次确认后按内置默认覆盖系统级文件 |

### LLM 写作
| 命令 | 对齐 CLI | 说明 |
| --- | --- | --- |
| 创作章节 | /write | 目标章解析→大纲覆盖率检查→流式生成+自动去AI味→预览确认保存 |
| 续写当前章 | /continue | 末尾 1000 字衔接继续写；本章无正文时回落到 /write |
| 重写本章 | /rewrite | 基于大纲与旧文整体重构，含前后章桥接 |
| 润色当前章 | /polish | 仅优化文字表达不改情节 |
| 去AI味 | /deai | 含 AI 常用词的句子打回 LLM 重写并原位替换 |
| 审阅本章 | /review | 全局视角查逻辑/连贯性问题出报告，可另存 审阅笔记.md |
| LLM 连接测试 | /llm test | GET /models 验证激活配置 |

## 三、常驻面板（侧边栏图标快捷入口）

- **写字台**（书本图标）：工作目录 + 书籍列表（下拉选书即切换）、当前小说概要、全局文档与各章文件树（点击打开编辑器，行尾单选钮才激活章节）；分组可折叠。右键条目有快捷菜单——书级「新建卷…」、章级「在此章前/后插入章节…」「重命名本章…」「删除本章…」及 LLM 写作三项（危险操作二次确认，删除进回收站）。故事状态.md 与磁盘脱节时用命令面板的「扫描重建小说状态文档」手动同步。右键条目有快捷菜单——书级「新建卷…」、章级「在此章前/后插入章节…」「重命名本章…」「删除本章…」及 LLM 写作三项（危险操作二次确认，删除进回收站）。
- **LLM 对话窗口**（消息图标）：多轮流式聊天，Enter 发送 / Shift+Enter 换行，顶部下拉切换已保存模型、「停止生成」只中断当前轮。支持 @ 引用 vault 任意文件：键入 @ 弹候选列表，或手输 @路径；范围写法 :12、:3-8、@a/b.md 5-9——发送时引用被原位展开为对应内容再发给模型。每轮自动携带创作规范与当前小说上下文快照；历史不落盘。

## 四、设置项（Obsidian 设置 → ArticleWriter）

- **工作目录（work_dir）**：写小说的文件夹，首次使用自动弹出选择器初始化。
- **创建后自动打开文档**：建书打开 大纲.md、建章打开 章节.md。
- **LLM 配置**：多组 OpenAI 兼容端点（本地 Ollama/LM Studio 或 DeepSeek/DashScope 等），每组含 base_url/api_key/模型名/temperature/max_tokens 等；「设为激活」「测试连接」。数据存插件 data.json，api_key 仅发往你自己配置的端点。

## 五、数据约定（目录结构）

```
<工作目录>/<书名>/
├── 故事状态.md        # YAML frontmatter 运行态（标题/类型/当前卷场景章节/各章元数据），正文可自由笔记
├── WRITING_GUIDE.md   # 小说级创作规范
├── 写作指南汇总.md     # 三层合并自动生成（哈希变更检测），注入提示词的唯一来源
├── 使用说明.md         # 本文档（位于工作目录根，非每书一份）
├── 大纲.md / 世界观.md / 卷.md / 伏笔.md / 笔记.md
└── 第NN章-<标题>/      # 每章一个文件夹
    ├── 章节.md          # 正文
    ├── 章节大纲.md
    └── 人物.md / 人物关系.md / 场景.md / 章节信息.md
```

新建时缺失文档自动创建为模板；已存在则跳过不覆盖用户内容。

## 六、常用标记速查

- **大纲详略**：[详] 重点展开 / [扩] 扩展细节 / [补] 补充小情节 / [略] 简略带过 / [跳] 可不写；[/] 或 [/详] 等结束作用域，可在同一行分段控制。
- **伏笔提取**：大纲中 [伏]...[/] 包裹的内容会被解析入全书 伏笔.md。
- **创作规范分类区块**：<!-- 写作指南分类:禁用词|故事风格|个人特色 --> ... <!-- /写作指南分类 -->；未包裹内容归「通用」。
