# ArticleWriter 使用说明

> 本文档由 ArticleWriter 插件在设置工作目录后自动生成，可自由编辑；「生成使用说明」命令仅在文件缺失或为空时写入最新内置版本，不会覆盖你已修改的内容。

## 一、安装与快速上手

### 安装

#### 方式一：Obsidian 社区插件市场（推荐）

1. 打开 Obsidian → **设置 → 第三方插件**（首次使用需先关闭「安全模式」）→ 点「浏览」进入社区插件市场。
2. 搜索 **ArticleWriter** → 点「安装」→ 安装完成后点「启用」。
3. 左侧栏出现书本/消息/人物/历史四个图标即安装成功。
4. **更新**：社区插件由 Obsidian 自动检查更新（也可在 设置 → 第三方插件 里手动「检查更新」后更新 ArticleWriter），更新后建议重启 Obsidian 生效。
5. **卸载**：先「停用」，再在插件条目处点「卸载」。你的小说文件都在 vault 普通目录里，不受影响。

#### 方式二：GitHub Releases 手动安装（备用／离线场景）

1. **下载三件套**：打开发布页 `https://github.com/gengbl/articlewriter-obsidian/releases`，在最新 Release 的 Assets 里下载 **`main.js`、`manifest.json`、`styles.css`** 三个文件（缺一不可：`manifest.json` 是插件元数据、`main.js` 是代码、`styles.css` 是界面样式）。
2. **放入插件目录**：在你的 vault 根目录下建目录 `.obsidian/plugins/articlewriter/`（`.obsidian` 是隐藏目录，文件管理器需开启显示隐藏文件；没有就手动创建），把三个文件放进去。放好后结构应为：
   ```
   <你的vault>/.obsidian/plugins/articlewriter/
   ├── main.js
   ├── manifest.json
   └── styles.css
   ```
3. **启用插件**：打开 Obsidian → 设置 → 第三方插件 → 社区插件列表会出现 **ArticleWriter** → 点「启用」。
4. **更新**：下载新版三件套直接覆盖同名文件，然后在 Obsidian 里重载插件（设置 → 第三方插件 → ArticleWriter 关再开，或重启 Obsidian）生效。手动安装后插件不再走社区市场的自动更新。

### 首次使用

1. **设置工作目录**：首次使用任何 ArticleWriter 命令会弹出文件夹选择器，从 vault 已有文件夹中选定一个作为工作目录（work_dir）。每本小说都是 work_dir 下的一个子文件夹；之后可随时用「选择工作目录」命令或设置页改换（切换后清空上次选书记忆）。确认后若该目录下还没有《使用说明.md》会自动创建并打开（插件每次启动也会自检补建）。
2. **创建新小说**：输入标题 / 题材 / 编写类型，自动建 <书名>/ 目录与全套模板文档（故事状态.md、大纲.md、世界观.md、卷.md、伏笔.md、笔记.md 等）；已存在的文档跳过不覆盖。
3. **配置 LLM 模型**（必配才能用 AI 写作）：Obsidian 设置 → ArticleWriter，在预置的 local / deepseek / qwen-dashscope 三组模板中填 api_key 与模型名、「设为激活」，再用「LLM 连接测试」验证。只用文件管理功能可不配。
4. **开始写作**：在 大纲.md 写总纲要点 → 「新建章节」→ 打开该章 章节大纲.md 写细纲 → 「创作章节」按本卷大纲与本章大纲+指令流式生成正文并自动去AI味 → 「统计当前章节字数」「保存当前章节」。

### 手动分步写作流程（从零到成书走查）

不想跑全自动流水线、想逐步掌控时，按这个顺序走（每一步都可单独反复执行、人工检查后再进下一步）：

1. **建书**：「创建新小说」→ 输入标题/题材/编写类型。
2. **写世界观**：「打开世界观」手写设定，或跑「生成世界观」（需先有一句话设定）。
3. **生成策划指南**：「策划指南」命令 AI 生成书级《策划指南.md》（十节规划约束；分卷模式会先问卷数量）。
4. **生成书级大纲**：「生成书籍大纲」——平铺模式问目标章数（产出恰好 N 个 `## 第N章` 标记）；分卷模式问卷数量（产出 `## 第X卷·卷名` 小节＋卷声明行）。
5. **落结构**：
   - 平铺：「书稿」小节标题右键「从书级大纲生成章节…」把书级大纲拆成章节；
   - 分卷：「从书级大纲生成卷」按卷声明逐卷建卷并生成卷大纲，再对各卷跑「从卷大纲生成章节」拆出章节。
6. **逐章写正文**：「创作章节」写单章（带预览确认），或「连续编写」从第一个没有正文的章起批量推进。
7. **打磨**：「续写当前章」「重写本章」「润色当前章」「去AI味」「错别字检测」「审阅本章」。

每一步的产物都是普通 Markdown 文档，可直接手动编辑后再继续下一步；AI 生成命令大多支持「已有内容跳过/覆盖」与增量续写，重复执行安全。

### 章节管理

| --- | --- |
| 新建章节 | 输入标题 → 建 第NN章-标题/ 目录及 6 份文档（正文 `NN-标题.md`、`NN-标题-大纲.md` 等，文件名前缀为纯数字章号）；编号在当前卷（无当前卷则「书稿」未归属域）容器内自动顺延，并设为当前章 |
| 插入章节 | 选参照章与「之前/之后」位置建新空章；参照章所在容器内 ≥插入位的各章编号整体 +1、文档引用与伏笔.md 同步重写，完成后聚焦新章 |
| 章节列表 | 扫描章节目录列出全部章节，选择后打开正文并切为当前章 |
| 下一章 / 上一章 | 按阅读序切换（书稿未归属章节在前、各卷按卷顺序、组内本地号升序）并打开正文；无当前章时 next→第一章、prev→最后一章；到边界提示不切 |
| 删除章节 | 移入回收站并清理元数据与归属引用；**被删号之后同容器仍有章节时自动补洞重新排号**（后续各章 -1、引用同步改写） |
| 重命名章节 | 改章名，同步目录名与文档内引用 |
| 重命名章节文件 | 重命名章节（与「重命名章节」同效）：选章 → 输入新标题 → 目录名改为 第NN章-新名 并同步文档内引用；命令名沿用旧措辞「将旧格式改为第NN章-章节名格式」 |
| 重排章节编号 | 每个容器（书稿未归属域/每卷）内部各自改为连续序号并改写交叉引用（手动兜底用；日常插删已自动维护连续性） |
| 打包章节合集 | 所选章节正文合一 MD：留空=当前章；`all`=全书；区间如 `3-7`/`3到7` 自动升序；列表如 `1、4、5`（逗号/顿号/空格分隔）；多卷同号裸号会先让你选卷。章标题行格式「## 第N章 章节名」（中文章节号），多章之间以 --- 分隔；无正文章跳过并在结果中列出。输出路径留空=`<书名>-第X章-合集.md`（多章 `-第X-Y章-合集.md`）、`.md` 结尾=指定文件名、否则视为目录（弹窗在输入框上方显示详细用法说明） |
| 导出卷合集 | 某卷全部章节正文合一 MD（与打包同款格式）；默认存小说目录下 `<书名>-<卷名>-合集.md`，输出路径规则同上（弹窗在输入框上方显示详细用法说明）。**写字台卷节点右键为「导出…」**：只问一个范围输入框（不预填、留空/all=该卷全部章节，区间/列表按卷内本地号），不问输出路径、不支持自定义文件名——所选章节正文经书稿引擎合一 MD（文件首行带 `# 第N卷 · 卷名` 标题行），默认存 `<书名>-<卷名>-范围.md`（单章 `-第N章`、连续 `-第X-Y章`、离散 `-第1、4、5章`）。**正文开头若自带章节号行（如「第3章 标题」「第三章：标题」）会先被去掉，章节号只使用导出生成的** |

| 统计当前章节字数 / 全书字数 | **只计纯文字字符**（不含标点符号/空白）；全书模式逐章输出并给合计，指定章节不存在计 0 |
| 保存当前章节 | 聚焦编辑器内容强制落盘 |

### 卷 / 场景 / 人物 / 伏笔 / 世界观

**卷（分组容器）用法**：每卷是「书稿/」下以卷名命名的实体目录，归属该卷的章节存放其中（卷名不可用「引言」——该名称保留给书稿引言文件夹）、**各卷独立从第01章连续编号**；未归卷章节留「书稿/」。**新书默认「无卷模式」**（纯「书籍→章节」扁平结构，写字台隐藏全部建卷入口），需先启用有卷才能建卷/归卷——可显式执行下表「启用有卷模式」，或直接跑任一卷命令：**v0.0.16+ 起，无卷模式下触发「新建卷 / 管理卷 / 按卷整理目录 / 导出卷合集」会自动切到「有卷」模式并提示《书名》已启用『有卷』模式，继续…**再正常执行。想回到扁平用「设为无卷模式」（破坏性需确认）。

| 命令组 | 说明 |
| --- | --- |
| 启用有卷模式 / 设为无卷模式 | 启用＝仅置位允许建卷/归卷/按卷整理（不改盘）；禁用＝破坏性拍平——所有已归卷章节移回「书稿/」并重排号、删除全部卷目录与元数据（卷内残留设定文档先 salvage 到「案头资料/」保留）（二次确认，幂等可续跑）。v0.0.16+ 无卷模式下直接跑任一卷命令也会自动转为 on |
| 卷列表 / 新建卷 / 管理卷 | 分组容器；每卷在「书稿/」下有同名实体目录，归属章节存放其中（**v0.0.15：每卷独立从第1章起编号**，命令里输入裸章号会自动按上下文解析到具体卷，多卷同号时逐个确认）；**新建弹批量建卷页：手动把要建的卷名逐行加入列表（可上移/下移调整创建顺序、删除），确定后按列表顺序依次创建并自动设为当前卷，单个重名失败不中断其余（末尾汇总提示），最后成功的卷可顺带建章归属**（卷描述建成后可在「管理卷→编辑描述」补填）；管理含启用/改名（同步移动实体目录）/改描述/分配章节（支持 all、区间如 3-7、列表如 1，4，5，批量时二次确认；章节目录物理移入卷目录）/删除（章节先移回书根） |
| 按卷整理目录 | 把仍留在「书稿/」的已归属章节一次性移入对应卷实体目录（幂等可重复执行）；**书里一个卷都没有时会先弹出同一个批量建卷页**（手动加名单、取消 = 跳过直接继续——已有同名章节目录时，其内章节立即归属该卷）；整理后对仍留书根的未归属章节会逐个让你选择归入哪个卷（仅一卷时一次确认整体移动）；切换书籍时若检测到平面结构会自动强制执行，**全书无卷时同样只弹这一次建卷页**，不弹逐章分配框 |
| 场景列表 / 新增场景 / 管理场景 | 全部章节 + 全局未归属；ID/简介/角色/正文/归属章节；切换/查看/编辑/移动/删除 |
| 人物列表 / 新增人物 / 管理人员 | 身份/性别/性格/外貌/背景/能力等；「管理人员」内可改名（全小说 MD 替换并备份 _backup/） |
| 角色改名 | 按名选角色 → 输入新名字（预填旧名）→ **全书 MD 文档**（《人物》《人物关系》《场景》《大纲》与各章正文等）同步替换，命中处数与文件数在完成提示中汇报；原文件先备份到 `_backup/角色改名_时间戳/`。替换按文本全量匹配（包含子串），改名前请确认旧名不会误伤其他词。人物关系面板「人物状态」区选中的角色旁也有「改名」快捷入口 |
| 分析人物与场景 | AI 逐章深度分析已有正文，自动把人物/场景按**出现范围**归入书/卷/章三层的《人物.md》《场景.md》，并把新的人物关系追加到对应层《人物关系.md》：每章一次 AI 调用（「生成过程」面板实时流式预览），全部章分析完后按出现章节定层——出现在 ≥2 个卷（平铺模式＝≥2 章）→ 书级（「案头资料/」）；单卷内 ≥2 章 → 该卷「文档/」；仅 1 章 → 该章目录（平铺模式只有书级/章两级）。已存在的同名人物/场景会**移动到新判定层并合并字段**（你手写的字段优先保留、缺项才补 AI 分析值，重复运行结果稳定不漂移；场景正文 content 只保留绝不覆盖）；人物关系按 A-B 对去重，已有的不重复追加。空章跳过；某章输出解析失败会自动带纠正说明重试（最多 3 次），仍失败的章跳过并在收尾汇总中列出，不影响其他章；点「停止生成」/关面板中止则本次**不写任何文件**。提示词会注入已知人名/场景名清单辅助跨章统一称呼 |
| 伏笔列表 / 添加伏笔 / 管理伏笔 | 全书 伏笔.md，按「章节+序号」标记完成/取消/删除 |
| 世界观总览 / 设置世界观字段 | 世界/类型/规则/势力/地点/历史/力量体系 |

### 全自动写书（按技能）
把六个生成命令串成一条**无人参与**的流水线：一句话设定 → 整套书。驱动者是插件本身（固定顺序、固定参数），AI 只负责各阶段内的文本生成。**唯一入口是「按技能全自动写书」**——先用「创建自动化建书技能」把参数存成技能文件，再一键执行。

| 命令 | 说明 |
| --- | --- |
| 生成世界观 | 以一句话设定为种子 AI 流式生成书级《案头资料/世界观.md》（全自动写书流水线首阶段，亦可单独运行）。一句话优先取故事状态里已存的一句话设定，为空则弹窗补问（补问值会存回故事状态作下次默认）。固定小节结构（「世界基本规则」「世界观红线」必含），只写设定不写情节；上下文＝书籍信息＋创作规范＋张力规则（按阶段 0「引用文档」配置框过滤注入）。已有非空世界观**直接覆盖、不确认**。 |
| 按技能全自动写书 | 一句话→整套书六阶段流水线的**唯一入口**：**生成世界观 → 生成策划指南 → 生成书级大纲 → 建卷并生成卷大纲 → 生成章节大纲 → 连续编写正文**。读取当前书《案头资料/》里所有带 `auto_book: true` 标记的技能文件（只有一个直接执行，多个弹选择器）。**参数齐全＝免交互直接开跑**整条流水线，全程零点击；缺参数会列出缺什么、并把技能里已有的参数预填进补填弹窗（起始节点/一句话/规模参数/覆盖），补填后开跑。**启动前预检**：按起始阶段所需的前置文件查盘（如从「生成章节大纲」起跑要求卷与卷大纲已存在），缺什么列出什么并拒绝启动——不生成任何内容。运行中所有弹窗询问自动按流水线参数回答（章数/卷数/覆盖确认等），「生成过程」面板自动保存。前三个阶段（世界观/策划指南/书级大纲）已有产物且未开「覆盖」开关则整阶段跳过；后三个阶段命令本身增量、只补缺失。已在运行时重复启动会被拒（先停止再启）。技能文件就是普通 Markdown，可在聊天窗口 @ 引用、可直接编辑；手写格式：frontmatter 首行 `auto_book: true`，可选字段 `start`（起始节点）/`mode`（flat 或 volumes）/`chapters`/`volumes`/`chapter_counts`/`overwrite`，正文即一句话设定。 |
| 停止全自动写书 | 中断当前生成并停止后续阶段。也可在「生成过程」面板上直接点「停止生成」——流水线在阶段边界检测到即停（v0.3.0+ 起 Esc 不再中断生成）。**阶段之间**（无流式生成时）关闭面板不影响流水线继续。 |
| 创建自动化建书技能 | 向导窗口生成一个**建书技能文件**保存到当前书《案头资料/<文件名>.md》：文件里存好起始节点、一句话设定、规模参数（按所选模式显示：平铺＝全书总章数；分卷＝卷数＋各卷章数，下方显示推算的全书总章数；文件里只写所选模式的参数）、覆盖开关。之后运行「按技能全自动写书」就按这份文件执行，不用再逐项填。同名文件已存在会先确认覆盖。用前须已创建好书籍（技能不含建书）。 |

**注意区分**：「建书技能」（案头资料/ 下、驱动全自动写书流水线的模板文件）与「写作技巧技能」（插件数据目录 SKILLS/ 下、注入 AI 提示词的技巧文档，见「参考文档与技能」设置）是两套东西，目录与用途都不同。

### 按技能全自动写书：逐步操作指南

**前置条件**：① 已用「创建新小说」建好书籍目录（技能文件不负责建书）；② 已在设置页配好并激活 LLM 配置（建议先跑「LLM 连接测试」）；③ 已把该书设为当前小说（「切换当前小说」或写字台下拉选书）。

**第 1 步 · 创建建书技能**：命令面板运行「创建自动化建书技能」，向导窗口逐字段填写：

| 字段 | 怎么填 |
| --- | --- |
| 技能文件名 | 保存到《案头资料/<文件名>.md》的文件名（不含 .md），默认「自动建书」 |
| 起始节点 | 六选一：生成世界观 / 生成策划指南 / 生成书级大纲 / 建卷并生成卷大纲 / 生成章节大纲 / 连续编写正文。从零开始选「生成世界观」；书已有部分产物时选第一个还没做的节点 |
| 一句话设定 | 写入技能文件正文；起始节点为「生成世界观」时必填（会预填故事状态里已有的一句话） |
| 规模模式 | 平铺（无卷）或 分卷；默认跟随当前书籍模式 |
| 全书总章数 | 仅平铺模式显示：正整数，全书恰好规划这么多章 |
| 卷数 / 各卷章数 | 仅分卷模式显示：卷数为正整数；各卷章数填一个整数＝所有卷同章数，或按卷逐个填（逗号/顿号/空格分隔），下方实时显示推算的全书总章数 |
| 覆盖已有产物 | 开＝世界观/策划指南/书级大纲即使已有内容也重新生成；关＝已有即跳过该阶段 |

点「创建技能文件」落盘（同名文件已存在会先确认覆盖）。

**第 2 步 · 运行**：命令面板运行「按技能全自动写书」。当前书《案头资料/》里只有一个技能文件就直接执行，多个会弹选择器。**参数齐全＝免交互零点击开跑**；技能缺参数会弹窗列出缺什么、已有参数预填，补填后开跑。

**第 3 步 · 预检（自动）**：启动前按起始节点查盘，缺前置文件会列出缺什么并拒绝启动（不生成任何内容）。各起始节点要求：

| 起始节点 | 盘上必须已有 |
| --- | --- |
| 生成世界观 | 无（只需一句话设定） |
| 生成策划指南 | 案头资料/世界观.md（非空） |
| 生成书级大纲 | 案头资料/世界观.md（非空） |
| 建卷并生成卷大纲 | 世界观.md ＋ 书级《大纲.md》（非空，分卷模式还需含卷声明行） |
| 生成章节大纲 | 世界观.md ＋ 分卷：各卷《卷大纲.md》含「第N章」章条目／平铺：书级《大纲.md》含章标记 |
| 连续编写正文 | 世界观.md ＋ 各章《章节大纲.md》（非空） |

**第 4 步 · 监控与停止**：运行中「生成过程」面板实时流式预览每个阶段，所有弹窗询问自动按技能参数回答、产物自动保存。想中途停：命令面板「停止全自动写书」或面板上点「停止生成」——在阶段边界生效，已落盘内容保留（v0.3.0+ 起 Esc 不再中断生成；阶段之间关面板不影响流水线继续）。已在运行时重复启动会被拒，先停止再启。

**第 5 步 · 重复跑＝增量补齐**：跑一半中断（停止/报错/断连）后，直接再跑同一个技能即可续起——前三个阶段（世界观/策划指南/书级大纲）已有产物且未开「覆盖」则整阶段跳过；后三个阶段本身增量，只补缺失的卷/章大纲/正文。

**技能文件手写格式**（就是普通 Markdown，可直接编辑、可在聊天窗口 @ 引用）：

```markdown
---
auto_book: true
start: worldview
mode: volumes
volumes: 3
chapter_counts: 10, 12, 12
overwrite: false
---
一个能看见别人死期的少年，发现自己每次说出死期都会提前应验
```

- `start` 取值＝六个起始节点 id：`worldview` / `planning` / `book-outline` / `volumes` / `chapter-outlines` / `bodies`
- `mode`：`flat`（平铺）或 `volumes`（分卷）；缺省跟随当前书籍模式
- 平铺用 `chapters: 30`；分卷用 `volumes` ＋ `chapter_counts`（单个数＝各卷同章数）
- `overwrite: true/false`；`premise` 可选（缺省时正文第一行即一句话设定）

## 四、设置项（Obsidian 设置 → ArticleWriter）

打开 Obsidian 设置 → 第三方插件 → ArticleWriter 进入设置页。页面自上而下四个区块：**顶层设置**（工作目录与写作上下文）、**写作阶段模型配置**（四标签页）、**LLM 配置**（两标签页）、**关于**。所有项**改动即落盘**（存插件 data.json），没有保存按钮；填错随时改回。

### 4.1 顶层设置

| 设置项 | 控件 | 用法与取值 |
| --- | --- | --- |
| 工作目录（work_dir） | 文本框 | 写小说的文件夹（vault 内已有文件夹）。首次使用任何命令时会自动弹出选择器让你选定；以后建书/建章/打开文档等全部在该目录下操作。每个小说是其下一个子文件夹（《故事状态.md》、《大纲.md》、章节目录等）。也可在本文本框直接填 vault 内路径（首尾斜杠自动去掉） |

| 注入整卷《卷摘要》 | 开关 | 开启后写作上下文额外包含当前卷完整《卷摘要》，跨卷缺口另以各前卷《卷摘要》填充（含触发 LLM 重建）；关闭＝严格只注入最近 N 章（默认关） |

- **《卷摘要》补充**：卷摘要以该卷已生成的章节摘要为输入整体重建、随更多摘要陆续生成而变全，其中任一变化即自动失效重算；开启注入时跨卷缺口由近及远填充。**每书覆盖**：在《故事状态.md》属性面板设 `include_volume_summary`（true/false）即为本书单独开关，优先于全局设置；删掉该属性即回落全局。
### 4.2 写作阶段模型配置（四标签页，v0.2.22+）

| 标签页 | 对应阶段与命令 |

| 策划方案生成 | 《策划指南.md》的 AI 生成（「策划指南生成·仅世界观」命令＋大纲流程前置链路自动生成） |
| 书籍大纲和卷级大纲生成 | 「生成书籍大纲」「从书级大纲生成卷」「自动生成卷大纲」 |
| 文章大纲生成 | 「从卷大纲生成章节」（按「第N章」标记确定性拆分，仅无标记时的 AI 拆分兜底走该阶段模型） |
| 编写文章 | 「创作章节」「连续编写」「续写当前章」「重写本章」「润色当前章」「去AI味」「修复章节编号引用」「错别字检测」「审阅本章」「分析人物与场景」 |

每个标签页内一个「模型配置」下拉框＋两个子标签：

- **模型配置下拉框**：选本阶段生成用哪份模型配置（列出全部已保存配置）；未指定时回落到「LLM 配置」中「模型配置」列表的第一个配置。
- **身份加强子标签**：本阶段的 AI 身份加强提示词，注入到系统提示词**末尾**。默认只读显示（留空显示「（留空=不注入）」）；点「编辑」切换为编辑框——「保存」写盘（Ctrl+Enter 同样保存）、「使用默认值」恢复该阶段内置的默认身份提示词。
- **引用文档子标签**：控制该阶段组装提示词时注入哪些文档，见 4.4。

### 4.3 LLM 配置（两标签页）

**tab 0「全局设置」**：

| 项 | 控件 | 用法与取值 |
| --- | --- | --- |
| 对话框使用的模型配置 | 下拉框 | LLM 对话窗口顶部下拉默认选中的模型；在这里改，已打开的对话框下拉同步跟随（反之在对话框切换也写回这里）。**只影响对话框自身**——写作命令按阶段映射独立选模型，不受此影响 |
| 写作系统提示词 system_prompt | 文本框 | 全局基础系统提示词：无编写类型格式块时使用；留空＝内置默认（对齐 CLI config.json 的 system_prompt） |
| 描述方式 desc_style | 下拉框 | normal / complete（对齐 CLI），默认 normal |

**tab 1「模型配置」**：多组 OpenAI 兼容端点（本地 Ollama/LM Studio/llama.cpp 或 DeepSeek/DashScope 等），每组含 base_url/api_key/模型名/temperature/max_tokens 等。列表页每份配置一行（名称＋模型名/服务地址摘要），**第一个配置是阶段映射与对话框的回落默认**；「＋ 新建配置」创建后直接跳进其详情页；点击任一行进入详情页，改完点「← 返回模型配置列表」回到列表。原「设为激活」按钮已移除——对话框用哪个模型由「全局设置」页的下拉框直接选定。数据存插件 data.json，api_key 仅发往你自己配置的端点。详情页字段：

| 字段/控件 | 用法与取值 |
| --- | --- |
| 名称 name | 配置显示名；改名自动同步全部引用（写作阶段映射、对话框）。空名/重名不保存（输入框回落原值） |
| 测试连接 | 对该配置执行 GET /models 连通性测试并弹通知（列出可用模型）——填好服务地址/API Key 后先点它验证 |
| 温度 temperature | 数值，如 0.8；留空＝不发送（跟随服务端） |
| 最大 token max_tokens | 数值，如 65535；留空＝不发送。注意：思考型模型思考与正文共享输出预算 |
| 服务地址 base_url | 如 http://localhost:8509 或 https://api.deepseek.com（已含 /vN 不重复拼接） |
| 模型 model_name | 模型名；本地服务可留空（用其已加载模型） |
| API Key api_key | 留空＝不发送鉴权头（本地服务通常不需要）。明文存于 data.json——同步/分享 vault 时注意不要泄露配置文件 |
| 推理强度 reasoning_effort | 下拉框：留空（不发送）/ none（关思考）/ low / medium / high / max。随每次请求发送（兼容端点支持时生效）；OpenAI o 系列原生支持 |
| 思考模式 thinking | 下拉框：留空（跟随服务端默认）/ on（开思考）/ off（关思考）。仅 DeepSeek 端点生效：off＝不思考，更快更省 token（deepseek-flash 默认开思考） |
| ↑ 上移 / 下移 ↓ | 调整列表顺序——第一个配置是阶段映射与对话框的回落默认 |
| 删除配置 | 被删配置若被写作阶段引用，自动清空该阶段引用（回落第一个配置） |

**思考型模型坑位**（Qwen3/DeepSeek-R 系列等）：思考与正文共享 max_tokens 输出预算，默认开思考时思考可能耗尽预算导致正文为空——本地端点在「推理强度 reasoning_effort」选 `none` 关闭思考（或调大 max_tokens）；DeepSeek 端点在「思考模式 thinking」选 `off`。两项均为下拉框（v0.2.21+，取值集合封闭、免手填出错），已填的非标存量值会动态并入选项并标「（存量值）」不会丢失。
### 4.4 写作阶段引用文档配置（v0.2.25+）

各阶段标签页的「引用文档」子标签控制**该阶段生成时注入哪些文档**——内置文档按阶段下拉勾选（清单随阶段不同：策划阶段默认＝书籍信息/张力规则/世界观/大事件列表，大纲与正文阶段如人物/场景/前卷大纲/前文大纲等），可修改、增删，并可**调整顺序**——每行显示序号，序号即装配顺序（排在前面的先组装进提示词），用 ↑/↓ 移动；也可点「添加 vault 文档…」从弹出选择器中搜索选取 vault 内任意 Markdown 文档（选中即添加，注入为【引用文档 · <路径>】块，追加到末尾＝最后组装，同样可调序）；「恢复默认清单」一键还原该阶段默认勾选。**三级写作指南（系统级/小说级/用户级 WRITING_GUIDE.md）为锁定行、恒排清单最上面、装配时恒为第一块**，恒定注入、不可取消（策划方案生成阶段同样锁定注入创作规范）。语义：**从未改过＝按默认清单注入**（老配置无需迁移）；**清空列表＝只注入锁定指南、不注入任何可选文档**。`审阅本章` 与对话命令按阶段 3（编写文章）配置框口径；**正文写作（阶段 3）有卷模式默认不注入全书大纲全文**——写作上下文只依赖本卷大纲与本章大纲（旧版曾注入【全书大纲】块，现已移除）；**平铺（无卷）模式例外**：没有卷大纲可依赖，书级《大纲.md》自动以【全书大纲】块注入（提示词措辞同步改为「全书大纲」口径）；「导出 AI 提示词」预览与运行时注入同口径。

### 4.5 技能文件（v0.3.0+）

技能＝写作技巧类短文档，存放在**工作目录下的 `SKILLS/` 文件夹**（如 `小说工作区/SKILLS/展示而非讲述.md`），平铺一层、只认 `.md`，你可以直接用 Obsidian 打开编辑。插件启动后会自动播种三个内置技巧技能（**展示而非讲述 / 对话技巧 / 悬念与伏笔**）——仅文件缺失才写入、绝不覆盖你的修改；也可在 SKILLS/ 下自建任意 `<技能名>.md`。技能**不自动生效**：在各阶段「引用文档」子标签点「添加技能…」按钮，弹窗按名称搜索选取 SKILLS/ 下的技能（已添加的不再列出），选中即添加为「🎯 技能 · <名称>」条目，同样可删除、调序。**注入位置分两档**：策划/大纲阶段（0–2）的技能按清单顺序注入上下文（【技能 · <名称>】块）；**「编写文章」阶段（3）的技能注入系统提示词**（对创作章节/连续编写/续写/重写/润色/去AI味/审阅等正文命令统一生效）。文件起始的 `# 技能名` 标题行注入时自动剥除，正文即技巧要点。LLM 对话窗口不注入技能。

### 4.6 关于

页面底部只读说明块：插件功能概览（建书/建章、打开文档、保存、字数统计）、数据存放约定（全部为 vault 内 MD 文档，运行态存于各书《故事状态.md》YAML 文件属性）、LLM 接口说明（OpenAI 兼容接口，可接 DeepSeek / DashScope / Ollama / LM Studio / llama.cpp 等）与 api_key 明文存放提醒。

卷实体目录内的模板文档存放于其 `文档/` 子目录、用裸基名（v0.2.22+）：`卷大纲.md` / `人物.md` / `人物关系.md` / `场景.md` / `时间线.md`（旧 `<卷名>-<基名>` 前缀名由回退读取兼容）；另有 `卷摘要.md` 为 AI 自动维护的卷摘要（非模板、建卷不播种）：设置「注入整卷《卷摘要》」开启且上下文组装需要时，以本卷各章摘要为输入整体重建落盘。

三层《时间线.md》为**手写参考资料**（不参与提示词注入）：书级「案头资料/」`时间线.md`、卷「文档/」`时间线.md`（旧前缀 `<卷名>-时间线.md` 由回退读取兼容）、章节目录 `NN-<标题>-时间线.md`（裸名亦可）——已列入各层默认文档模板清单，新建书/卷/章时随模板播种空文件，缺失时可经写字台「补全资料 / 补全卷文档 / 补全文档 / 新建文章…」等动作补齐，已有内容一律原样保留；由「时间线面板」把三层合并成一条时间轴只读展示。格式：每个标题块＝一条事件，标题＝时间点（支持 `年` / `年-月` / `年-月-日`，如 `-129-06-15`；负数/小数/科学计数也可），**标题深度即事件级别**（`#`=一级、`##`=二级、`###`=三级，可更深＝更细的子事件；面板按「父＝其前最近一条级别更小的条目」嵌套展示），块内 `- 人物：A、B` 字段行记涉及角色、`- 事件：<文字>` 记事件（简短，面板内联显示）、`- 描述：<文字>` 记详细描述（仅悬停 Tip 显示、不内联渲染；其后还可跟 ```text 围栏多行正文）；非时间点标题的块（含文档标题 `# 时间线`）整块忽略。详见「三、常驻面板 · 时间线面板」。

新建时缺失文档自动创建为模板；已存在则跳过不覆盖用户内容。**旧格式文档（裸名如 `章节.md`/`卷大纲.md`，或旧前缀如 `初见-章节.md`、`第01章-初见-大纲.md`）在切换书籍时会自动检测并提示批量更新**——确认后仅重命名文件——章节文档改为「NN-标题-后缀」格式、卷文档归一为 `文档/` 内裸基名（如 `卷大纲.md`），不改动内容。

## 六、常用标记速查

- **大纲详略**：[详] 重点展开 / [扩] 扩展细节 / [补] 补充小情节 / [略] 简略带过 / [跳] 可不写；[/] 或 [/详] 等结束作用域，可在同一行分段控制。
- **伏笔提取**：大纲中 [伏]...[/] 包裹的内容会被解析入全书 伏笔.md。
- **创作规范分类区块**：<!-- 写作指南分类:禁用词|故事风格|个人特色 --> ... <!-- /写作指南分类 -->；未包裹内容归「通用」。
