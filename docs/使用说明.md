# ArticleWriter 使用说明

> 本文档是插件**内置说明**，文件首行带版本戳（`<!-- articlewriter:usage-doc-version X.Y.Z -->` ＋一行可见版本提示）。插件**每次启动都会比对版本戳**：版本与当前插件不一致（升级后必然如此）、文件缺失/为空/无版本戳，就用新版内置文本**重写本文件并自动打开**；版本一致则不动。⚠️ 因此你在本文档里的修改会在升级时被覆盖——需要长期保留的个人笔记请另建文档。「生成使用说明」命令同口径：已是当前版本就跳过。

## 一、安装与快速上手

### 安装

#### 方式一：Obsidian 社区插件市场（推荐）

1. 打开 Obsidian → **设置 → 第三方插件**（首次使用需先关闭「安全模式」）→ 点「浏览」进入社区插件市场。
2. 搜索 **ArticleWriter** → 点「安装」→ 安装完成后点「启用」。
3. 左侧栏出现书本/消息/人物/历史四个图标即安装成功。
4. **更新**：社区插件由 Obsidian 自动检查更新（也可在 设置 → 第三方插件 里手动「检查更新」后更新 ArticleWriter），更新后建议重启 Obsidian 生效。**升级后首次启动会自动按新版重写工作目录里的《使用说明.md》并打开**（版本戳比对，见本页顶部提示），方便一眼看到本版变化。
5. **卸载**：先「停用」，再在插件条目处点「卸载」。你的小说文件都在 vault 普通目录里，不受影响。

#### 方式二：GitHub Releases 手动安装（备用／离线场景）

1. **下载三件套**：打开发布页 `https://github.com/gengbl/articlewriter-obsidian/releases`，在最新 Release 的 Assets 里下载 **`main.js`、`manifest.json`、`styles.css`** 三个文件（缺一不可：`manifest.json` 是插件元数据、`main.js` 是代码、`styles.css` 是界面样式）。
2. **放入插件目录**：在你的 vault 根目录下建目录 `.obsidian/plugins/articlewriter/`（`.obsidian` 是隐藏目录，文件管理器需开启显示隐藏文件；没有就手动创建），把三个文件放进去。放好后结构应为：
   ```
   <你的vault>/.obsidian/plugins/articlewriter/
   ├── main.js
   ├── manifest.json
   └── styles.css
   ```
3. **启用插件**：打开 Obsidian → 设置 → 第三方插件 → 社区插件列表会出现 **ArticleWriter** → 点「启用」。
4. **更新**：下载新版三件套直接覆盖同名文件，然后在 Obsidian 里重载插件（设置 → 第三方插件 → ArticleWriter 关再开，或重启 Obsidian）生效。手动安装后插件不再走社区市场的自动更新。

### 首次使用

1. **设置工作目录**：首次使用任何 ArticleWriter 命令会弹出文件夹选择器，从 vault 已有文件夹中选定一个作为工作目录（work_dir）。每本小说都是 work_dir 下的一个子文件夹；之后可随时用「选择工作目录」命令或设置页改换（切换后清空上次选书记忆）。确认后若该目录下还没有《使用说明.md》会自动创建并打开（插件每次启动按**版本戳**自检：缺失或版本与当前插件不符＝重建并打开，见本页顶部提示）。**v0.4.7+ 无书籍引导**：插件每次启动还检查一次「有没有书」——没有工作目录、或工作目录里一本书都没有（其下子文件夹都没有《故事状态.md》）时弹出引导面板：没目录＝带你选目录，有目录没书＝直接带你「创建新小说」（也可换工作目录／打开使用说明／不再弹出）。已经建好书就不再打扰；开关见设置页「无小说时弹出建书引导」。
2. **创建新小说**：输入标题 / 选择题材（下拉来自 `SKILLS/题材/`，默认四题材：玄幻仙侠、科幻、历史武侠、都市现实）/ 选编写类型（下拉来自 `SKILLS/编写类型/`），自动建 <书名>/ 目录与全套模板文档（故事状态.md、大纲.md、世界观.md、卷.md、伏笔.md、笔记.md 等）；已存在的文档跳过不覆盖。
3. **配置 LLM 模型**（必配才能用 AI 写作）：Obsidian 设置 → ArticleWriter，在预置的 local / deepseek / qwen-dashscope 三组模板中填 api_key 与模型名、「设为激活」，再用「LLM 连接测试」验证。只用文件管理功能可不配。
4. **开始写作**：在 大纲.md 写总纲要点 → 「新建章节」→ 打开该章 章节大纲.md 写细纲 → 「创作章节」按本卷大纲与本章大纲+指令流式生成正文并自动去AI味 → 「统计当前章节字数」「保存当前章节」。

### 手动分步写作流程（从零到成书走查）

不想跑全自动流水线、想逐步掌控时，按这个顺序走（每一步都可单独反复执行、人工检查后再进下一步）：

1. **建书**：「创建新小说」→ 输入标题/选择题材（`SKILLS/题材/` 下的技能名，默认玄幻仙侠/科幻/历史武侠/都市现实）/选编写类型（`SKILLS/编写类型/` 下的技能名）。
2. **写世界观**：「打开世界观」手写设定，或跑「生成世界观」（需先有一句话设定）。
3. **生成策划指南**：「策划指南」命令 AI 生成书级《策划指南.md》（十节规划约束；分卷模式会先问卷数量）。
4. **生成书级大纲**：「生成书籍大纲」——平铺模式问目标章数（产出恰好 N 个 `## 第N章` 标记；目标章数从《故事状态.md》`auto_book.chapters` 预填、改值写回）；分卷模式问卷数量（产出 `## 第X卷·卷名` 小节＋卷声明行）。
5. **落结构**：
   - 平铺：「书稿」小节标题右键「从书级大纲生成章节…」把书级大纲拆成章节；
   - 分卷：「从书级大纲生成卷」按卷声明逐卷建卷并生成卷大纲，再对各卷跑「从卷大纲生成章节」拆出章节。
6. **逐章写正文**：「创作章节」写单章（带预览确认），或「连续编写」从第一个没有正文的章起批量推进。
7. **打磨**：「续写当前章」「重写本章」「润色当前章」「去AI味」「错别字检测」「检测敏感词」「审阅本章」。写完后各平台红线词也可跑「全书敏感词汇总」出报告（见「二、命令一览」）。
8. **随时攒灵感**（穿插在任何阶段）：「灵感工具包」把零碎想法记进《案头资料/灵感/灵感.md》——一条灵感一个「## 灵感名 · 日期」块，可快速打开、跳到某条、改名、删除、在文末追加一个模板块填新想法；它不参与 AI 提示词注入，是留给自己以后翻的材料（见「二、命令一览 · 灵感工具包」）。

每一步的产物都是普通 Markdown 文档，可直接手动编辑后再继续下一步；AI 生成命令大多支持「已有内容跳过/覆盖」与增量续写，重复执行安全。

### 灵感工具包（案头资料/灵感/灵感.md，v0.4.3+）

一条命令管全书灵感：**快速打开灵感文件、跳到某条灵感、改名、快捷删除、快捷新增**。

| 入口 | 说明 |
| --- | --- |
| 灵感工具包 | 打开弹窗：顶部搜索框（按名字或正文过滤，**回车＝定位到当前结果第一条**）；每条灵感一行＝名字＋日期＋一行摘要＋「定位／改名／删除」按钮（点整行也是定位）；底部三个按钮＝**新增灵感**／**打开灵感文件**／**编辑灵感模板** |
| 写字台右键 | 「案头资料」小节标题行或组内空白右键 →「灵感工具包…」；「案头资料/灵感」文件夹行右键也有这一项（对哪本书的案头资料操作就是哪本书的灵感文件，不必先切当前书） |

- **文件位置**：该书的《案头资料/灵感/灵感.md》——**全部灵感攒在这一份文件里**，每条灵感是一个二级标题块：`## 雨夜追凶 · 2026-11-14`（标题＝灵感名 ＋ 新增当天的日期）。
- **新增灵感**：先问灵感名，**留空＝「未命名」＋今天日期**；插件在文档**末尾**追加一个灵感模板块，并把编辑器定位到刚追加的那一块——直接在编辑器里填，填完照常保存（不再弹确认框）。
- **模板可自定义**：正文模板＝系统技能 `SKILLS/灵感模板.md`（弹窗里点「编辑灵感模板」直接打开改）。模板里的小节就是新灵感的小节；`{{name}}`/`{{date}}`/`{{time}}` 会被替换成灵感名/日期。模板里**不要写 `#`、`##` 标题**（二级标题是灵感块的分界，插件会自动把它们降为 `###`）。
- **定位**＝在编辑器打开灵感文件并把该块滚到视口中央；**删除**先弹确认框（显示该块摘要），只移除这一块，其他灵感与文件本身保留，删完弹窗不关、可接着删下一条。
- **手工编辑完全允许**：自己往文件里写 `## 某条灵感`（日期可以省）也算一条灵感；插件每次改动前都会重新读盘、按标题找回你点的那一条，找不到就只提示、不动文件。

### 章节管理
| 命令 | 用法说明 |
| --- | --- |
| 新建章节 | 输入标题 → 建 第NN章-标题/ 目录及 6 份文档（正文 `NN-标题.md`、`NN-标题-大纲.md` 等，文件名前缀为纯数字章号）；编号在当前卷（无当前卷则「书稿」未归属域）容器内自动顺延，并设为当前章 |
| 插入章节 | 选参照章与「之前/之后」位置建新空章；参照章所在容器内 ≥插入位的各章编号整体 +1、文档引用与伏笔.md 同步重写，完成后聚焦新章 |
| 章节列表 | 扫描章节目录列出全部章节，选择后打开正文并切为当前章 |
| 下一章 / 上一章 | 按阅读序切换（书稿未归属章节在前、各卷按卷顺序、组内本地号升序）并打开正文；无当前章时 next→第一章、prev→最后一章；到边界提示不切 |
| 删除章节 | 移入回收站并清理元数据与归属引用；**被删号之后同容器仍有章节时自动补洞重新排号**（后续各章 -1、引用同步改写） |
| 重命名章节 | 改章名，同步目录名与文档内引用 |
| 重命名章节文件 | 重命名章节（与「重命名章节」同效）：选章 → 输入新标题 → 目录名改为 第NN章-新名 并同步文档内引用；命令名沿用旧措辞「将旧格式改为第NN章-章节名格式」 |
| 重排章节编号 | 每个容器（书稿未归属域/每卷）内部各自改为连续序号并改写交叉引用（手动兜底用；日常插删已自动维护连续性） |
| 打包章节合集 | 所选章节正文合一 MD：留空=当前章；`all`=全书；区间如 `3-7`/`3到7` 自动升序；列表如 `1、4、5`（逗号/顿号/空格分隔）；多卷同号裸号会先让你选卷。章标题行格式「## 第N章 章节名」（中文章节号），多章之间以 --- 分隔；无正文章跳过并在结果中列出。输出路径留空=`<书名>-第X章-合集.md`（多章 `-第X-Y章-合集.md`）、`.md` 结尾=指定文件名、否则视为目录（弹窗在输入框上方显示详细用法说明）。**选择跨容器时（如 all 全书、跨卷列表）合辑章号按阅读序 1..N 连续重编（空章不占号），避免多卷书出现重复的「第一章」；单卷/书根内的选择保持卷内本地章号不变** |
| 导出卷合集 | 某卷全部章节正文合一 MD（与打包同款格式）；默认存小说目录下 `<书名>-<卷名>-合集.md`，输出路径规则同上（弹窗在输入框上方显示详细用法说明）。**写字台卷节点右键为「导出…」**：只问一个范围输入框（不预填、留空/all=该卷全部章节，区间/列表按卷内本地号），不问输出路径、不支持自定义文件名——所选章节正文经书稿引擎合一 MD（文件首行带 `# 第N卷 · 卷名` 标题行），默认存 `<书名>-<卷名>-范围.md`（单章 `-第N章`、连续 `-第X-Y章`、离散 `-第1、4、5章`）。**正文开头若自带章节号行（如「第3章 标题」「第三章：标题」）会先被去掉，章节号只使用导出生成的** |
| 导出书稿 | 「书稿」小节标题右键：所选范围全部章节《章节.md》正文按阅读序合一 MD——留空/all/全部=整本、区间如 `3-7`、列表如 `1、4、5`（多卷可加卷名前缀限定，裸号跨容器时选所在卷）。**有卷模式每个卷组前带「# 第N卷 · 卷名」标题行（无章的空卷也照样输出其卷名）**（卷号按卷顺序），无卷模式平铺不带；章标题行同为「## 第N章 章节名」。**默认文件名按口径区分**：限定某卷=`<书名>-<卷名>-范围.md`（单章 `-第N章`、连续 `-第X-Y章`、离散 `-第1、4、5章`），整本/书根域=`<书名>-书稿.md`（重导覆盖同名文件），输出路径规则同打包。**正文开头自带的章节号行（「第N章 标题」等）会先被去掉，章节号只用代码生成的**。**整本/跨卷选择的章号按阅读序 1..N 连续重编（多卷书不再各出「第一章」；限定单卷则保持卷内本地号）**。两问弹窗均在输入框上方显示详细用法说明 |

### 卷 / 场景 / 人物 / 伏笔 / 世界观

| 连续编写 | 从阅读序中**第一个没有正文的章节**起逐章推进（不再看当前章——章数很多、当前章停在第 40 章时也从最前面的空缺开始；全部章节都有正文时直接提示无需连续编写）：先**收集待编写章节数组**（正文为空＋大纲非空才入队），再逐章走与「创作章节」**同一条编写管线**（`writeOneChapter` 共用：上下文装配→流式生成→摘要随写→字数/编号引用/敏感词提醒——敏感词提醒 v0.4.6+ 零 LLM 非阻断，只弹通知不动正文）+ **免确认自动保存**；已有正文的章节跳过继续；停在第一个没有大纲的章节。**去AI味时机（v0.4.3+）**：连续编写不在每章写完后立刻打回重写，而是只用禁用词表**本地检测**并把命中登记到书级《案头资料/AI味清单.md》（每章即时落盘，中途停止也留下待处理清单），**全部章节写完后统一改写**并回填状态（⏳ 待统一改写 / ✓ 已统一改写 / ✋ 未清洗），正文按清洗结果写回；单章命令（创作章节 / 续写 / 重写）仍是写完立即清洗。这样章与章之间只剩连续的写作请求，本地引擎的上下文复用不再被中间的清洗请求打断。**中途点「停止生成」也照样把已写完的章统一去AI味**（面板只是预览载体，清洗在后台完成，打不开也照洗；面板被关或打不开只是看不到过程），统一清洗途中再停止＝那一章标 ✋ 未清洗、其余仍留 ⏳ 待处理，可运行命令「补做去AI味」按《AI味清单.md》接着洗完（下一轮连续编写也会自动把未清洗的章并入本轮一起收尾）。面板每章完成行显示本章用时，结束弹汇总（写入章数/跳过章数/总字数/总用时/停止原因/AI 味统一改写统计＋清单文件路径），中断后重跑会从上次写完的章之后续起。也可写字台右键触发：卷节点右键＝限该卷内连续编写（从该卷第一个没有正文的章节起，停在卷末或第一个无大纲章）；「书稿」小节标题行右键＝全书语义（与命令面板同义） |
| 续写当前章 | 末尾衔接窗口继续写（窗口字数可在设置页「续写衔接窗口（字）」调整，默认 1000、可填 200–20000；长章建议 2000–3000，衔接更稳但输入更长）；本章无正文时回落为「创作章节」；继续推进大纲下一个情节要点、不提前收束本章，大纲含「章末钩子」时为其留出落点 |
| 重写本章 | 基于大纲与旧文整体重构，含前后章桥接；关键转折用动作/对话演出来，章末以情节自然终点收束（有大纲「章末钩子」才落钩子）；通顺与逻辑优先兜底（句子完整、行动有缘由、信息不断链） |
| 润色当前章 | 仅优化文字表达不改情节 |
| 去AI味 | 含 AI 常用词的句子打回 LLM 重写并原位替换 |
| 补做去AI味 | 按《案头资料/AI味清单.md》把没洗完的章接着清洗：连续编写中途停止、清洗中途被停止或面板被关闭时，未清洗的章留在清单里（⏳ 待统一改写／✋ 未清洗），运行本命令逐章回读正文打回重写并写回，清单同步回填状态；已清洗（✓）的章不重复改，可反复运行直到洗完 |
| 修复章节编号引用 | **手动检测并修改**正文中的「第N章」类章节编号元引用（v0.2.21+；v0.2.x+ 输入语义改）：弹窗输入章节号——**留空＝全书所有章节都检测修复**（按阅读序逐章处理）、**填数字＝只修指定章节**；每个目标章：代码确定性定位命中句 → LLM 逐句改写为具体内容指代 → 代码原位替换后自动保存（无预览确认）；无正文/无引用的章跳过、未成功改写的句子保留原文，结束弹汇总通知（改写保存章数／跳过章数／共改写句数） |
| 错别字检测 | LLM 全文扫描当前章错字，每个错字在正文中加下划线标记、悬停显示建议改正；先预览「共发现 N 处错别字」清单＋带标记全文，确认后保存。重跑幂等（检测前自动剥离既有标记），修完错字可手动删标记或重跑检测 |
| 检测敏感词 | **零 LLM**（v0.4.6+）：按词表《SKILLS/敏感词清单.md》逐字扫描当前章（留空＝当前章，填章号＝指定章），命中处正文包**底色标记**（悬停显示「分类：说明」）并自动保存、打开该章；通知列「分类×次数」分布与前 5 处命中（行号＋行片段）。词表为空时提示去编辑词表文件；也可在写字台章节行右键直接检测指定章。与错别字下划线、AI 标红三种标记共存，重跑幂等 |
| 全书敏感词汇总 | **零 LLM**（v0.4.6+）：逐章扫描全书正文（**不落标记**，只出报告），结果按「每扫一次一节」带时间戳追加到《案头资料/敏感词报告.md》——扫描章数、合计命中、有命中章的分类分布表，天然形成当日与历史汇总；收尾通知汇总并打开报告 |
| 审阅本章 | 全局视角查逻辑/连贯性问题出报告，可另存 审阅笔记.md |
| LLM 连接测试 | GET /models 验证激活配置 |

**正文「第N章」章节编号引用禁令（v0.2.21+）**：创作章节 / 连续编写 / 续写当前章 / 重写本章四个命令的提示词均禁止 LLM 在正文中输出「第N章」这类章节编号的元引用——提及前文事件或伏笔时改用具体内容（人物、事件）指代，章节编号只允许出现在标题行。插件另对新生成内容做确定性检测，命中即弹非阻断通知列出前 5 处（行号＋片段）供人工检查（标题行豁免；追加/续写模式不重查既有正文）。已有正文需要清理时，手动执行「修复章节编号引用」命令：弹窗输入章节号——留空＝全书所有章节都检测修复（按阅读序逐章）、填数字＝只修指定章节；每个目标章由代码定位含引用的句子（至多 10 句），LLM 逐句改写后原位替换；**全部章处理完先弹预览窗逐章列出「原句 → 改写句」对照，点「确认保存」才批量落盘，取消/Esc＝全部不落盘、正文零改动**（v0.4.6+，此前为直接自动保存无预览），结束弹汇总通知。

### 书籍 Skill（v0.3.4+，本书专用写作技巧）

| 新建 Skill… | **创建一条独立路径（创建与配置分开）**：弹窗＝名称＋保存位置下拉（系统级 SKILLS/ ｜ 书籍级 案头资料/Skill/——**v0.4.7+ 两级说明的小字不再常驻在标签下方，鼠标悬停「保存位置」标签才显示**）＋内容文本域——**内容预填格式模板**（`# 技能名`＋一行概述＋「- 」要点列表），你按需填充后保存。保存只写入文件并弹提示（含写入路径），**不会进入任何阶段配置**；想配置时机自己再运行「书籍 Skill 阶段配置…」。保存位置选书籍级但当前没有小说会给出明确提示。 |

技能文件就是普通 Markdown：**编辑与删除直接在 Obsidian 里对 `案头资料/Skill/<技能名>.md` 操作**（改内容即时生效；删文件后 故事状态.md 里的残留引用会自动忽略）。写字台「案头资料」节右键还提供「新建 Skill…」与「书籍 Skill 阶段配置…」快捷入口（该节下的 **Skill** 子节点在 `案头资料/Skill/` 文件夹出现后自动显示）。**生效方式**：所选技能注入该阶段提示词，位置恒排在系统技能之后（策划/大纲阶段进上下文【技能 · 名称】块；编写文章阶段进系统提示词）；LLM 对话窗口不注入技能。「全自动建书配置」（《故事状态.md》的 `auto_book` 块，见「全自动写书」一节）是另一套功能，与此无关。

### 全自动写书（按书配置）
把六个生成命令串成一条**无人参与**的流水线：一句话设定 → 整套书。驱动者是插件本身（固定顺序、固定参数），AI 只负责各阶段内的文本生成。**配置保存在当前书《故事状态.md》里、没有单独配置文件**：执行范围与规模参数存 `auto_book` 块，规模模式复用顶层 `use_volumes`（分卷/平铺），一句话设定复用顶层 `one_line`。两条命令分工——「配置全自动建书…」把参数写进状态文档，「全自动写书」按配置跑流水线。流水线**可从任意节点开始、到任意节点停止**（停止节点也会执行；缺省＝跑到「连续编写正文」末尾），起止节点固化在 `auto_book` 的 `start`/`end`、也可在运行确认弹窗里临时调整。

| 命令 | 说明 |
| --- | --- |
| 生成世界观 | 以一句话设定为种子 AI 流式生成书级《案头资料/世界观.md》（全自动写书流水线首阶段，亦可单独运行）。手动运行一律弹窗确认一句话设定：故事状态里已有一句话则预填进弹窗供修改、没有则空框（输入框为占满弹窗宽度的 5 行文本框，回车换行、点「确定」或 Ctrl/Cmd+回车开始生成；修改后的值会存回故事状态）。流水线运行时免交互直接取配置参数（one_line）。固定小节结构（「世界基本规则」「世界观红线」必含），只写设定不写情节；上下文＝书籍信息＋阶段 0 引用清单里的条目（默认含技能「张力工具箱」「世界观生成框架」，按该配置框过滤注入）。已有非空世界观**直接覆盖、不确认**。 |
| 配置全自动建书… | 向导窗口配置当前书的全自动建书参数并**保存进《故事状态.md》**：起始节点、停止节点（下拉多一项「跑到末尾」＝不写 `end` 键）、一句话设定（写顶层 `one_line`；仅当起始节点为「生成世界观」时显示，其它起始节点自动隐藏；留空＝保持已有 `one_line` 不动）、规模模式（平铺/分卷，所选值写回顶层 `use_volumes` 并决定全书按哪种方式组织）、规模参数（按模式互斥显示：平铺＝仅全书总章数可编辑；分卷＝仅卷数＋各卷章数，全书总章数整行隐藏、推算值显示在各卷章数说明行；状态文档里只写所选模式的参数，切换模式时另一模式的旧键自动清掉）、覆盖开关。点「保存配置」即写入状态文档。用前须已创建好书籍（配置不含建书）。 |
| 全自动写书 | 一句话→整套书六阶段流水线的**唯一入口**：**生成世界观 → 生成策划指南 → 生成书级大纲 → 建卷并生成卷大纲 → 生成章节大纲 → 连续编写正文**。按当前书《故事状态.md》配置执行（`auto_book` 块＋`use_volumes`＋`one_line`）。**参数齐全＝弹「全自动写书 — <书名>」执行范围确认窗口**：预填配置里的起始/停止节点，可临时调整后点「开始」才开跑（取消＝什么都不做）；缺参数会列出缺什么（按模式与起始节点判定：一句话设定/卷数/各卷章数/全书总章数），并把已有配置预填进补填弹窗（起始节点/停止节点/一句话/规模参数/覆盖），补填后开跑、**补填结果顺带保存进《故事状态.md》**。**启动前预检**：按起始阶段所需的前置文件查盘（如从「生成章节大纲」起跑要求卷与卷大纲已存在），缺什么列出什么并拒绝启动——不生成任何内容。运行中所有弹窗询问自动按流水线参数回答（章数/卷数/覆盖确认等），「生成过程」面板自动保存。前三个阶段（世界观/策划指南/书级大纲）已有产物且未开「覆盖」开关则整阶段跳过；后三个阶段命令本身增量、只补缺失。已在运行时重复启动会被拒（先停止再启）。停止节点排在起始节点之前＝执行范围为空，运行时会拒绝启动。旧版「案头资料/」建书技能文件（frontmatter 带 `auto_book: true`）会在运行本命令或「配置全自动建书…」时自动迁移进《故事状态.md》并删除文件。 |
| 停止全自动写书 | 中断当前生成并停止后续阶段。也可在「生成过程」面板上直接点「停止生成」（按钮固定在面板最底部，不随正文滚动）——流水线在阶段边界检测到即停（v0.3.0+ 起 Esc 不再中断生成；v0.4.x+ 起在面板内按 Esc 什么都不做，也不会把编辑器跳到其它文档）。**阶段之间**（无流式生成时）关闭面板不影响流水线继续。 |
**注意区分**：「全自动建书配置」（《故事状态.md》里的 `auto_book` 块，驱动全自动写书流水线）与「写作技巧技能」（插件数据目录 SKILLS/ 或书内 `案头资料/Skill/` 下、注入 AI 提示词的技巧文档，见「参考文档与技能」设置与「书籍级 Skill」）是两套东西，用途与存放位置都不同。

### 全自动写书：逐步操作指南

**前置条件**：① 已用「创建新小说」建好书籍目录（配置不负责建书）；② 已在设置页配好并激活 LLM 配置（建议先跑「LLM 连接测试」）；③ 已把该书设为当前小说（「切换当前小说」或写字台下拉选书）。

**第 1 步 · 配置参数**：命令面板运行「配置全自动建书…」，向导窗口逐字段填写：

| 字段 | 怎么填 |
| --- | --- |
| 起始节点 | 六选一：生成世界观 / 生成策划指南 / 生成书级大纲 / 建卷并生成卷大纲 / 生成章节大纲 / 连续编写正文。从零开始选「生成世界观」；书已有部分产物时选第一个还没做的节点 |
| 停止节点 | 同样六选一＋「跑到末尾」：流水线执行到该节点（**含**）为止；选「跑到末尾」＝一直执行到「连续编写正文」。停止节点排在起始节点之前会拒绝提交 |
| 一句话设定 | 保存到《故事状态.md》顶层 `one_line`；**仅当起始节点为「生成世界观」时显示**（起跑点不含世界观时该行自动隐藏、也不参与必填）；标签自占一行、输入框独占整行宽度（会预填故事状态里已有的一句话，留空＝保持原值不动） |
| 规模模式 | 平铺（无卷）或 分卷；默认跟随当前书籍模式；**保存时写回顶层 `use_volumes`**（会实际改变全书组织模式） |
| 全书总章数 | 仅平铺模式显示：可编辑正整数，全书恰好规划这么多章（分卷模式该行整行隐藏） |
| 卷数 / 各卷章数 | 仅分卷模式显示：卷数为正整数；各卷章数填一个整数＝所有卷同章数，或按卷逐个填（逗号/顿号/空格分隔）；下方说明行实时显示推算的全书总章数（＝卷数×单值或逐项求和） |
| 覆盖已有产物 | 开＝世界观/策划指南/书级大纲即使已有内容也重新生成；关＝已有即跳过该阶段 |

点「保存配置」写入《故事状态.md》的 `auto_book` 块（模式切换时另一模式的旧参数键自动清掉）。

**第 2 步 · 运行**：命令面板运行「全自动写书」。参数齐全＝弹「全自动写书 — <书名>」确认窗口：起始/停止节点两个下拉已预填 `auto_book` 里的 `start`/`end`（可临时调整，比如这次只想试跑到「生成书级大纲」），点「开始」才真正开跑，取消／Esc＝什么都不做；缺参数会弹窗列出缺什么、已有配置预填进补填弹窗，补填后开跑，补填结果顺带保存进《故事状态.md》。还没配置过（`auto_book` 缺失）也照样能跑：直接弹补填窗口逐项填参数。

**第 3 步 · 预检（自动）**：启动前按起始节点查盘，缺前置文件会列出缺什么并拒绝启动（不生成任何内容）。各起始节点要求：

| 起始节点 | 盘上必须已有 |
| --- | --- |
| 生成世界观 | 无（只需一句话设定） |
| 生成策划指南 | 案头资料/世界观.md（非空） |
| 生成书级大纲 | 案头资料/世界观.md（非空） |
| 建卷并生成卷大纲 | 世界观.md ＋ 书级《大纲.md》（非空，分卷模式还需含卷声明行） |
| 生成章节大纲 | 世界观.md ＋ 分卷：各卷《卷大纲.md》含「第N章」章条目／平铺：书级《大纲.md》含章标记 |
| 连续编写正文 | 世界观.md ＋ 各章《章节大纲.md》（非空） |

**第 4 步 · 监控与停止**：运行中「生成过程」面板实时流式预览每个阶段，所有弹窗询问自动按配置参数回答、产物自动保存。想中途停：命令面板「停止全自动写书」或面板上点「停止生成」——在阶段边界生效，已落盘内容保留（v0.3.0+ 起 Esc 不再中断生成；阶段之间关面板不影响流水线继续）。已在运行时重复启动会被拒，先停止再启。

**第 5 步 · 重复跑＝增量补齐**：跑一半中断（停止/报错/断连）后，直接再运行「全自动写书」即可续起——前三个阶段（世界观/策划指南/书级大纲）已有产物且未开「覆盖」则整阶段跳过；后三个阶段本身增量，只补缺失的卷/章大纲/正文。

**手写配置**（直接编辑《故事状态.md》顶部的文件属性，插件读取时自动清洗、非法项忽略；正常情况用「配置全自动建书…」生成即可）：

```yaml
use_volumes: true
one_line: 一个能看见别人死期的少年，发现自己每次说出死期都会提前应验
auto_book:
  start: worldview
  end: chapter-outlines
  volumes: 3
  chapter_counts:
    - 10
    - 12
    - 12
  overwrite: false
```

- `start` 取值＝六个起始节点 id：`worldview` / `planning` / `book-outline` / `volumes` / `chapter-outlines` / `bodies`
- `end` 停止节点（**含**该节点）：取值同 `start` 六个 id；不写＝一直执行到「连续编写正文」末尾；写在 `start` 之前＝执行范围为空，运行时拒绝启动
- 规模模式看**顶层** `use_volumes`（true＝分卷、false＝平铺，它同时决定全书组织方式，不是 `auto_book` 内的键）；平铺在 `auto_book` 里写 `chapters: 30`；分卷写 `volumes` ＋ `chapter_counts`（列表逐项，或单个整数＝各卷同章数）
- `overwrite: true/false`；一句话设定用**顶层** `one_line`（不在 `auto_book` 里）
- 《故事状态.md》里还有一个插件自维护的内部字段 **`outline_split`**（「从大纲生成章节」的中断续跑进度，见上文该命令条目）——运行时自动写入、完成后自动清除，无需也不应手动编辑
- **v0.4.6+ 起规模三字段与手动命令双向同步**（不再只服务全自动写书）：`chapters`＝「生成书籍大纲」平铺章数弹窗与「AI 拆分书级大纲」的预填源＋写回目标；`volumes`＝「生成书籍大纲 · 卷数量」「策划指南 · 卷数量」的预填回落（磁盘已有卷数优先）＋写回目标；`chapter_counts`＝「从书级大纲生成卷」/「自动生成卷大纲」各卷章数弹窗的预填源＋写回目标（按卷阅读序逐项对应，单卷弹窗缺位取末值）。同值不写盘、弹窗取消不写、全自动流水线运行中不重复写——手动定过的规模参数，全自动写书直接沿用

## 四、设置项（Obsidian 设置 → ArticleWriter）

打开 Obsidian 设置 → 第三方插件 → ArticleWriter 进入设置页。页面自上而下四个区块：**顶层设置**（工作目录与写作上下文）、**写作阶段模型配置**（五标签页）、**LLM 配置**（两标签页）、**关于**。所有项**改动即落盘**（存插件 data.json），没有保存按钮；填错随时改回。

- **《卷摘要》补充**：卷摘要以该卷已生成的章节摘要为输入整体重建、随更多摘要陆续生成而变全，其中任一变化即自动失效重算；开启注入时跨卷缺口由近及远填充。**每书覆盖**：在《故事状态.md》属性面板设 `include_volume_summary`（true/false）即为本书单独开关，优先于全局设置；删掉该属性即回落全局。
- **大纲阶段抽人物/关系开关（v0.4.3+）**：在《故事状态.md》属性面板设 `ai_outline_cast: false` 可对本书关闭「生成卷大纲 / 从大纲生成章节」时的随手人物/关系抽取与分层写盘（删掉该属性即回落默认＝开）；`ai_expand_chapter_outline: false` 则连章大纲 AI 扩展一起关掉（此时也不抽人物/关系）。

**思考型模型坑位**（Qwen3/DeepSeek-R 系列等）：思考与正文共享 max_tokens 输出预算，默认开思考时思考可能耗尽预算导致正文为空——本地端点在「推理强度 reasoning_effort」选 `none` 关闭思考（或调大 max_tokens）；DeepSeek 端点在「思考模式 thinking」选 `off`。两项均为下拉框（v0.2.21+，取值集合封闭、免手填出错），已填的非标存量值会动态并入选项并标「（存量值）」不会丢失。
**本地端点的前缀缓存（v0.4.3+）**：插件按「共享上下文在前 → 本轮易变段在后」装配提示词，并在稳定段末尾钉一个检查点（`strata_prefix`），让同一本书连续生成（连写下一章、逐章大纲、逐章人物分析…）复用整段书籍级上下文，服务端不必每步重读。走本地 Strata serve / llama.cpp 兼容端点时，生成面板的「完成」状态行与自动保存行会附一行读数：**前缀缓存复用 x/y tokens（pct%）**（云端端点不返回该字段，则没有这段）。核对口径：同一次运行的第 2 步起 pct 应接近 100%；**长期 0% 说明相邻请求没有公共前缀**（多半是上下文注入清单每步都在变、或该命令本就单发），而不是服务端坏了。另外**引擎重启（换模型/重载）会清空 KV**，重启后第一个请求必然 0%，属正常。还有第三种常见原因：本地引擎为「下一条请求」把上一段对话的 K/V 暂存到内存的额度有限（额度不足时日志会打印 skip parking），**同一个引擎实例上同时跑着别的大会话（例如编程 agent）就会把写作请求的缓存挤掉**——这时 reused 也会是 0；想要稳定的复用，可给写书单开一个模型实例。**v0.4.3+ 起「连续编写」把去AI味挪到整轮之后**：连续编写每写完一章只用禁用词表**本地检测**并把命中登记到书级《案头资料/AI味清单.md》，**全部章节写完后统一改写**并回填状态——章与章之间只剩连续的写作请求，复用不再被中间的清洗请求打断（清单里能看到 ⏳ 待统一改写 / ✓ 已统一改写 / ✋ 未清洗；中途停止的章可用命令「补做去AI味」按清单接着洗）。单章命令（创作章节 / 续写当前章 / 重写本章）仍是写完立即清洗，此时清洗请求会把本章的写作上下文一并带上（仅本地回环端点，云端为省输入 token 仍不带），使「生成 → 清洗」共用同一段前缀；代价是本地清洗请求变长（复用时几乎不增加 prefill）。**v0.4.3+ 起「纠错重试」也顺着缓存走**：输出格式不合规（编写类型不符、剧本缺场景标题、时间线标题块不对）或不是合法 JSON 时的重试，不再把纠错说明拼回原提示词、也不换个开头重发，而是把「上一版输出」＋「纠错要求」作为新增的两轮追加——上一轮已经读过的书籍上下文与正文直接复用（本地端点实测重试段由 ~1.5s 降到 ~0.3s）。你在面板上看到的仍是清屏后重新流式，行为与文案不变。

### 4.4 写作阶段引用文档配置（v0.2.25+）

各阶段标签页的「引用文档」子标签控制**该阶段生成时注入哪些文档**——内置文档按阶段下拉勾选（清单随阶段不同：五个阶段默认各含本阶段**内置技能「身份加强·〈阶段名〉」**（v0.4.3+ 起进默认清单；旧配置里已保存过清单的阶段不变，可在清单里「添加技能…」补上）；世界观生成阶段默认＝书籍信息/身份加强/技能「张力工具箱」「世界观生成框架」（v0.3.7+/v0.4.3+），策划阶段默认＝书籍信息/身份加强/技能「张力工具箱」/世界观/时间线，大纲与正文阶段如人物/场景/前卷大纲/前文大纲等），可修改、增删，并可**调整顺序**——每行显示序号，序号即装配顺序（排在前面的先组装进提示词）；v0.4.3+ 支持**鼠标拖拽行**直接换位（拖到目标行上半＝插到它前面、下半＝插到它后面，行上/下缘会显示插入线），触屏端用 ↑/↓ 按钮；也可点「添加 vault 文档…」从弹出选择器中搜索选取 vault 内任意 Markdown 文档（选中即添加，注入为【引用文档 · <路径>】块，追加到末尾＝最后组装，同样可调序）；「恢复默认清单」一键还原该阶段默认勾选。语义：**从未改过＝按默认清单注入**（老配置无需迁移）；**清空列表＝不注入任何引用文档**（旧「三级写作指南锁定行」已随 v0.3.5 写作指南体系废弃，清单中不再有锁定项）。`审阅本章` 与对话命令按阶段 4（编写文章）配置框口径；**正文写作（阶段 4）有卷模式默认不注入全书大纲全文**——旧版曾注入【全书大纲】块，现已移除；**平铺（无卷）模式例外**：没有卷大纲可依赖，书级《大纲.md》自动以【全书大纲】块注入（提示词措辞同步改为「全书大纲」口径）。**v0.4.3+ 大纲只给节选**：无论卷模式还是平铺模式，阶段 4 的大纲块都按「前 prevN 章 / 后 nextN 章」窗口取当前章前后若干章的大纲（含卷设计等前言块、保留 `## 第N章` 标记行），并在块首注明节选范围——不再注入整份大纲；窗口覆盖全书或章号不可定位时回退整份。「导出 AI 提示词」预览与运行时注入同口径。

### 4.5 技能文件（v0.3.0+）

技能＝写作技巧类短文档，存放在**工作目录下的 `SKILLS/` 文件夹**（如 `小说工作区/SKILLS/展示而非讲述.md`），可直接用 Obsidian 打开编辑。**v0.4.3+ 起新增两个自动加载子目录**：`SKILLS/题材/<题材名>.md`（与《故事状态.md》`genre` 对应）与 `SKILLS/编写类型/<编写类型名>.md`（与 `writing_style` 对应）——正文写作时按这两个字段自动注入对应技能，不需要在引用文档清单里手动添加；新建/修改小说信息时，两个下拉也分别读取这两个目录。其余技能仍在 SKILLS/ 平铺一层、只认 `.md`；设置页「添加技能…」弹窗按文件夹层次递归展示全部技能，选中后按相对路径（如 `题材/玄幻仙侠`）保存并正确加载。

**v0.4.3+ 张力规则并入张力工具箱**：情节张力/节奏手法只剩一份载体——系统技能 `SKILLS/张力工具箱.md`（内置合并版＝A 赌注升级 / B 时间压力 / C 盟友变数 / D 两难选择 / E 悬念反转 / F 章末钩子 / G 反派塑造 / H 节奏控制 ＋ 用法建议）。变化四点：① 每书一份的《案头资料/张力规则.md》**不再播种、不再自动注入**——旧文件原样留在案头资料里（想按书用回它，在该阶段清单里「添加 vault 文档…」选它即可），建书与写字台「补全资料」的资料清单由十件套变九件套；② 设置页「引用文档」的内置下拉里不再有「张力规则」这一项；③ 各阶段默认清单改用技能条目「张力工具箱」（世界观生成／策划方案／书籍与卷级大纲／文章大纲四阶段默认注入，编写文章阶段仍默认不注入），**你已保存过的旧清单会在启动时自动改写**——原「张力规则」条目原位换成「张力工具箱」（位置不变，若该阶段本来也加了这条则合并成一条）；④ 你已有的 `SKILLS/张力工具箱.md` 若还没有「H. 节奏控制」段，启动时会在文末自动补上内置的「H. 节奏控制 ＋ 用法建议」两段，你已改写的正文一律不动。生成时间线（策划指南前置自动生成）的固定上下文里的张力块同样换成这份技能。

**打字（码字）统计（v0.4.5+，无面板无命令的后台功能）**：插件运行期间自动记录你的键入行为，按**一段＝设置项「码字记录段长」（分钟，默认 10）**切段（段边界按整点对齐：10→:00/:10/:20…；改段长从下一段起生效，且**新段起点不会回溯到刚落盘那段的末时刻之前**——否则两段区间重叠、同一段时间被两段各算一次活跃时长）为当前小说追加一行到该书《案头资料/码字记录.md》，五列＝**日期｜时间段（HH:MM–HH:MM）｜净增字数｜停顿｜码字速度**（v0.4.5+ 起第三列叫「净增字数」；旧文件里仍是「有效字数」字样也无妨，读回按列位置认、不看列名）：
- **净增字数**＝段内编辑器改动的**新增非空白字符 − 删除非空白字符**（下限 0，空格换行不计）：**删除不算码字**，而且会把先前敲进去的字抵掉——写 100 字又删掉 80 字只记 20 字。**纯删除**（一次改动只删没写）不算一次键入事件：不开段、不进停顿统计、不影响活跃时长。
- **停顿**＝段内**三段空档按同一口径累加**：① 段首空档（段起→第一次键入）、② 相邻两次键入间隔、③ 段尾（最后键入→段末）——各段只把**超过 30 秒的超出部分**计入（前 30 秒视作边想边写）。段首空档也计入是本轮修正：段起点是整点网格、不是你开始敲字的时刻，以前那段发呆既不算停顿、又留在「跨度 − 停顿」里被算成码字时长（每段最多虚增一个段长）。
- **码字速度**＝净增字数 ÷（段长 − 停顿）外推成「N 字/小时」，无字数或活跃时长归零显示「—」。
- **不算打字的情形**：粘贴或程序化写入（单次新增超过 300 个非空白字符，含 AI 生成落盘）；**程序化写盘的编辑器回声（v0.4.6+：插件自己写盘（AI 落盘、错别字标记、面板写回等）后 0.5 秒内编辑器出现同样的改动＝系统回声，只刷新比对基线、不计字）**；一次性删掉超过 300 个非空白字符的整块剪贴同样不计；文件第一次被看见只立比对基线（打开整章不会按全文计字）；当前小说目录以外的 md（`SKILLS/`、别的书）。**只有含至少一次有效键入的段才写行**，纯空闲时段（整段没有一次键入）不产生记录；**写了又全删光的段（净增 0）仍写一行**——字数记 0、速度显示「—」，这样该段的时长不会在落盘那一刻从「本次时长／写作总时长」里凭空消失（攒段期间面板算着、落盘后不算＝读数往回跳）。插件重载/退出时刻尚未攒满一段的缓冲直接丢弃。文件可自由查看编辑，追加永远写在表尾；表头被删也能重建。
- **写字台「码字状态」Tab（v0.4.5+）**：**本次写作的起点＝本次内的第一次有效键入**，不是写字台打开的时刻——Obsidian 一启动就把写字台打开，若「打开即计时」会把挂机时间灌进读数。所以启动后不动笔时该页显示「**本次未开始**」，敲下第一个字即开始计时。**结束本次**的三个动作：写字台打开/重开、切书、**停笔超过一个「码字记录段长」**（默认 10 分钟）；结束后再敲字自动重开一次。该页给出「本次开始／本次码字／本次时长／总时长／码字速度／写作总时长」：**本次码字**与各项字数一律按上面的**净增**口径；结束本次时进行中的那段**先结算进《码字记录.md》**、不带进下一次本次；本次各项只算**起点之后**的部分（段起点按整点网格对齐、可能早于本次开始，故活跃时长按起点夹取，「本次时长」不会超过墙钟「总时长」）；**本次时长**＝本次各段（跨度 − 停顿）之和＝真正在敲字的时间；**总时长**＝此刻 − 本次开始；**码字速度**同时给本次平均值与本次最近一个已完成段的值；**写作总时长**＝本书《码字记录.md》全部段的（跨度 − 停顿）之和＋当前未落盘段（＝本书口径的累计敲字时间，重开 Obsidian 后依然连续，因为它读的就是这份文件）；该行括注里的**本书累计字数**与之同口径，**也含尚未落盘的当前段**（不会每落一盘才跳一格）。进行中那段按其**开窗时的段长**核算，改过段长也不会让读数当场失真。该页每 10 秒刷新，页尾「段长 N 分钟」标记可点＝打开《码字记录.md》。

新建时缺失文档自动创建为模板；已存在则跳过不覆盖用户内容。**旧格式文档（裸名如 `章节.md`/`卷大纲.md`，或旧前缀如 `初见-章节.md`、`第01章-初见-大纲.md`）在切换书籍时会自动检测并提示批量更新**——确认后仅重命名文件——章节文档改为「NN-标题-后缀」格式、卷文档归一为 `文档/` 内裸基名（如 `卷大纲.md`），不改动内容。

## 六、常用标记速查

- **大纲详略**：[详] 重点展开 / [扩] 扩展细节 / [补] 补充小情节 / [略] 简略带过 / [跳] 可不写；[/] 或 [/详] 等结束作用域，可在同一行分段控制。
- **伏笔提取**：大纲中 [伏]...[/] 包裹的内容会被解析入全书 伏笔.md。
