# L2 · 写字台（StatusView）

## 模块概要

写字台是常驻 ItemView（面板显示名 getDisplayText="写字台"，命令/ribbon 文案同用此名；可停靠任意区域、重载保留位置）。渲染陷阱见 [l3-view-rendering.md](./l3-view-rendering.md)「常驻 ItemView 渲染陷阱」。

- **布局自上而下**：工作目录行（标签 + 路径 + 「刷新」按钮，行下有细分隔横线）→「小说状态」区（仅展示当前激活书概要：书名行＝名称左对齐 + 更新时间右对齐、题材/编写类型、`N章·第X章·总字数Y字`）→「书籍列表（n）」分组（分组标题行右侧下拉框选书；组内只渲染激活书的「全局文档」「章节」两个小节）。头部固定不随内容滚走，树主体独立滚动。
- **下拉框选书**：选择即激活对应小说（同 statusSwitchStory 语义）、已选中项再选不重复触发；分组标题行右键＝新建小说…/[有卷模式]新建卷…｜改名…｜删除当前小说（删书唯一出现处——改名同步改状态文档 title + 顶层目录 + 全书 MD 文档内旧书名，删除整目录入回收站并清 lastStory）。
- **树操作约定**：点章节行/箭头只展开或折叠本章文件列表、绝不激活；**行尾 Radio 是激活章节的唯一入口**（写回 current_chapter 并同步所属卷，书内同名互斥）；点文件行在编辑器打开。开合是纯展示态（本地重渲染、绝不读盘），折叠态仅会话内保持不落盘。
- **右键菜单按点击位置精确分配**（案头资料组/书稿组/卷名节点/章节名行/引言块/文件行各有其入口），**删除类项仅出现在作用对象自身的菜单上**（danger 红字、只作用于被点中条目）；空白处兜底为最小菜单。
- **新建文档流程**：统一单弹窗（全宽输入框 + 可点选标准模板行 + 「确定」CTA 置于弹窗最底部）；名称与已存在标准文档一致→确认后以模板空内容覆盖；不存在→直接按模板创建；自定义名净化后建空 .md。
- **导出书稿**：问范围（留空/all＝整本，或限定某卷）+ 输出路径 → packStory 装配《章节.md》正文（有卷模式每卷组前贴「# 第N卷 · 卷名」H1 行、无章空卷也出卷名行）；默认文件名：限定某卷＝<书名>-<卷名>-范围.md、整本＝<书名>-书稿.md；重导覆盖。
- **字数展示一律实时统计**（countWords，与 count-current/count-all 同口径），不读状态文档里可能过期的 words/total_words 字段。
- **写作实时刷新**：main.ts 订阅 vault md 文件事件（modify/create/delete/rename，按 workDir 过滤）→ 防抖调各打开面板 refresh()（章节字数随编辑器落盘自动跟进）。
- **引言节点**：书稿体内恒置顶（先于卷/平铺章渲染）；尚无引言→提示行（书稿标题右键「新建引言…」创建）；存在→可折叠块「引言（N）」。
- **文件行着色口径**：未命中参与写作提示词的标准模板集合的文件着主题强调色 + title「不参与写作提示词生成」；标准模板文档保持侧栏默认弱化灰。
