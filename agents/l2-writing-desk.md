# L2 · 写字台（StatusView）

## 模块概要

写字台是常驻 ItemView（面板显示名 getDisplayText="写字台"，命令/ribbon 文案同用此名；可停靠任意区域、重载保留位置）。渲染陷阱见 [l3-view-rendering.md](./l3-view-rendering.md)「常驻 ItemView 渲染陷阱」。

- **状态页「书籍列表」分组标题行右侧有占满剩余宽度的下拉框（`.aw-st-select`），选择即激活对应小说**（经 doSwitchStory→statusSwitchStory）；组内只展示当前激活小说的「全局文档/章节」小节、不枚举全部书名。

md（非章节目录，含建卷播种的设定五件套/卷摘要等）。**该节点恒存在**——即使无文档也渲染命名头（此时 N=0、展开后列表为空且不渲染空容器）；因此任何卷都可展开（renderVolume 不再有 hasContent 门槛）。**命名头直接复用章节名行的 `.aw-st-chap` 类**（同一显示风格、不重复定义样式；旧独立定义 `.aw-st-vol-dochead` 及其 padding-left 对齐补丁已删），标签文本无前导空格、紧跟 caret(自带 margin-right:0.35em) 起笔；其文件列表再嵌一层 `.aw-st-kids` 使各行对齐/缩进与「章节名下的文档」相同，层级缩进一律沿用 `.aw-st-kids` 不另造；**命名头右键=「补全卷文档」+「在本卷新建文档…」**：前者(StatusAction `complete-volume-docs`)检查该卷下缺失的设定模板（卷大纲/人物/人物关系/场景/时间线五件套）并创建、已存在保留不覆盖——由 main.ts 调 story_manager.ensureVolumeDocs，其模板清单经私有 volumeDocTemplates(vol) 与建卷播种 ensureVolumeFolder / rescanStory 补缺同一来源；Notice 汇报本次补建的名单或提示已齐全。后者(StatusAction `new-volume-doc`→main.ts 落点为 `${storyPath}/${volumeFolderName(vol)}`)。文件行右键仍为「在本卷新建文档…/删除」，点击在编辑器打开。**该命名头可独立折叠**：左侧带 ▾/▸ 纯视觉指示符（`.aw-st-caret`），鼠标点击整行即切换开合——状态键 `voldocs:<书>:<卷ID>` 复用 `collapsed` 集合、默认展开，收起时仅保留命名头、不渲染文件行，且与其所在卷节点的开合互不连动。数据由 story_manager.listVolumeDocsByVol 一次性枚举后经 StatusDetail.volumes[].docs 注入快照（view 只读渲染）。「案头资料」「书稿」两个小节标题行同样**直接复用卷名行的 `.aw-st-vol` 类**（同一显示风格：600 字重、同款 padding/hover），`.aw-st-subsection` 仅保留纵向间距作用不再定义字体；顶层「书籍列表」仍用 `.aw-st-section-head .aw-st-section`（带底部分隔线与下拉框）。「案头资料」「书稿」两个小节的**子节点容器均挂 `.aw-st-kids`**（缩进+左侧指示线，体现与标题的包含关系；卷/平铺章在「书稿」下为一级子节点，其内文档/章节再逐级嵌套）。**v0.2.x+ 引言节点**（renderPrologue，「书稿」体内恒置顶、先于卷/平铺章渲染）：尚无引言→淡色提示行（`.aw-dim .aw-st-hint`）「尚无引言，可在『书稿』标题右键『新建引言…』创建。」；存在→可折叠块（collapse key `prologue:<书>` 默认展开），复用卷块 `.aw-st-vol-block` + 章节名行同款 `.aw-st-chap` 命名头「引言（N）」（caret 开合、整行点击切换）；命名头与块内空白右键＝[新建引言内文档… / 删除引言(danger，二次确认后整文件夹入回收站)]；文件行自定义渲染（**不走 appendFileRow**——其固定菜单 new-file 用 ctx.key 会在书根误建），点击在编辑器打开、右键＝[新建引言内文档… / 删除 <文件名>(danger，复用 path-based delete-file)]。
