# L2 · 写字台（StatusView）

## 模块概要

写字台是常驻 ItemView（面板显示名 getDisplayText="写字台"，命令/ribbon 文案同用此名；可停靠任意区域、重载保留位置）。**v0.2.20+ 同时常驻左栏（移动端抽屉／桌面端左栏）视图切换列表**——插件启动时自动补位、切书恢复工作区后亦自动补回（main.ts `ensureStatusInLeftSidebar` 经 `ensureSideLeaf` 幂等补 tab、不抢焦点、不展开抽屉），始终可被选中；「打开写字台」命令与侧边栏书本图标即激活它。渲染陷阱见 [l3-view-rendering.md](./l3-view-rendering.md)「常驻 ItemView 渲染陷阱」。

- **布局自上而下**：工作目录行（标签 + 路径 + 「刷新」按钮，行下有细分隔横线）→ **「小说状态 / 码字状态」Tab 区（v0.4.5+ 合并，默认码字状态）**：小说状态页＝当前激活书概要（书名行＝名称左对齐 + 更新时间右对齐、题材/编写类型、`N章·第X章·总字数Y字`），码字状态页＝打字统计读数 →「书籍列表（n）」分组（分组标题行右侧下拉框选书；组内只渲染激活书的「全局文档」「章节」两个小节）。头部固定不随内容滚走，树主体独立滚动。
- **下拉框选书**：选择即激活对应小说（同 statusSwitchStory 语义）、已选中项再选不重复触发；分组标题行右键＝新建小说…/[有卷模式]新建卷…/从书级大纲生成卷…｜改名…｜删除当前小说（删书唯一出现处——改名同步改状态文档 title + 顶层目录 + 全书 MD 文档内旧书名，删除整目录入回收站并清 lastStory）。
- **树操作约定**：点章节行/箭头只展开或折叠本章文件列表、绝不激活；**行尾 Radio 是激活章节的唯一入口**（写回 current_chapter 并同步所属卷，书内同名互斥）；点文件行在编辑器打开；**「案头资料」小节内的文件夹行（v0.2.23+）点行/箭头展开收起其直属文件列表（默认折叠）**，文件行右键「新建文章…」落该文件夹内。开合是纯展示态（本地重渲染、绝不读盘），折叠态仅会话内保持不落盘。
- **右键菜单按点击位置精确分配**（案头资料组/书稿组/卷名节点/章节名行/引言块/文件行各有其入口），**删除类项仅出现在作用对象自身的菜单上**（danger 红字、只作用于被点中条目）；空白处兜底为最小菜单。卷名节点另有**卷大纲工作流两项组**（从卷大纲生成章节 / 同步卷大纲章节，均锁定被点卷、不弹选择器）与**「连续编写」入口**（限该卷内连续编写：从该卷第一个没有正文的章节起，详见 [l3-status-view.md](./l3-status-view.md)）；「书稿」小节标题行右键另有**书级「自动生成卷大纲…」入口**（不带卷 id——无卷时按书级《大纲.md》声明自动建卷并逐卷生成、有卷时走当前卷/选择器，与命令面板同语义）、**「生成书籍大纲…」入口**（v0.2.x+，两模式都显示——AI 依据世界观与策划指南生成书级《大纲.md》，平铺形态下即整书当一卷的逐章规划，配套拆章步骤＝「从书级大纲生成章节…」；StatusAction `book-outline-generate`→cmdGenerateBookOutline）与**「连续编写」入口**（全书语义，与命令面板同义）、**「补全大纲资料…」入口**（StatusAction `complete-outline-docs`→manager.ensureOutlineDocs：补齐参与大纲生成的大纲/策划指南/世界观/人物关系，已存在不覆盖）；**[平铺（无卷）模式]** 书稿标题行另显示**「从书级大纲生成章节…」**（不带 id→cmdVolumeOutlineToChapters()：读书级《大纲.md》、章节落书根——「生成书籍大纲」平铺形态的显式拆章步骤，改完大纲可重复执行重新同步）。
- **灵感工具包入口（v0.4.3+）**：「案头资料」小节标题行与组内空白右键 → **「灵感工具包…」**；「案头资料/灵感」文件夹行右键也有该项（仅当 `folder.name === INSPIRATION_FOLDER_NAME` 时出现）。两处都发 StatusAction `inspiration-kit`（带 `story`）→ `cmdInspirationKit(a.story)` 按**该书**的《案头资料/灵感/灵感.md》开弹窗，**不要求先把书切成当前书**；语义见 [l2-inspiration-toolkit.md](./l2-inspiration-toolkit.md)。
- **新建文档流程**：统一单弹窗（全宽输入框 + 可点选标准模板行 + 「确定」CTA 置于弹窗最底部）；名称与已存在标准文档一致→确认后以模板空内容覆盖；不存在→直接按模板创建；自定义名净化后建空 .md。
- **导出书稿**：问范围（留空/all＝整本，或限定某卷）+ 输出路径 → packStory 装配《章节.md》正文（有卷模式每卷组前贴「# 第N卷 · 卷名」H1 行、无章空卷也出卷名行；**每章正文开头自带的「第N章 标题」行先剥掉，章号只用代码生成的**）；默认文件名：限定某卷＝<书名>-<卷名>-范围.md、整本＝<书名>-书稿.md；重导覆盖。
- **字数展示一律实时统计**（countWords，与 count-current/count-all 同口径），不读状态文档里可能过期的 words/total_words 字段。
- **写作实时刷新**：main.ts 订阅 vault md 文件事件（modify/create/delete/rename，按 workDir 过滤）→ 防抖调各打开面板 refresh()（章节字数随编辑器落盘自动跟进）。
- **引言节点**：书稿体内恒置顶（先于卷/平铺章渲染）；尚无引言→提示行（书稿标题右键「新建引言…」创建）；存在→可折叠块「引言（N）」。
- **文件行着色口径（v0.4.3+ 改统一着色）**：不再以颜色区分——是否命中参与写作提示词的标准模板集合，文件行一律用同一默认色（即参与提示词节点的现用色）；「不参与」仅以悬停 title「不参与写作提示词生成」表达，`.aw-st-npdoc` 类照旧挂上、仅作用户自定义 CSS 挂钩。**案头资料文件夹内文件一律视为不参与**（v0.2.23+，提示词只按固定路径读顶层文档）。
- **树节点前导图标（v0.4.3+）**：Tab 按钮（小说状态/码字状态）与小节标题（书籍列表/案头资料/书稿）及卷、「文档」、引言、章节、文件夹、文件行均在 caret 后显示语义 SVG 图标，随主题色与行字号；文件夹图标随展开态切 folder/folder-open（原「📁」emoji 退场）；叶子文件行带隐形 caret 占位，与同层「有子节点」行的图标/文字严格对齐（不分层更深/更浅）。映射与样式口径见 [l3-status-view.md](./l3-status-view.md)「树节点前导图标」。**v0.4.5+ 图标防裁＋换形**：图标盒子 `line-height:0`＋`svg{display:block}`（盒子高度恰等于 SVG，无 inline 基线留白）＋`flex:0 0 auto`＋`overflow:visible`＋`svg{overflow:visible}`（描边越过 viewBox 的部分不再被 SVG 自身裁掉），标题行另加上下 2px 留白；原「小说状态」的 `gauge` 已弃用——它本身是**底部开口的圆弧表盘**，小尺寸下必然读作「下缘被裁」，改 `book-open`（Tab 按钮图标：小说状态＝`book-open`、码字状态＝`feather`）。
- **「小说状态 / 码字状态」Tab 区（v0.4.5+ 合并；码字页只读、无右键）**：标题行＝caret ＋两个 Tab 按钮（`.aw-st-tab-btn`，图标＝小说状态 `book-open`／码字状态 `feather`），**默认显示「码字状态」**；点另一按钮＝切页（顺带展开该区），点当前按钮或标题行空白处＝折叠/展开整区（折叠键仍是 `status-info`），选中页只会话内保持、不落盘。码字页数据源＝打字统计（见 [l2-typing-stats.md](./l2-typing-stats.md)），六行标签-数值对齐排版——**本次开始**（＝本次内第一次有效键入的时刻，**不是写字台打开的时刻**；本次未开始时该行显示「未开始」、本次各值一律「—」并在页顶给一句淡色说明；跨天才显示 MM-DD）、**本次码字**（本次**净增**字数＝新增−删除，含未落盘当前段）、**本次时长**（本次实际码字时长＝各段「跨度−停顿」之和，旁注「码字（不含停顿）」）、**总时长**（此刻−本次开始，旁注「开始至现在」）、**码字速度**（本次平均 X 字/小时 ＋ 本次最近一个已完成段的值；无字数/无活跃时长显示「—」）、**写作总时长**（本书《码字记录.md》全部段的活跃时长＋当前未落盘段，旁注本书累计字数＝同口径的**全部段＋当前未落盘段**，不只读文件，以免恒落后一个段长、每落一盘跳一格）。页尾淡色脚注「段长 N 分钟」（设置项当前值）＝可点标记，走 StatusAction `open-typing-record` → 在编辑器打开该书《案头资料/码字记录.md》（缺失先按表头创建）。刷新＝面板打开时＋10 秒定时器＋段落盘后（main.ts 主动调 `refreshTyping`），**只重绘该 Tab 正文、不碰树区**（不清 scrollTop、不重扫字数）；Tab 停在小说状态页或该区收起时只缓存数据，切回时先同步画缓存。**本次的边界**＝写字台打开/重开、切书、或停笔超过一个「码字记录段长」→ 结束本次（下次敲字自动重新起算），口径详见 [l2-typing-stats.md](./l2-typing-stats.md)。取不到数据（无激活书）时该页退化为一句淡色占位提示。
