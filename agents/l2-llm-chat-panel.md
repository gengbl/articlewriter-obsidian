# L2 · LLM 对话面板

## 模块概要

- **LLM 对话窗是常驻 ItemView 不是 Modal**：`LlmChatView`（`src/llm_chat_view.ts`）经 main.ts `registerView(LlmChatView.VIEW_TYPE, ...)` 注册 + ribbon 图标；自持 history 与每轮 AbortController，配置经构造注入的 getter 实时取 settings.llm；**顶部「模型：」下拉切换即写回 data.json 的 `llm.chat_model`**（v0.2.22+，构造第 5 参 `setActiveModel` 由 main.ts 注入 `setActiveLlmFromChat`；对话框模型只影响对话框自身——写作命令/连接测试各按所属阶段映射取模型〔getPhaseLlmSetup〕、不受其影响；重启后对话框下拉按它加载），设置页改对话框模型或新建/删除/重命名配置后经 main.ts `syncChatModelSelect()` 反向同步下拉（`refreshModels` 已改为 public 且**一律以 `chat_model || active_llm` 为选中依据**）。可见时才抢焦点（offsetParent 判空），避免停靠他区打断编辑。`StatusView`（状态页）同款：数据 getter + 写动作回调注入，渲染陷阱一致（见 [l3-view-rendering.md](./l3-view-rendering.md)「常驻 ItemView 渲染陷阱」）。
- **v0.4.6+ 自然提及自动加载**：发送时除手动 @ 引用外，输入文本里的自然提及会被自动识别并把对应内容注入本轮上下文（识别纯模块 `src/chat_refs.ts`，读盘装配在 main.ts `collectChatAutoRefBlocks`，构造第 7 参注入）——识别形态：`第N章`（阿拉伯/中文数字）→该章正文、`第A到B章`（到/至，范围自动展开、单轮上限 10 章）→逐章正文、`第N卷`→该卷《卷大纲.md》、`《标题》`与「章节标题直接出现在句子里」→按章标题解析（解不到章回落内置文档名映射、再回落案头资料同名 .md）、关键词 故事状态/策划指南/人物关系/时间线/世界观/全书大纲/大纲→对应内置文档（「故事状态」注入格式化进度摘要而非原文件）。无需动词（「看/说说/评价/加载」皆可、不提动词也触发）；手动 @ token 先掩掉防重复加载；同章号跨卷歧义→当前卷优先再按卷 order；无当前小说/无命中/读盘失败＝静默跳过不阻断发送。生效表现：内容块追加进本轮 user 消息（与 @ 展开同款 `=== 标签 ===` 格式、计入自动压缩估算）、用户气泡下追加「〔自动加载：…〕」清单、状态行显示「自动加载 N 项」。
- **v0.4.6+ 工具调用（function calling）**：面板每轮请求带 `CHAT_TOOLS_PAYLOAD`（工具定义在纯模块 `src/chat_tools.ts`，共 21 个——只读：`read_chapter`/`read_doc`（世界观/大纲/人物关系/时间线/策划指南/故事状态）/`read_chapter_outline`/`read_volume_outline`/`list_chapters`/`search_vault`/`set_current_chapter`；写作命令代跑（`CHAT_WRITING_TOOLS`）：`review_chapter`/`continue_writing`/`rewrite_chapter`/`write_chapter`/`polish_chapter`/`deai_chapter`；书级生成命令代跑（`CHAT_GENERATION_TOOLS`）：`generate_worldview`/`generate_planning_guide`/`generate_timeline`/`generate_book_outline`/`generate_vol_outline`/`outline_to_chapters`/`write_chapters_consecutive`（`volume_name` 均经 `resolveToolVolId` 卷名→卷 id）；落盘：`save_content_to_file`（SaveReplyModal 人证：路径可编辑、覆盖勾选、取消不落盘，逐级建目录走共用 `modals.ensureParentFolders`））。模型返回 `tool_calls` → 面板经构造第 8 参转 main.ts `chatExecTool` 本地执行 → `role:"tool"` 结果续轮回灌，直到模型给出最终回答（上限 `MAX_TOOL_ROUNDS=5` 轮；工具结果统一截断 12000 字）。**写作命令工具走原命令同款流程**：代跑前预置 `chatToolCtx`（章节直给＝`targetChapterKey` 免弹窗、补充要求＝`prompt()` 一次性预答，instruction=null＝不预答任何弹窗如新建章标题输入）、当前章驱动型命令（续写/重写/编写/润色）先 `switchChapter` 切当前章（review/deai 走 targetChapterKey 不动指针），结果仍进「生成过程」面板由用户**保存/不保存**确认才落盘，产出文本回灌给模型继续推理（`peekGenPanelText`）。状态行显示「🔧 正在执行工具 name(参数)」。中间工具轮**不落会话历史**（只存档最终答案）；端点拒绝 tools 参数（不支持 function calling 的本地服务）→ 自动去参重试一次、按普通对话继续；执行失败以文本回灌不断流。**生成命令工具（`runChatGenerationTool`）**：模式/章数/覆盖确认/中断续跑三选等弹窗一律留给用户在聊天阻塞期间作答，仅 `generate_worldview` 的 premise 可由工具参数预答（复用 `chatToolCtx` instruction 接缝，该命令唯一 prompt）；命令直接写盘的（拆章/时间线）无流式产出时如实回灌「已结束但没有流式产出，请查看文档与通知」；`write_chapters_consecutive`（连续编写）逐章**免确认自动保存**，回灌不走面板文本、改用 `chapterFilledMap` 正文前后快照差集报告「本轮新写了哪几章（字数）/仍为空的章」。**防「行动宣告就停下」**：注入执行器时系统提示词追加【工具调用规则】块（必须本次回复内直接发起 tool_calls，不得只输出「我先看看…」类意图文字）；兜底：模型回了含「我先/让我/即将…」意图词但无 tool_calls 的短文本（≤300 字）时，循环自动催办一次（把宣告＋「请继续直接调用工具」的用户指令续进本轮 messages，仅一次）。
- **多轮流式聊天**：Enter 发送 / Shift+Enter 换行（含中文输入法合成态保护）；「停止生成」仅中断当前轮。
- **v0.4.6+ 会话持久化（案头资料/AI会话/）**：每轮结束（含中断留存的半截回复、仅用户轮）自动把整段对话写到当前书《案头资料/AI会话/对话 YYYY-MM-DD HHMM.md》（frontmatter：type/story/created_at/updated_at/model；正文 H2 章节 `## 我`/`## 助手`/`## 摘要（上下文压缩）`，格式与解析在纯模块 `src/chat_session.ts`，文件是普通 Markdown 可人工编辑）；**面板重开自动接回**该目录 mtime 最新的会话；「**重新加载对话**」按钮从磁盘重读绑定文件（人工编辑后生效）/未绑定时接回最近文件；「清空对话」解除文件绑定（磁盘文件保留），下一轮另起新文件；已绑定会话切书后仍写回原文件；**无当前小说（纯问答）不落盘**、仅内存。顶部新增会话状态行：绑定文件路径 · 条目/字数 · 长对话软提醒。
- **v0.4.6+ 上下文压缩（手动＋自动）**：「压缩上下文」按钮把保留窗（最近 2 轮）之外的早期轮次连同旧摘要交当前模型合并成一条**摘要轮**（会话最前、气泡区渲染为虚线弱化块、文件内为 `## 摘要（上下文压缩）` 章节）；后续每轮只把摘要折入系统提示词尾部、被压轮次不再逐轮重发。压缩进行中可「停止生成」中止（历史原样）；不足保留窗＋4 条时拒绝并提示；成功后会话文件同步重写。滚动式：再压缩时旧摘要并入新摘要。**自动触发（发送前判定）**：每份模型配置可填「上下文窗口 context_window」（token 数；留空按模型名 `-128k` 类后缀推断，推不出＝不自动、仅手动）——发送前估算「系统提示词＋历史（含旧摘要）＋本轮 @展开文本＋回复预留（min(max_tokens, 窗口/4)）」，超过 窗口×阈值%（全局设置「对话自动压缩阈值」，缺省 75、0＝关闭）即先自动走一轮压缩再继续发送（压缩失败照发兜底）；会话行实时显示「历史估算 ~N token / 窗口 M ≥X% 自动压缩」预算状态。
- **回复落盘（v0.4.6+ 起无逐条按钮）**：助手气泡下方**不再**显示「保存到文件」按钮（用户反馈每次交互都出现过于打扰，已移除 `addSaveAction`/`saveReply`/`writeReply` 与构造注入 `getDefaultSaveDir`）；逐轮内容本就由 `saveSession()` 自动写入《AI会话/》会话文件、需要单独存文件时改走对话工具 `save_content_to_file`（SaveReplyModal 人证闸门不变）。
- **@ 引用功能**：两种形式——`@[[相对路径]]`（弹窗插入、可含空格）与 `@相对路径`（手输，须含 `/` 或扩展名防误伤邮箱）；支持行范围（`:起-止`、空格分隔、紧贴 token 尾的数字）；键入 @ 弹候选列表（vault 文件按路径过滤、排除 `_resources`、v0.4.3+ 不截断全量列出）；Enter 发送时 token 原位内联展开为「=== 路径（第X–Y行 / 全文）=== + 带行号正文」片段（模型直接看到原文），气泡回显原始输入（保留 @ 标记）。
- **每轮系统提示词与上下文**：请求前置对话专用系统提示词（友好助手身份 + 当前小说上下文快照〔写作上下文 + 当前章节正文截断 6000 字〕；**v0.3.5+** 旧「创作规范指南」三层指南块已随写作指南体系废弃、不再注入）；多轮历史经原生 messages 传递。顶部首行显示当前小说·章节，切书/切章等变更后由 main.ts 主动刷新（钩子挂在 saveSettings 与状态落盘回调两条必经路径，任何命令的状态变更无需逐处埋点）。
