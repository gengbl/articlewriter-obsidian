# L2 · 设定实体（人物 / 场景 / 世界观 / 伏笔 / 大纲）

## 模块概要

负责设定实体的增删改查：人物（书/卷/章三层归属）、场景、世界观、伏笔、大纲（全书大纲/章节大纲）。解析与格式化全部在 `md_docs.ts`（纯函数层，不接触 Vault），文件 IO 在 `story_manager.ts`；实体文档随建书/建卷/建章按模板清单播种。

## 行为约定

- **字段命名陷阱（勿单方面"修正"）**：角色文档 `CharacterDoc` 的章节归属字段叫 **`chapter`**，场景文档 `SceneDoc` 叫 **`chapter_num`**——两边都要改才允许统一（详见 [l3-md-docs-parsing.md](./l3-md-docs-parsing.md)）。
- **卷级人物（v0.2.0+ 落盘口径）**：`chapter=0 && vol=<卷id>` = 卷级人物，物理落卷目录《人物.md》（H1 用卷名）；v0.2.0 前 `addCharacter` 把 `chapter=0` 的 vol 一律丢弃（只能落书根）。
- **伏笔**：定位一律「复合键 + 章内序号（0 起）」；[伏]…[/] 提取的「章节」字段支持 `章节：N`（默认当前容器）与显式跨卷 `章节：<卷名>第N章` 两式；renumber/insert/delete 时按复合键结构化重映射。
- **大纲类文档**：模板末尾恒附「大纲详略标记使用帮助」（[详][扩][补][略][跳]/[伏] + `<角色：>`/`<场景：>` 用法），写盘路径同样恒带尾注。
- **卷大纲→章节大纲拆分（v0.2.10+）**：《卷大纲.md》可按「第N章」标记拆入各章《章节大纲.md》（命令 `volume-outline-to-chapters`）——H2 标题式 `## 第N章 <标题>`（标题入章节名）与普通段落式双格式；空大纲直接写入、非空走与 /outline 追加同语义的去重合并；**一个「第N章」标记都没有时自动调 LLM 拆分**（目标章数优先取大纲内声明如「共N章」，未声明弹窗收集、取消即中止；输出同格式标记、复用同一解析器落盘，失败提示并中止）；卷大纲本身只读不改，模板注释内示例不参与解析（stripComments 先行）。
- **自动生成卷大纲（v0.2.11+）**：命令 `vol-outline-generate`（LLM 流式）——依据全局设定（世界观/社会组成/力量体系/基调等）+ 全书大纲 + 前一卷卷大纲（只读参考）为目标卷生成恰好 N 章的卷大纲；**生成前弹窗询问章数**（复用 `promptChapterCountInput` 核心，取消即中止）；流式预览后保存确认；目标卷《卷大纲.md》非空（清洗文本判定，模板注释视为空）弹覆盖/追加二选一——追加保留原文含注释（raw 剥首部 H1 后拼接），空则直写；不改任何 state。**零卷兜底（v0.2.x+）**：尚无任何卷时若书级《大纲.md》有卷声明（parseVolumeDeclarations）→ 自动创建全部声明卷（声明描述作卷描述）并逐卷生成其卷大纲——各卷章数由单弹窗一次性问全（`promptAllVolumeChapterCounts`，建卷前问、Esc 零副作用取消）、每卷一次 LLM 流式输出防长输出断开、批内相邻卷链式传递上下文（freshOutlines 缓存本轮已生成卷）、Esc 整批中止、收尾逐卷 ✓/↷/✗ 汇总；新建卷大纲必空故直写不弹覆盖/追加；无声明则提示先新建卷或补全书级大纲。**入口**：命令面板 + v0.2.x+「书稿」小节标题行右键（书级语义＝无参调用，零卷兜底/当前卷/选择器与命令面板一致）；v0.2.x+ 卷节点右键入口已移除（`cmdGenerateVolOutline` 的 volId 可选参随之删除）。**v0.2.13+ 策划指南注入**：生成前经 main.ts `ensurePlanningGuide` 确保书级《策划指南.md》存在（缺失先 LLM 流式自动生成落盘，软依赖——失败仅告警、不带【策划规范】块继续），非空时其既定规划以【策划规范 · 本书既定规划】块注入提示词【书籍信息】之后；该文件由 `/planning-guide` 命令手动生成/重写，详见 [l2-llm-writing-commands.md](./l2-llm-writing-commands.md) 与 [command-reference.md](./command-reference.md)。
- **同步卷大纲章节（v0.2.11+）**：命令 `vol-outline-sync`（确定性、无 LLM）——卷大纲被用户续写后，把新增的「第N章」标记建成新章节：章号尚不存在的自动创建并把该段内容直写其《章节大纲.md》（新章必空纲）；已存在的章跳过不动其大纲；一个标记都没有时引导用拆分命令（含 AI 兜底）；收尾有原当前章则恢复、否则指向首个新建章（文档序）。
- 多行内容（场景正文、世界观历史/力量体系等）用 ```text 围栏包裹，解析按围栏进行。
- **世界观提示词注入（v0.2.x+ 全文注入）**：所有注入世界观的 LLM 命令（写作类 + 卷大纲生成 + 书级大纲生成 + 从书级大纲生成卷）统一经 `story_manager.readWorldDoc`——除结构化字段外附带 `fullText`（《世界观.md》去 HTML 注释后的清洗全文），提示词侧 `prompts.worldBlock` **优先注入全文**（自由格式设定——人物小节/时间线/自定义标题等 parseWorld 不识别的内容——也原样进上下文），fullText 缺失才回退结构化字段渲染。模板注释「字段可增删」由此兑现：任意写法的世界观都会被注入，不再静默丢弃。
- 人物关系是独立面板模块，见 [l2-relationship-panel.md](./l2-relationship-panel.md)；时间线同理见 [l2-timeline-panel.md](./l2-timeline-panel.md)。
