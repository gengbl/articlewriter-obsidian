## v0.4.5+ 写字台「码字状态」Tab 读数（读回与本次会话）

`src/typing_stats.ts` 追加的纯函数（全部可单测、无 IO）：

- `parseDurText(s)`：`durText` 的逆解析——「无」/空 → 0，「N 秒」「N 分」「N 分 N 秒」「N 时 N 分」→ ms，其它写法 → null（用户手改坏的单元格整行跳过，不抛）。
- `parseStatsRow(line)`：`| YYYY-MM-DD | HH:MM–HH:MM | 字数 | 停顿 | 速度 |` → `{start,end,chars,pauseMs,activeMs}`（起止按**本地时区**还原；`end<start` 视为跨零点加一天；`activeMs=max(0, 跨度−停顿)`）；表头行/分隔行/散文行/无效数字一律 null。
- `summarizeStatsFile(text)`：逐行汇总 `{segments, chars, pauseMs, activeMs}`——**「写作总时长」的事实源就是这本书的《码字记录.md》**，不另存计数器，重启/换设备后依旧连续，用户手改文件也如实反映。
- `liveSegStats(seg, now, segMs)`：进行中段「写到此刻」的 `{chars, pauseMs, activeMs}`——**`chars`＝净增字数（`segNetChars`）**；此刻夹到段末；无键入事件 → 活跃 0；停顿按 `segmentPauseMs` **三段同口径**（段首空档＋间隔＋段尾，各取 >30s 的超出部分）。停笔不动时活跃时长不再增长（尾距全部算停顿）。

`src/main.ts` 会话侧（与上表同一接线段）：

- 字段：`typeSessionStartAt`（**0＝本次尚未开始**）、`typeSessionStory`、`typeSessionChars`、`typeSessionActiveMs`、`typeLastEditAt`（本次内最后一次有效键入时刻，停笔判定用）、`typeLastSeg{start,end,chars,speed}`。
- **懒锚定两个函数**（v0.4.5+ 改版）：`endTypeSession()`＝结束本次——进行中的段先 `enqueueTypeFlush(min(now, 段末))` 结算进它自己的《码字记录.md》（同书才写 `typePrevSegEnd`，换书归 0）、清 `typeSeg` 与全部累加、`typeSessionStartAt=0`、`notifyTypingPanel()`；调用点＝StatusView.onOpen（写字台打开/重开，构造第 7 参）、`applyStorySwitch`（切书）、`tickTypingStats`（停笔超过一个段长）。`anchorTypeSession(now, story)`＝本次未开始（或归属书变了）时以这次键入为起点重开一次并清累加，已在本次中则只确认归属。`onTypingEdit` 每次有效键入先 anchor 再记 `typeLastEditAt`。**`active-leaf-change` 钩子已删除**（懒锚定后不需要「激活即开一次」，点标签页来回切不影响本次）。
- `writeTypeRow` 成功后才记账（写失败不计数）：`active = segActiveMs(seg, end, typeSessionStartAt)`（**按本次锚点夹取**，段起点早于锚点时不把锚点前的发呆算进本次），仅当 `seg.story === typeSessionStory` 才累加，并刷新 `typeLastSeg`；随后 `notifyTypingPanel()` 只刷各打开 StatusView 的 `refreshTyping()`。
- `getStatusTyping(): Promise<StatusTyping|null>`：`chars/active = 会话累加 + liveSegStats(当前段, now, typeSeg.segMs)`（**段长取开窗时值**，取当前设置会在改过段长后把「此刻」夹到过去、停顿/活跃当场失真）；`wallMs = now − typeSessionStartAt`；`avgSpeed = round(chars×3_600_000/active)`（任一为 0 → null）；`totalActiveMs = summarizeStatsFile(文件).activeMs + live.activeMs`（文件已含本次已落盘段，只补 live）；`totalChars = 文件 chars + live.chars`（与 `totalActiveMs` 同口径含当前段，旧实现只读文件→恒落后一个段长）；`segmentMin = effectiveTypeSegmentMin()`；`recordPath` 供面板 tooltip。**本次数走 `liveSession = liveSegStats(段, now, segMs, typeSessionStartAt)`**（窗口夹取），`totalActiveMs/totalChars` 走**整段** `live`；返回体新增 `started`（`typeSessionStartAt>0`），**无书才返回 null**（本次未开始时仍返回数据：本次各值 0/`avgSpeed=null`，面板显示「未开始」占位，「写作总时长」照常给出）。
- StatusAction 新增 `{kind:"open-typing-record"}`：码字状态页页尾「段长 N 分钟」标记点击 → 打开该书《案头资料/码字记录.md》（缺失先写 `TYPE_STATS_HEADER` 骨架）。
- **旧文件兼容**：v0.4.5+ 前创建的《码字记录.md》表头第三列写着「有效字数」——`parseStatsRow` **按列位置**取值、不看列名，故旧文件读回汇总不受影响；新写行按新表头（只在文件缺失需重建时才写新表头）。
