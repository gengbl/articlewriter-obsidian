# L2 · 设置页与 LLM 配置

## 模块概要

- **LLM 配置存插件数据目录 `data.json`**（`.obsidian/plugins/articlewriter/data.json`，经 saveData/loadData）：`settings.llm` = `PluginConfig`（`chat_model`〔对话框模型〕+ `active_llm`〔旧版激活态，仅作对话框模型回落〕+ `llm_configs[]` + `system_prompt` + `desc_style`（**v0.3.5+ 写作指南体系整体废弃**：旧 `system_guide`/`system_guide_path` 遗留字段与 `ensureSystemGuideFile`/`purgeLegacySystemGuideFields` 迁移链已删除，类型不再含该两字段；存量 data.json 残字段由 `purgeWritingGuideArtifacts()` 启动清理时读侧删除落盘），类型与默认模板在 `src/plugin_config.ts`。首次运行（data.json 无 llm 段）由 `buildDefaultLlmConf()` 预置 local/deepseek/qwen-dashscope 三组标准模板并弹通知提示填写 api_key/model_name；**不读取也不迁移旧的 work_dir MD 设置文档**（该方案已废弃）。**api_key 明文存于 data.json——勿将 .obsidian 同步/共享到不可信位置**。所有 LLM 命令读配置一律走 `getPhaseLlmSetup(phaseIndex)`（按所属写作阶段取模型；回退链＝该阶段 `llm_config_name` → 第一个配置 `cfgs[0]`，对话框 `chat_model` 与旧版激活态 `active_llm` 均不参与阶段回退；无可用配置返回 null、不弹通知），不再依赖 work_dir（旧 `getLlmSetup()`/`loadWriterSetup()` 全局激活入口已删除）。**v0.2.22+ 对话框模型同步**：LLM 对话框顶部下拉切换模型即写回 `llm.chat_model` 并落盘（`main.ts setActiveLlmFromChat` → `saveSettings`）；对话框模型**只影响对话框自身**——写作命令/连接测试各按所属阶段映射取模型（getPhaseLlmSetup）、不受其影响；反向由设置页驱动——改「LLM 配置」tab 区块的对话框模型下拉 / 新建 / 删除 / 重命名配置后调 `main.ts syncChatModelSelect()` 让已打开的对话框下拉跟随（`LlmChatView.refreshModels` 一律以 `chat_model || active_llm` 为选中依据）。**v0.2.25+ LLM 配置 tab 区块**：原「LLM 全局设置」group 与「模型配置」list 合并为一个 tab 区块——固定两 tab：tab 0=「全局设置」（对话框模型 / 系统提示词 / 描述方式三项），tab 1=「模型配置」（列表形态：每份配置一行＝名称 + model_name/base_url 摘要 + 「配置 ›」，点击进该配置的详情页；页顶「＋ 新建配置」按钮，新建后直接跳进新配置详情页）。详情页顶部「← 返回模型配置列表」按钮回列表（局部刷新、不整页重建）；页内「↑ 上移 / 下移 ↓」按钮调整列表顺序（替代旧 list 拖拽，第一个配置＝阶段映射与对话框的回落默认，重排走整页重建、详情页跟随新位置）、「删除配置」按钮（删除后回落列表形态）。改名不整页重建、返回列表即见新名。「设为激活」按钮已删除——`active_llm` 不再有 UI 直接写入口，仅由新建（首个配置时）/删除（激活项被删回落 `cfgs[0]`）/改名（跟随更名）逻辑维护，作对话框 `chat_model` 留空时的回落、不影响任何写作阶段。**v0.2.21+ 多值配置项改下拉框**：每份配置的 `reasoning_effort`（留空/none/low/medium/high/max）与 `thinking`（留空/on/off）由文本输入改为下拉框——取值集合封闭、手填易错；存量值不在标准集时动态并入选项并标「（存量值）」防丢失（实现细节见 [l3-settings-page.md](./l3-settings-page.md)）。**v0.2.22+ 写作阶段模型配置**：`writing_phases[]` 字段定义五阶段（0=世界观生成 / 1=策划方案生成 / 2=书籍大纲和卷级大纲生成 / 3=文章大纲生成 / 4=编写文章；v0.3.7+ 新增阶段 0 世界观生成，原四阶段整体后移一位）各自使用的模型配置名（留空=回落第一个配置 `cfgs[0]`，`active_llm`/`chat_model` 均不参与回落），设置页「写作阶段模型配置」区块＝tab 页管理（tab 名与书籍 Skill 弹窗/导出文档同源＝`WRITING_PHASE_LABELS`；每 tab＝该阶段模型下拉＋引用文档配置框）。代码里引用阶段一律用命名常量 `PHASE_WORLDVIEW`/`PHASE_PLANNING`/`PHASE_OUTLINE`/`PHASE_CHAPTER_OUTLINE`/`PHASE_WRITING`（`src/plugin_config.ts`），不写裸下标。全部 LLM 命令（含章节/卷摘要生成、剧本转换、连接测试等辅助任务）按所属阶段调用 `getPhaseLlmSetup(phaseIndex)` 获取对应配置（完整阶段分类见 [l2-llm-writing-commands.md](./l2-llm-writing-commands.md)「v0.2.22+ 全部 LLM 调用按写作阶段取模型（阶段分类）」）。

## v0.2.25+ 阶段引用文档配置框（ref_docs）

- **每个写作阶段 tab ＝模型配置下拉＋引用文档配置框**（v0.3.4+ 身份加强 Skill 化后原「身份加强 | 引用文档」两个内层子标签已收敛，tab 内直接渲染引用文档清单）：可删除/添加条目、可 ↑/↓ 调整顺序（行首序号＝装配顺序，排前的先组装）、可从 vault 添加 Markdown 文档、可「恢复默认清单」；**v0.3.5+ 写作指南体系整体废弃**：旧「三层《写作指南》（小说级/用户级/系统级）以锁定行展示在清单最上面（🔒 默认注入 · 不可修改），不在清单内、任何配置下都恒注入、不参与排序、装配时固定第一块」全部移除，清单不再有锁定行；历史保存清单里的 `guide` 条目由 `phaseRefDocKeys` 就地过滤忽略（无需用户重设）。
- **配置真正控制运行时注入**（非仅展示）：装配入口按阶段过滤引用文档——阶段 0 世界观生成（/worldview-generate）、阶段 1 `buildPlanningGuideInput`＋`buildTimelineInput`（planning-guide-worldview、时间线前置生成）、阶段 2/3 `assembleVolOutlineContext`（book-outline-generate / vol-outline-generate / book-outline-to-volumes / vol-outline-to-chapters AI 拆章）、阶段 4 `assembleWritingDocGroups`（write / continue / rewrite / polish / deai / review / chat 等）；export-ai-prompts 导出预览与各命令同一构建函数同口径。评审类命令（review）与 chat 的引用文档跟随阶段 4 配置框。代码里按阶段取配置一律用 `PHASE_*` 命名常量（见上条）。
- **数据模型**：`WritingPhase.ref_docs?: string[]`（`src/plugin_config.ts`）。条目 = 内置文档 key（`book_info`/`tension_rules`/`worldview`/`timeline`/`book_outline`/`vol_list`/`planning_guide`/`outline_source`/`book_relations`/`vol_relations`/`prev_vol_outline`/`vol_outline`/`chapter_outline`/`characters`/`scenes`/`chapter_relations`）或 `file:<vault 路径>`（用户自选文档）。`undefined` = 该阶段默认清单（`PHASE_REF_DOC_DEFAULTS`，不做 loadSettings 回填）；`[]` = 不注入任何引用文档（**v0.3.5+** 旧「只注入锁定写作指南」语义已随写作指南体系废弃）。v0.3.3+ 合并时间轴与大事件：key `timeline`（显示名「时间线（书/卷/章三层《时间线.md》合并时间轴）」）替代旧 `events_list`；存量配置里的 `events_list` 在 loadSettings 末尾静默迁移为 `timeline`（保位置、去重、仅变化才 saveData）。
- **默认清单按阶段**（事实源 `PHASE_REF_DOC_DEFAULTS`，`src/plugin_config.ts`，五组与 `WRITING_PHASE_LABELS` 同序）：阶段 0 = 三项（书籍信息/张力规则＋`skill:世界观生成框架` 方法论技能条目，v0.3.7+；世界观.md 是产出目标、不注入自身，目录也只有书籍信息/张力规则两项）；阶段 1 = 四项（书籍信息/张力规则/世界观/时间线，v0.3.3+，原「大事件列表」退场；书级《时间线.md》无有效条目时先生成再注入，见 [l2-llm-writing-commands.md](./l2-llm-writing-commands.md)）（全书大纲/卷列表默认不注入、可在下拉手动添加）；阶段 2 = 四项（书籍信息/张力规则/世界观/策划方案，大纲来源/全书大纲/关系/卷列表/前卷大纲默认不注入、可在下拉手动添加）；阶段 3 = 八项（书籍信息/张力规则/世界观/策划方案/大纲来源/全书大纲/卷列表/前卷大纲，书级/本卷人物关系默认不注入、可在下拉手动添加）；阶段 4 = 八项（世界观/书级人物关系/本卷大纲/卷级人物关系/本章大纲/人物/场景/章节关系）＋`skill:网文高频禁用词清单`（v0.3.6+）——**正文写作有卷模式默认不注入全书大纲全文**（旧版曾无条件注入【全书大纲】块，v0.2.25+ 已移除，写作上下文只依赖本卷大纲与本章大纲）；**平铺（无卷）模式例外**：无卷大纲可依赖，`vol_outline` key 在平铺下解析为书级《案头资料/大纲.md》并以【全书大纲】块注入（提示词措辞经 `outlineBlockNameOf` 同步改「全书大纲」口径）。下拉候选目录 `PHASE_REF_DOC_CATALOGS[phaseIdx]` 按阶段裁剪、只显示尚未添加的内置项（`timeline` 阶段 1–4 四个目录均有、仅阶段 1 默认注入——阶段 2/3/4 手动添加后经 `mergedTimelineText` 三层合并时间轴注入【时间线】块；阶段 0 目录只有书籍信息/张力规则两项）；显示名映射 `REF_DOC_LABELS`。
- **注入语义**：`ref_docs` 数组顺序即装配顺序（排前的先组装进提示词）；目标文档永不注入自身生成上下文（strict skip 保留）；用户 `file:` 条目以【引用文档 · <路径>】标题在清单位置就地注入。实现细节见 [l3-prompt-assembly.md](./l3-prompt-assembly.md)；UI 实现见 [l3-settings-page.md](./l3-settings-page.md)。
