# L3 · 时间线面板（TimelineView）实现细节

时间线面板模块的实现级说明（源文件职责，含 readTimelineDocs 与接线部分）；模块级行为见 [l2-timeline-panel.md](./l2-timeline-panel.md)。

## 时间轴绘制美化（v0.4.4+，全部在 styles.css 时间线段，timeline_view.ts 零改动）

| 视觉件 | 实现 |
| --- | --- |
| 主轴渐隐圆头 | `.aw-tl-list::before` 底色改 `linear-gradient(to bottom, transparent, var(--background-modifier-border) 12px calc(100% - 12px), transparent)`＋`border-radius:2px`（两端收在首末条目附近） |
| 跳跃段虚线轴 | `.aw-tl-skip::before` 以 `var(--background-secondary)`（面板底，与 `.aw-tl-time` 不透明徽章同一口径）盖住 list 坐标 x3–5 的实线段（块坐标 left:-13px width:8px），`.aw-tl-skip::after` 画 `repeating-linear-gradient` 虚线（left:-11px width:2px）；绘制次序＝文档序（skip 子树后于 list::before）自然压过实线，块内层级导引线又压在两段之上、互不冲突；`.aw-tl-skiplbl` 虚线描边胶囊＋letter-spacing |
| 留白时间标尺 | `.aw-tl-spacer` `background-image: linear-gradient(to bottom, … 0 1px, transparent 1px)`＋`background-size:5px 24px`＋`background-position:-9px 11px`＋`repeat-y`＝沿主轴右侧每 24 布局 px 一格刻度；spacer 是 position:relative 的绘制在主轴之上，刻度从轴右缘起不叠轴 |
| 圆点光晕/靶心 | `.aw-tl-dot` 加 `box-shadow:0 0 0 2px var(--background-secondary)`；`.aw-tl-item.lv-1 .aw-tl-dot` 追加 `0 0 0 3.5px currentColor` 外环；**`.aw-tl-dot.has-kids` 同样描 `0 0 0 3.5px currentColor` 外环＝「有子事件可折叠」标记（一级 has-kids 由 `.lv-1` 规则 (0,3,0) 胜出、同值不冲突）**；`.aw-tl-dot.has-kids:hover` `transform:translateX(-50%) scale(1.4)`（覆盖基础 transform，须写全） |
| 徽章/胶囊语言 | `.aw-tl-time` `border-radius:999px`＋`border-color:var(--tl-lv-color, var(--h2-color, var(--interactive-accent)))`（与 `.aw-tl-dot` 的 color **同一回退链**＝描边恒等于本级圆点色；勿回落 `--background-modifier-border`——二级徽章会因此几乎无边框可见）；`.aw-tl-char`/`.aw-tl-rel` 胶囊；`.aw-tl-done` 胶囊＋`color-mix(in srgb, var(--color-green) 12%, transparent)` 底衬（旧内核忽略该 declaration 自动退化） |
| done 条目语感 | done 行由 renderRow 挂 `is-tl-done-row` 类、`.aw-tl-item.is-tl-done-row .aw-tl-name{color:var(--text-muted)}`（**不用 `:has()`**——外部检查器判大范围选择器失效有性能隐患，一律改视图挂类）；lv-1 事件名 `font-size:1.05em` |
| caret 移到徽章前（v0.4.4+） | renderRow 里 caret 块先于时间徽章创建（行内序＝圆点→▾/▸→徽章）；caret 吃原徽章的 `margin-left:-12px` 拉回、`.aw-tl-caret + .aw-tl-time{margin-left:0}` 免二次拉回——无 caret 行徽章维持原 -12px 紧贴圆点 |

几何坑位：skip/spacer 内块坐标与 list 坐标换算恒为 **块坐标＝list 坐标−(padding-left 14px)**（主轴占 list x3–5＝块 x−11..−9）；改 `--tl-indent`/主轴位置时两处伪元素与标尺 background-position 须同步；`.aw-tl-time` 徽章左缘（圆点圆心右 2px）会盖过一级靶心外环右侧一小段——徽章边框同为级别色，读作圆点→徽章连续，属预期。

## 树挂分支视图（v0.4.9+ 新增显示方式，用户要求＝「按向下生长的树挂事件」）

| 件 | 实现 |
| --- | --- |
| 模式状态（v0.4.9+ 已退场） | 用户确认＝**默认即树挂、去掉「显示方式」选项**：`TlDisplayMode`/`tlMode`/头部 `modeSel`/`.aw-tl-modesel` CSS 全部删除；列表容器恒挂 `is-tl-tree`（CSS 形状开关改为恒真，规则本身不变） |
| 唯一渲染趟 | `renderBody` 只有一条路：`buildTlRoots(visible)` → `renderTlTree(list, roots, q)`（`q`＝筛选词，空＝非筛选趟）。旧 `buildFlatRows`/`flattenTl`/`TlFlatNode`/`ancestors` 链折叠判定整体删除（跨文档不挂父口径移进 `buildTlRoots`）；`setContentWidth` 恒由 `renderTlTree` 写（无 line 趟复位问题） |
| 根集合 | `buildTlRoots(rows)`＝按 `sourcePath` 连续段逐文档 `buildOutlineTree`（跨文档不挂父），只取各棵轮廓树的根、**按文档先序返回**（不再在这里排时间——行序统一交给 `flattenOutlineOrdered`）。时间升序比较器收敛成模块级私有 **`tlTimeCmp(a,b)`**（年→月→日，缺月日按 0），全局行序与同刻先序共用同一份 |
| 全局时间行序（v0.4.11+ 用户要求＝「Y 值按每个事件的时间安排，不得时间晚的在上、时间早的在下；各级事件与子事件都遵循时间顺序」） | `renderTlTree` 调 `outline_tree.flattenOutlineOrdered(roots, cmp, {keep, descend})`：深度优先先序收集（父在子前）→ **稳定排序**（`cmp` 相同用收集序号兜底＝同刻保持父先子后/文档序）→ 返回 `OutlineRow{node, depth}[]`。**父事件与各级子事件参与同一个时间序**：一级事件 A 的子事件若晚于一级事件 B，B 会插到 A 与该子事件之间（旧「子树整块输出、逐层各自排序」会让时间晚的子事件压在时间早的一级事件上面）。层级只由 `depth` 决定缩进/圆点列/列线，不再影响 Y 序；子事件时间早于父事件（数据异常）时也严格按时间排在父事件之上 |
| 折叠/筛选在压平前处理 | `flattenOutlineOrdered` 的 `keep`＝false 整支（自身＋后代）不进序列＝筛选 `subtreeHas` 整支剪枝；`descend`＝false 保留自身但不下钻＝折叠（筛选趟忽略折叠）。压平后 `tlTreeMaxDepth`＝可见行最大深度（封顶 6），横向预算按它摊 |
| 全局时间间距游标 | 行序已全局升序 ⇒ 相邻行时差 Δ≥0；`tlPrevMs` 是**整条列表共用的一条游标**（不再进/出每层保存复原）：留白/跳跃块按相邻事件的真实时差插入，各级共用同一条时间尺度＝Y 值只由时间决定 |
| 轨道绘制（v0.4.11+ 方法一「连续轨道＋小出针」，用户要求＝修掉「子时间轴的绘制和走向很难看」） | 行与留白块全部画完后 `layoutTlLanes(list, roots, step)` 做三件事：①按 `nodeEls` **实测**每个条目行的 `offsetTop/offsetHeight`（`offsetParent`＝list，list 已 `position:relative`）；②**先序**收集「有已渲染子事件」的父事件区间 `{id, parentId, top, bottom}`（top/bottom＝父圆点圆心与各直接子圆点圆心的 min/max，圆心＝行顶＋`TL_DOT_CY=11`；子事件时间点早于父事件＝min/max 兜住、不塌成 0 高）交给纯函数 `assignTlLaneXs`（`src/timeline_lanes.ts`）分配 X；③每个父事件画一条 `.aw-tl-rail`（`drawTlRail`＝list 直接子元素、绝对定位：`left=父X`、`top=父圆点Y`、`width=子轨道X−父X+1`、`height=bottom−top`）并给它的已渲染子行写内联 `--tl-x=轨道X`。**旧 `attachTlGuides`／逐行通高列线／每行分叉弧线／留白块挂导引 全部删除**（`aw-tl-branch-line`/`aw-tl-branch-out` 的 JS 生成与 CSS 规则一并删；`.aw-tl-spacer`/`.aw-tl-skip` 不再挂任何导引，轨道本身就一整条贯穿留白） |
| 轨道 CSS | `styles.css` `.aw-tl-rail`：`box-sizing:border-box`＋`border-top`/`border-right` 2px＋`border-top-right-radius:12px`（**小出针**＝旧 `max(14px, .85×indent)` 大弧退场；高/宽不足时浏览器按比例夹小半径＝不会画破）＋`z-index:-1`＋`opacity:.7`＋`pointer-events:none`。宽由 JS 写「子轨道 X − 父 X ＋ 1」⇒ **2px 右描边的中心线**正好落在轨道 X 上＝子卡片左缘＝子圆点圆心（与主轴 `left:3px;width:2px` 同一「描边中心线＝列 X」口径）。颜色走级别色**单一来源**＝`.aw-tl-rail.lv-N` 与 `.aw-tl-item.lv-N` 共用同一条调色板规则（改色只改那一处），缺级别色时 `--tl-rail-color` 回落 `--background-modifier-border` |
| 列距（v0.4.11+ 用户要求＝「收窄封顶约 56px」） | 常量 `TL_LANE_STEP=56`（上限）／`TL_LANE_STEP_MIN=28`（下限）：`renderTlTree` 里 `fit=round((usable−4−TL_TREE_CARD_W)/levels)` **只在面板窄时收缩**列距，**不再按「子线族摊面板 2/3 宽」放大**（旧口径列距涨到 ~150px＝出针弧被撑成横跨整行的大弯＝难看主因之一）。相关常量同在 timeline_view.ts：`TL_AXIS_X=4`（＝`.aw-tl-list::before{left:3px;width:2px}` 的圆心＝一级事件所挂的主轴 X）、`TL_DOT_CY=11`（各级圆点圆心距行顶的距离，一级 `top:5`+半高 6＝默认 `top:7`+半高 4＝恒 11）、`TL_RAIL_VGAP=8`（通道判重叠的纵向缓冲） |
| 倾斜退场（v0.4.11+ 用户改口径＝「取消倾斜，走垂直」） | 旧 `applyTlSlant`＋`--tl-slant-x`/`--tl-slant-deg`＋`skewX` 与 `.is-tl-tree > *{left:var(--tl-slant-x)}` **全部删除**——`skewX` 会把 elbow 的圆角剪成不对称歪弧＝「走向难看」的直接来源之一。现口径＝轨道垂直一段到底、只有出针处一个小圆角。**坑位（若要回到「向右下漂」）**：别再用 `skewX` 剪 elbow（应改成整段线性位移＋段端逐段对齐），并留意 `left` 位移不能改用 `transform`（会给行造层叠上下文、破坏 `z-index:-1` 的线被卡片盖住） |
| 固定卡片宽＋卡片挂在轨道 X 上（v0.4.9+ 用户两轮要求＝卡片不占满整宽、宽度变小、**卡片开始位置从本行时间线的 X 轴起**；v0.4.11+ 横坐标改由 JS 实测写值） | 模块级常量 **`TL_TREE_CARD_W=240`**（事实源＝timeline_view.ts，`renderTlTree` 写进容器 `--tl-card-w`，CSS 兜底同值）。`styles.css` `.aw-tl-list.is-tl-tree .aw-tl-item`＝`margin-left:calc(var(--tl-x, 4px) - 14px)`（`--tl-x`＝`layoutTlLanes` 给每行写的**所挂轨道 X**＝list padding-box 坐标；list `padding-left:14px` ⇒ 盒左缘恰＝轨道 X；根事件未被写值＝默认 4px＝主轴圆心线）＋`padding-left:24px`＋`width:calc(30px + var(--tl-card-w))`（border-box＝24 内衬＋240 卡宽＋6 右边距）＝**各深度卡片同宽**。**同宽＝实测布局成立的前提**：行高与该行走哪条轨道无关 ⇒ 可以先按默认 X 排版、再实测 Y、最后写 X，坐标不自我循环。坐标连锁：`.is-tl-tree .aw-tl-item > .aw-tl-dot{left:0}`（translateX(-50%) 后圆心＝盒左缘＝轨道 X）；横向滚动区＝`setContentWidth(maxX + TL_TREE_CARD_W + 38)`（`maxX`＝`layoutTlLanes` 返回的最右轨道 X） |
| 层级（v0.4.9+ 用户要求＝**事件卡片要在绘制的时间线上面**） | 轨道 `.aw-tl-rail` 挂 `z-index:-1`：最近层叠上下文＝zoomEl 的 transform ⇒ 负层先画、卡片盒（position:relative z-auto）连同文字/徽章后画＝**卡片盖住轨道穿过的部分**；圆点保持 z-auto＝仍压在出针处与卡片左缘角上。卡底必须不透明才盖得住线＝`color-mix(in srgb, var(--tl-lv-color, …) 10%, var(--background-primary))`（级别色淡染；五级五色＝核心调色板 `--color-red/orange/yellow/green/blue`，原 `--hN-color` 标题色因多数主题同色已弃用）＋前一行 `--background-primary` 兜底＋`outline:1px solid 级别色`（**用 outline 不用 border**＝不参与布局，卡片宽/轨道 X/圆点坐标全不动）；hover 淡染 18% 须显式补同权重规则（常驻底 (0,3,0) 压过通用 `.aw-tl-item:hover` (0,2,0)）。**几何推论（＝用户投诉「子时间轴难看」的根因，动笔前必读）**：卡片宽 240、列距只有 56 ⇒ 任何更深一层的轨道**必然**穿过更浅层事件的卡片，线只能「藏在卡片后面、只在通道与留白里露出」；所以轨道必须**一个父事件一条、各占自己的 X**（见「通道分配」），否则同 X 上不同子树的线段会被读成一条虚线、归属不清 |
| 通道分配＝不同一级事件的子时间线不得糊成一条（v0.4.11+ 用户明确要求处理「不同一级事件都有子时间线时、它们在时间上的重叠」） | `assignTlLaneXs(items, axisX, step, vgap)`（`src/timeline_lanes.ts`，纯函数）按**先序**（父先于子）逐个处理：基准 X＝`parentId` 已分配的 X ＋ `step`（一级事件＝`TL_AXIS_X`）；若与**已放置轨道**在同一个 X（差 <0.5）且纵向区间重叠（含 `TL_RAIL_VGAP=8` 缓冲）就整体再右移一个 `step`，最多试 32 次。⇒ 时间上互不相干的两棵子树**复用**同一条通道（不无谓右移、不横向膨胀）；纵向交错的（全局时间序下不同一级事件的子事件会互相插）各占一条。孙层基准＝父轨道 X ⇒ 逐层右移 |
| 旧列坐标公式退场（v0.4.11+ 坑位） | `.aw-tl-list` 的 `--tl-indent`/`--tl-guide-start` 与「列 k＝guide-start＋(k−1)×indent」公式随「逐行通高列线」一起退场，现只作旧口径兜底保留（`.aw-tl-dot` 基线 `left` 与 `.aw-tl-item` 基线 `padding-left` 仍引用它们，但树挂趟里两者被 `.is-tl-tree` 规则覆盖＝圆点 `left:0`、卡片 `padding-left:24px`）。**新代码不得再用 `--tl-d` 推横坐标**：行横坐标单一来源＝内联 `--tl-x`（`tl-d<N>` 类只保留深度语义与样式兜底） |
