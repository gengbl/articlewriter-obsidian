# L3 · 时间线面板（TimelineView）实现细节

时间线面板模块的实现级说明（源文件职责，含 readTimelineDocs 与接线部分）；模块级行为见 [l2-timeline-panel.md](./l2-timeline-panel.md)。

## 相关源文件

| 文件 | 职责 |
| --- | --- |
| `src/timeline_view.ts` | **时间线面板**（v0.2.x+，自定义 ItemView「时间线」，view type `articlewriter-timeline`，命令 `timeline-panel`＋ribbon `history`）：纯展示只读视图——数据全部来自 main.ts `getTimelineSnapshot()` 注入的 TlSnapshot{workDir, stories, activeStory, activeStoryTitle, useVolumes, rows:TlRow[], totalCount, unparsedDocs}；TlRow extends TimelineEntry ＋ {scope:"book"|"volume"|"chapter", sourcePath, sourceLabel(层级标签)}——三层条目已在快照阶段合并并按 (年,月,日) 升序排好。头部＝筛选输入框（按人物/事件关键字模糊过滤）＋「刷新」按钮（不显示工作目录行与小说列表）；主体 renderBody 渲染单一纵向时间轴自上而下（`.aw-tl-list` 左边线＋`.aw-tl-item` 圆点），每条＝时间点徽章（timelineTimeText）＋来源层级标签（`.aw-tl-src`）＋人物 chips（`.aw-tl-char`）＋事件多行文本，条目带 `is-<scope>` 类按来源层级区分重要性（书 > 卷 > 章：书籍级节点圆点最大＋正文加粗、卷级基准、章级节点最小＋正文弱化），尾随汇总行（总条数／各层分布，筛选时显命中数）；unparsedDocs（有内容但零有效条目）在列表下方给可点击提示（openFile 打开检查格式）。**双击条目**经 openAt：workspace.getLeaf().openFile 打开该文档 → locateHeading 在 MarkdownView.editor 的行内找匹配的 `## <时间点>` 标题（按解析值比对、兼容未补零写法；250ms 重试一次，移动端无 editor 降级仅打开）并 scrollIntoView 居中。空态区分「未选择小说」与「尚无时间线」（附三层放置位置与日期格式提示）。渲染陷阱见 [l3-view-rendering.md](./l3-view-rendering.md)「常驻 ItemView 渲染陷阱」（onClose 置 built=false 以便重开重建）。样式 styles.css `.aw-tl-*` 类 |
| `src/story_manager.ts`（时间线只读枚举部分） | **v0.2.x+ 时间线文档只读枚举**：`TimelineDocSource`{scope:"book"|"volume"|"chapter", label, path, text, volId?} + `readTimelineDocs(storyName)` 全程非交互探测三层《时间线.md》（书根仅裸名；卷目录新格式 `<卷名>-时间线.md`→缺失回落裸名；章节目录经私有 `probeTimelineInDir(dirPath, folder)`＝新格式 `<NN-标题>-时间线.md`→裸名，均缺失记候选路径＋空文本供展示侧空态）；顺序＝有卷模式：书籍级→书根未归卷章(num升序)→各卷按阅读序紧随其成员章(num升序、条目带 volId)，无卷模式：书籍级→全部章节(num升序)。不写盘。**《时间线》已入模板清单**：rootDocTemplates/chapterDocTemplates/volumeDocTemplates 各加 ["时间线.md", story_types.timelineTemplate(h1Title)]（书八件套/章七件套/卷五件套），与建书/建卷/建章播种及 ensure*/rescan 补缺同一来源；不参与提示词注入。其余部分见 [l3-state-and-volumes.md](./l3-state-and-volumes.md) |
| `src/main.ts`（时间线面板接线部分） | **v0.2.x+ 时间线面板接线**：`registerView(TimelineView.VIEW_TYPE)`（注入快照 getter）＋命令 `timeline-panel`「打开时间线面板」＋ribbon 图标 `history`＋`openTimelinePanel()`（已有叶子则激活、否则右栏新建，与写字台同屏）；`getTimelineSnapshot()`＝非交互聚合——activeStory 守卫→`manager.readTimelineDocs(当前书)`→逐源 `md_docs.parseTimelines` 合并为单一 rows 列表（每行带 scope/sourcePath/sourceLabel）、按 (time, month??0, day??0) 全局稳定升序；原文非空但零有效条目的文档进 unparsedDocs 供展示侧格式提示，无激活书返回空快照；`scheduleTimelinePanelRefresh()` 已并入统一入口 `schedulePanelRefresh()`（写字台＋关系＋时间线三面板共用防抖刷新）。其余部分见 [l3-main-ts-flow.md](./l3-main-ts-flow.md) |
