# L3 · work_dir 与每书工作区实现细节

work_dir 初始化与每书独立工作区模块的实现级说明（源文件职责：使用说明投放 / main.ts 工作区相关部分）；模块级行为见 [l2-workdir-story-switch.md](./l2-workdir-story-switch.md)。

## 相关源文件

| 文件 | 职责 |
| --- | --- |
| `src/usage_guide_default.ts` | 《使用说明.md》**内置默认文本**（DEFAULT_USAGE_GUIDE：快速上手/命令一览/常驻面板@引用语法/设置项/目录结构/常用标记速查，面向 vault 内用户、勿引用仓库路径）。两个投放点同源——①pickWorkDir 回调内 `seedUsageDoc()` 在设置/切换工作目录后自动写入 work_dir 根、②`generate-usage-doc` 命令手动重建（成功后 openMarkdown 打开）、③**v0.4.7+ 每次启动自检 `syncUsageDocOnStartup()`**——三处统一按文件里的**版本戳**判定（`src/usage_doc_stamp.ts`：缺失/为空/无戳/戳版本≠`manifest.version` 才重建并打开，升级＝直接覆盖不留备份、已是当前版本＝跳过）；写出文本＝内置正文＋首行注释戳＋一行可见版本提示。内容为独立文档 [docs/使用说明.md](../docs/使用说明.md)（esbuild `.md=text` 打包内联），更新用法直接编辑该 md；**v0.4.10+ 图片占位符**＝md 里 `{{WECHAT_QR}}` 在 `usage_guide_default.ts` 导出前替换为 wikilink `![[articlewriter-wechat-qr.png]]`，图片本体（docs/wechat_qr.png 经 `.png=dataurl` 内联进包）由 main.ts `writeUsageQrAsset` 解码 `writeBinary` 投放到说明同目录＝**资源文件而非内联**（阅读模式不渲染 md 内联 data: 图＝空白）；启动自检版本一致时若资源缺失也会补投 |
| `src/main.ts`（v0.4.7+ 启动无书引导） | `guideNewStoryOnStartup()`（onload 里 `void` 调用，紧随 `syncUsageDocOnStartup`）：`settings.noStoryGuideOff`＝true 直接返回；`workDir` 为空＝弹「先选工作目录，再建一本书」变体（CTA→`pickWorkDir(true)`）；`workDir` 存在但不是 TFolder＝不弹（失效目录走命令里的重选路径，不叠引导）；否则 `manager.listStories()`（抛错＝console.warn＋不弹）非空＝不弹、为空＝弹「先建一本书，开始写小说」变体（CTA→`cmdNewStory()`，另有 `pickWorkDir(false)`／打开《使用说明.md》）。弹窗类＝`src/modals.ts` **`AwGuideModal`**（通用引导弹窗：h3 标题＋`p.aw-prompt-hint`（pre-line 多行）＋`Setting.addButton` 动作组，`cta:true` 设主按钮；任一动作＝先 `close()` 再执行（模态遮罩让位），Esc/遮罩＝无动作）。开弹窗时机＝**`runWhenLayoutReady(cb)`**（v0.4.7+ 从 `openWhenLayoutReady` 提取的共用件：`workspace.layoutReady` 短轮询 250ms＋`registerInterval` 托管清理；`openWhenLayoutReady` 现为它的薄封装）。设置行「无小说时弹出建书引导」＝`control.key:"noStoryGuideOff"` 且**显示取反**（getter `s.noStoryGuideOff !== true`／setter `s.noStoryGuideOff = value !== true`，缺省 undefined＝开）；面板「不再弹出」→`disableNoStoryGuide()`＝置 true＋`saveSettings()`＋Notice 指路设置页 |
| `src/main.ts`（每本书独立工作区部分） | **v0.2.1+ 每本书独立工作区**：`bookWorkspacePath(story)`＝`.obsidian/plugins/<id>/workspaces/<书名>.json`、`captureBookWorkspace(story)`（getLayout→JSON `{v,platform,layout}` 尽力存档）、`loadBookWorkspace(story, closeIfNoArchive?)`（changeLayout 恢复；跨端/损坏静默 false，成功 Notice；无存档且 closeIfNoArchive=true → `closeOpenDocs()` 关主编辑区全部 markdown 页签[iterateRootLeaves+detach]）、**`applyStorySwitch(next, closeIfNoArchive?)`＝所有改 lastStory 路径的统一入口**（归档旧书→写回 saveSettings→恢复新书；重选同书 no-op；仅 `switch-story` 选择器、写字台下拉框、新建书三个显式切书点传 true）＋ onload 订阅 workspace `layout-change` 防抖 1500ms 自动存当前书（3s 窗过滤自身 changeLayout 回声）；rename/delete-story 迁移/清理存档文件——语义细节见 [l2-workdir-story-switch.md](./l2-workdir-story-switch.md)「行为约定」v0.2.1+ 条；**v0.2.20+ `ensureStatusInLeftSidebar()`**：写字台常驻左栏视图切换列表——iterateAllLeaves 先查已有 StatusView 叶子（幂等守卫），无则 `ensureSideLeaf(StatusView.VIEW_TYPE, "left", {active:false, reveal:false})` 补 tab（不抢焦点、不展开抽屉、失败静默，命令/ribbon 仍可手动打开）；两个触发点＝onload `onLayoutReady`（启动自动补位）＋`loadBookWorkspace` changeLayout 成功后（全量替换会抹掉左栏——存档未含写字台时——立即补回保持常驻）；双端统一不做平台分支。其余部分见 [l3-main-ts-flow.md](./l3-main-ts-flow.md) |
