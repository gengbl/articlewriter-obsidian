# L2 灵感工具包（案头资料/灵感/灵感.md）

一个「一处攒全书灵感、随时跳回去」的最小工具：**一条命令、一份文件、每个灵感一个块**。实现在 main.ts 命令侧＋`src/inspiration.ts` 纯逻辑（见 [l3-inspiration-impl.md](./l3-inspiration-impl.md)）。

## 落盘约定

- 位置：**书级《案头资料/灵感/灵感.md》**（`deskDocsPath(story)/灵感/灵感.md`）。写字台「案头资料」小节里以一个 `灵感` 文件夹行出现，可展开看到该文件。
- 全书灵感都写在这一份文件里（不是一条灵感一个文件）——拆文件会让「跳到某条灵感」变成开一堆标签页。
- 文档头＝一个一级标题（`# 灵感（书名）`）＋一段说明注释；**每条灵感＝一个二级标题块**：

  ```markdown
  ## 雨夜追凶 · 2026-11-14

  主角在雨里只凭声音认出了凶手。

  ### 可以用在哪里

  - 第 3 章
  ```

- 块标题＝「灵感名 · 日期」（`YYYY-MM-DD`，新增当天的本地日期）。用户不给灵感名 → 名字用「**未命名**」＋日期。
- 只有**二级标题**切块：块内的 `###` 及更深标题属于这条灵感的正文；`#` 一级标题收尾当前块。手工往文件里加 `## 标题` 也算一条灵感（日期可以省，省略时该块没有日期）。

## 命令与入口

| 入口 | 行为 |
| --- | --- |
| 命令面板「灵感工具包」（`inspiration-kit`） | 打开当前书的灵感工具包弹窗 |
| 写字台「案头资料」小节标题行／组内空白 右键 →「灵感工具包…」 | 对**该书**的灵感文件操作（不必先把书切成当前书） |
| 写字台「案头资料/灵感」文件夹行 右键 →「灵感工具包…」 | 同上（仅该文件夹行有此入口） |

## 弹窗语义（一个弹窗内完成全部操作）

- 顶部：文件路径＋条数统计；搜索框按**名字或正文**过滤，**回车＝定位到当前过滤结果的第一条**。
- 每条灵感一行：名字（粗体）＋日期＋一行正文摘要（注释/列表标记剥掉、超长截断）。行本身＝定位。
- 行右侧三个按钮：
  - **定位**：在编辑器打开灵感文件，把该块标题行滚到视口中央（共用件 `src/editor_nav.ts`：`openFileAtLine`，与时间线面板同一套「打开＋跳行」动作，含 0/250ms 两次尝试以躲开编辑器装载慢）。
  - **改名**：弹输入框（预填现名）→ 只换块标题，日期不变、**块内正文一字不动**。
  - **删除**：先确认框（显示该块摘要）→ 只移除这一块，其他灵感与文件本身保留；删除**不关弹窗**，列表即时刷新，可接着删下一条。
- 底部三个按钮：
  - **新增灵感**：先问灵感名（**留空＝未命名＋今天日期**）→ 按模板在文档**末尾**追加一个灵感块 → 打开文件并定位到刚追加的块，等用户填充（填完直接在 Obsidian 里保存，工具包不做二次确认）。
  - **打开灵感文件**：只打开文件（定位到文档头）。
  - **编辑灵感模板**：在编辑器打开系统技能 `SKILLS/灵感模板.md`。
- 「定位／改名／新增／打开文件／编辑模板」都会**先关掉工具包弹窗**（模态遮罩要让位给编辑器或下一个弹窗）；只有「删除」留在弹窗里。

## 灵感块模板走 SKILLS/（可编辑）

- 模板事实源＝系统技能 **`SKILLS/灵感模板.md`**（`DEFAULT_SKILLS["灵感模板"]` 播种、**仅缺失才写**、用户改过的不覆盖；误删后新增灵感时会先重播种一次，仍缺才回落内置文本）。
- 模板约定（渲染器 `renderInspirationBody` 负责兜住）：
  - 文件自己的 H1 与 HTML 注释块**不进灵感块**（块标题由插件生成）；
  - 模板里出现的一/二级标题会被**自动降为 `###`**，防止破坏灵感块的二级边界；
  - 占位符 `{{name}}`（灵感名）、`{{date}}`（日期）、`{{time}}`（日期时间）由插件替换。
- 它**只是文档模板、不参与提示词装配**：不要在引用文档清单里写 `skill:灵感模板`（会把它当写作技能注入提示词）。

## 与手工编辑共处

- 每次写盘前都**重新读取并解析**文件，按「标题＋行号 → 标题」两级回查用户点的那一条（弹窗里缓存的块对象会因手工编辑或上一次增删而失效）；回查不到就只提示、不改动。
- 增删改后必须用 `parseInspirationDoc` 的新结果回填弹窗（`setBlocks`），旧行号一律作废。
- 写文件走 `manager.writeGuideAt`（连父目录一起创建、存在则覆盖），读走 `manager.readDoc`；换行风格保住原文件（CRLF 文件不会被改成 LF）。
