| `src/story_manager.ts`（人物关系数据入口部分） | **v0.1.9+ 人物关系面板数据入口**：公开只读 `readRelationshipDocs(story, chapterKey?)` 一次返回书根 / 当前卷（键所属卷、缺省 current_volume）/ 当前章（chapterKey 缺省 current_chapter）三层《人物关系.md》的 `RelationshipDocSource[]`（`scope`/`label`/`path`/`text`；书根带「角色关系.md」旧别名兜底，定位不到或文件缺失的层按需省略/空 text），内部复用私有 `readDoc` + `resolveVolumeDocPath`/`resolveChapterDocPath`，不写盘、不统计字数。**v0.2.0+ 人物写入扩展**：`appendRelationships(story, scope, entries, { volId?, chapterKey? })` 把 `md_docs.RelationshipEntry[]` **追加**到指定层级的《人物关系.md》（book=`<书根>/人物关系.md`、volume=`resolveVolumeDocPath(卷目录,…,人物关系.md)`（先 `ensureVolumeFolder`）、chapter=`resolveChapterDocPath(章目录/人物关系.md)`），文档缺失或为空时按该层模板（书/章=`CHAPTER_RELATIONSHIPS_TEMPLATE`、卷=`VOL_RELATIONSHIPS_TEMPLATE`）起底、已有内容原样保留，返回实际写入路径；`characterFilePath`/`saveCharactersFile` 支持**卷级人物**（`chapter=0 && vol` → 写 `resolveVolumeDocPath(卷目录, 卷名, 人物.md)`、H1 用卷名），`addCharacter` 相应允许 `chapter=0 + vol`（v0.2.0 前 `chapter=0` 一律强制忽略 vol 落书根）。其余部分见 [l3-state-and-volumes.md](./l3-state-and-volumes.md) |
| `src/main.ts`（人物关系面板接线部分） | **v0.1.9+ 人物关系面板接线**：`registerView(RelationshipView.VIEW_TYPE, …)` 注入快照 getter + v0.2.0+ **`onAddCharacter` 写动作回调**（面板展示仍只读，无切书回调——切书走写字台或 `switch-story` 命令；「添加人物」由 main.ts `openAddCharacterDialog()` 承载：`activeStory()` + `loadAllCharacters` 按层级算候选 → `loadState` 取 current_chapter/current_volume 定默认归属并把默认项置顶 → 弹 `AddCharacterModal(scopes, allNames, RELATION_TYPE_OPTIONS)`（模块常量：师徒/同门/朋友/同伴/恋人/亲族/主仆/敌对/对手/盟友，均命中 relationship_view 类型正则）→ 提交后 `manager.addCharacter`（章级 `parseChKey` 取 num/vol，卷级 `chapter=0 + volId`，书籍级 `chapter=0` 无 vol）+ 关系非空时 `manager.appendRelationships` 写同层级《人物关系.md》（status 默认 `active`）→ `schedulePanelRefresh(300)`）、命令 `relationship-panel`、ribbon `users` 入口、`openRelationshipPanel()`（已有则 setActiveLeaf，否则经 `getPanelHostLeaf()` 取承载叶子：桌面端右栏叶子 `getRightLeaf` 承载〔与左栏写字台同屏〕；移动端右栏无 UI 入口调不出来，改分割主区域 `getLeaf("split")` 承载〔与 LLM 对话窗口相同〕）、`getRelationshipSnapshot()`（只读聚合：工作目录 + 小说列表 + 当前书三层关系解析，逐层容错）、`scheduleRelationshipPanelRefresh()` 与合并入口 `schedulePanelRefresh()`（写字台 + 关系面板共用；vault modify/create/delete/rename 与 `notifyContextChanged` 均已改走它）。其余部分见 [l3-main-ts-flow.md](./l3-main-ts-flow.md) |
