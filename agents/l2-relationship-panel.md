# L2 · 人物关系面板

## 模块概要

- **v0.1.9+ `RelationshipView`（人物关系面板）同属常驻 ItemView 家族，v0.2.0+ 头部带「添加人物」、v0.4.11+ 新增「＋ 关系」**：注入快照 getter + **可选 `onAddCharacter`／`onAddRelationship` 写动作**（展示仍只读；切书/切章入口一律留在写字台与命令面板，业务逻辑/弹窗/落盘都在 main.ts，面板只回调不持有业务实现）、UI 建在 onOpen 的 contentEl、onClose 只管 `edgeTipEl.remove()`（tip 挂 document.body）；**头部＝「卡片 / 图表」分段切换按钮 + 筛选框 + 「＋ 关系」（v0.4.11+，未选小说时 disabled）+「添加人物」（未选小说时 disabled）+「刷新」**（不显示工作目录行与小说列表，未选小说/未设工作目录时在主体区给引导文案）；两种展示方式（`mode`，**默认＝图表**——v0.4.8+ 初值由 `list` 改 `graph`；会话内保持不落盘）共享同一份 `lastSnap`——卡片走 `renderTree`、图表走 `renderGraph`（**纯手写 SVG，不得引入 d3 等图形依赖**），切换与筛选只重渲染主体区而**不重建头部**，避免输入焦点/光标丢失；图表的高亮/布局全本地计算（`buildGraph` 聚合 + `focusGraph` 邻接高亮；`graphNodeEls`/`graphEdgeEls`/`graphAdj` 每次重渲染重建）；**v0.4.4+ 图表布局与连线重做**：①不再把人物等分在一个圆环上（登记顺序＝随机排布、主次不分、主角找不着），改**退火式力导向**（`forceLayout`）——枢纽（＝连线最多的人物，通常就是主角）摆到**画布中央偏上**（`hubUp`，即用户要的「把主角向上提」）、与其至亲聚在中心、次要人物被推到外圈，两轴摊满画布并做硬碰撞消解使圆点互不压着；②人物**按连线数分级**——圆点半径与角色名字号都随关系多少变大（`nodeRadius`/`labelFontSize`），枢纽另加 `.is-hub`（实心描边更粗）并最后绘制以叠在最上层；③连线一律画**向上拱的弧线**、不画直弦（每条边从起点往上方兜一圈再接到终点，走向一眼可追；端点按各自节点半径裁到圆周外、竖直弦向右拱、靠顶边的边自动变平不顶出 viewBox），默认半透明细线、悬停那条才提亮到不透明，角色名带描边光晕（`paint-order:stroke`）以免被线压住；**v0.4.8+ 按住拖动期间不响应悬停**——鼠标已按下起拖后扫过节点/连线不再触发变色高亮、也不弹边 tip，松手（真拖过）时自动清掉残留高亮）；布局与弯曲几何都是纯计算，集中在 `src/graph_layout.ts` 并带单测——调观感的旋钮：`CURVE_RATIO`/`CURVE_MIN_BOW`/`CURVE_MAX_BOW`（弯曲度）、`COLLIDE_GAP`/`LABEL_ROOM`（疏密）、`hubUp`（主角上提幅度）、`centerName`（改居中人物，＝面板 `graphCenter` 传入；非空且在点集内＝钉正中、忽略 hubUp）。**滚轮缩放 + 拖动平移**（v0.2.0+ 已移除摘要行下方的「缩小 / 放大 / 重置视图」缩放条，缩放只用滚轮）：档位 `GRAPH_ZOOMS`〔0.5/0.75/1/1.25/1.5/2/3〕，`graphZoom` 与 `graphPan`〔屏幕像素偏移〕均会话内保持不落盘，`applyView()` 只写 `svg.style.transform = translate(pan) scale(zoom)`——**布局尺寸不变**（`width:100%`、`height:auto`、`max-height:70vh`），靠 viewBox 让图形与角色名一起等比缩放、不重算布局、不重建 DOM，`transform-origin: center` 令缩放围绕图心；滚轮用 `zoomAt(dir, mxView, myView)`：接 viewport 坐标、内部经 `getBoundingClientRect()` 换算到 svg layout 偏移（与 `ec = clientWidth/2` 同坐标系——早期版本把 viewport 像素与 layout 像素混算，z≠1 时"鼠标不动点"会漂移）后以鼠标位置为不动点反求 pan（公式 `pan' = m - ec - k·(m - pan - ec)`，`k = z'/z`），保证缩放前后**鼠标下的图点屏幕位置不变**；滚轮在 svg 上 `wheel` 监听（`{passive:false}` + `preventDefault` 防冒泡触发主滚动条），`deltaY` 累计 `|>=50|` 时按符号切档（上滑=放大、下滑=缩小，闭包 `wheelAcc` 在切档后清零），已达档位边界时切档早退故累加器不会"卡"；`applyView` 内用 `treeEl.clientWidth/Height` 与 `svg.clientWidth/Height × zoom` 收敛平移量（`clampNum`），**图不会被拖出视野找不回来**。拖动 = svg 上的 `pointerdown` + document 级 `pointermove/pointerup`（拖出面板也跟手，松手即解绑），位移 >3px 记 `dragged` 并在捕获阶段 `stopPropagation` 吃掉随后的 click，避免「拖到一半松手」误打开角色/关系文档（未拖动的单击照常放行）；`.aw-st-tree.is-graph` 改为**裁剪**（`overflow:hidden` + flex 纵向收缩，图例不会被裁到面板外）——**面板不出滚动条**，放大后被裁掉的部分靠拖动查看，故重渲染不再需要保持 `scrollTop/scrollLeft`，空态文案由 `placeholderFor` 两处共用；开合与筛选是纯展示态（`lastSnap` + 本地重渲染，不读盘）；整卡**双击**打开来源文档（`getLeaf().openFile`；v0.2.0+ 由 click 改 dblclick，单击不触发以免误开）；**图表连线双击（v0.4.11+）＝编辑关系弹窗（不再打开来源文档）**，右键连线＝编辑／删除关系菜单；**v0.4.9+ 人物上的两套交互（用户要求）**＝**双击人物＝只弹人物编辑弹窗**（v0.4.9+ 用户要求＝**此外无任何别的响应**：不顺带选中/重绘整图、也不选中文字——故「单击＝选中」压 220ms 由 `pickCharLater` 落地、双击到达即 `cancelCharPick`，`onClose` 也清定时器；旧 v0.4.8「双击＝以该人物为中心重画」已移入右键菜单）＋**右键人物＝人物菜单**（`openCharMenu` 一份实现三处挂载＝图表节点 `contextmenu`、「人物状态」区每块 `contextmenu`、卡片模式关系卡里的角色名 `bindCharMenu`；**顺序照用户要求固定**＝**编辑人物「X」排第一** → 改名「X」（复用 v0.2.x+ 已有的 `onRenameCharacter`＝main.ts `renameCharacterFlow`）→ 打开来源文档（该人物《人物.md》，未登记回退关系文档）→ 设为中心人物（已是中心者变「恢复默认中心」）→ 新增人物 → **删除人物「X」恒排最后**（前五项共用 `setSection("aw-rel-char")`＝组内不画分隔线，删除用 `setSection("danger")`＝Obsidian 只在 section 变化处画线且该组落尾，同 `scene_view` 卡片菜单口径）；未注入写动作回调的那一项自动不出现）；`graphCenter` 会话内保持、现仅由菜单驱动（默认中心＝《人物.md》身份/备注标了「主角/主人公」的角色钉**画布正中**，无标注回退连线最多者居中枢轴——`forceLayout` 参 `centerName`）；**编辑弹窗＝`modals.CharacterEditModal`（main.ts `openEditCharacterDialog`）**＝人物级别（可换层，见下）＋姓名（改名走 `renameCharacterTo` 全书同步替换＋备份）＋八个设定字段，命令「管理人员 → 编辑信息」与面板「编辑」链接共用同一弹窗（代码重用）；**删除走 `deleteCharacterByName`**（确认框 → `manager.deleteCharacter` 连带清理场景引用，命令与面板共用）；「人物状态」区每块另有「编辑」链接（悬停 title＝`docLocationLabel(scope, sourcePath, snap.storyDir, REL_SCOPE_WORDS)`＝`书籍级 · 案头资料/人物.md` 一类书内位置）——图表**单击节点＝选中**：底部固定「人物状态」区显示该角色在《人物.md》的设定信息（层级标签＋「打开文档」＋身份/年龄/性别/性格/外貌/背景/能力/备注字段行、未填项跳过，同名多层登记逐层各一块，《人物.md》无记录时提示用「添加人物」补录；× 清除，`selectedChar` 会话内保持；拖后伪点击被捕获阶段拦截不误选）、选中节点 `.is-sel` 强调描边，分组头右侧「打开文档」仍为单击、须 `stopPropagation` 以免连带触发开合；容器类直接复用 `.aw-status-view` + `.aw-st-top/.aw-st-tree`（字体/滚动布局同写字台），专属样式只用 `.aw-rel-*`，勿另造容器布局样式。
- **人物右键菜单多一项「合并 N 处登记」（v0.4.11+ 人物信息合并）**：该人物登记在**两份以上**《人物.md》时才出现（＝`charEntryCount(name)>1`，取快照 `chars` 同名条目数），「人物状态」区头部也同步出现「合并（N 处登记）」小链接；点击＝main.ts 的 `openMergeCharacterFlow`（面板只回调、不自持业务）＝弹窗**先选最终存储文档**、再逐字段取哪份登记／全部保留／留空、带条目预览，确认后块级写回并先备份（细节与口径见 [l2-setting-entities.md](./l2-setting-entities.md)「人物信息合并」条）。
- **图表的缩放/平移＝整体复用画布共用设施 `CanvasPanel`（v0.4.11+ 重写，用户三轮反馈后废弃面板内自写的 transform 数学）**：面板主体 `.aw-st-tree.is-graph` 就是画布视口（`overflow:auto`），内部由 `CanvasPanel` 建 sizer→pan→zoom 三层（`parentBodyEl` 复用既有元素）；图例、「人物状态」区与分隔条仍是主体的普通固定子项＝不缩放也不滚动。**图尺寸＝画布可视区（viewBox 与真实像素 1:1，见 `graphBoxSize`）**，力导向布局就在该尺寸内跑＝内容坐标与画布换算坐标同一套；面板比画布窄时 `setContentWidth` 撑出横向滚动/拖动范围。上方不再展示统计说明行（卡片模式统计行照旧保留），图下方两行图例（边色／线型）保留。
- **图表里「名字文字」与「圆点」是同一颗人物＝鼠标行为完全一致（v0.4.11+ 用户要求）**：悬停高亮相邻、单击选中（220ms 延后那套）、双击弹编辑人物弹窗、右键出人物菜单、按住拖动整图平移——点在名字上跟在点在圆点上一模一样。**实现口径＝事件本来全挂在节点 `<g>` 上**（`click`/`dblclick`/`contextmenu`/`mouseenter` 一个监听器共用），差别只在 CSS：旧版 `.aw-rel-gname{pointer-events:none}` 把文字整块踢出命中区＝只有圆点有反应（那行注释还写反了）。现改为 `pointer-events:auto` ＋ `cursor:pointer` ＋ `user-select:none`＝命中范围＝字形轮廓＋ `paint-order:stroke` 那圈 3px 描边光晕（描边参与 hit-test），按住名字拖也不会选中文字（svg `pointerdown` 另有 `preventDefault`）。节点 `<title>` 悬浮提示同步说明「圆点与名字文字＝同一颗人物」。另：图表主体上方不再渲染统计＋操作说明行（见下条）。
- **图表 tip＝人物（圆点／名字文字）与连线共用同一份浮层、同一样式；右键时 tip 立刻收起（v0.4.11+ 用户要求）**：节点此前用 SVG `<title>`（浏览器原生 tooltip＝多行被截断、样式跟连线不一致），现改挂同一份 `.aw-rel-gtip`（`position:fixed` 跟手、越界自动翻向、`pointer-events:none`）；`mouseenter`/`mousemove`/`mouseleave` 口径与连线完全相同。连线与节点的 `contextmenu` 都先 `hideGraphTip()`＝**在关系线或名字／圆点上右键，tip 必须消失**（右键不产生 mouseleave，不主动收就会一直挂在菜单旁）。共用一份浮层带来归属问题＝`graphTipOwner` 记录当前显示方，`hideGraphTip(owner?)` 只在归属相符时才隐藏，交叠处节点进出不会误关掉连线刚弹的 tip；拖图松手、重渲染（`renderBody`）、视图卸载则无条件清。
- **节点 tip 的内容＝人物信息，不是操作提示；图面上不再有浏览器原生长条 tooltip（v0.4.11+ 用户要求）**：鼠标停在人物（圆点或名字文字）上＝显示该人物在《人物.md》里的设定（首行「名字 · N 条关系」＋身份/年龄/性别/性格/外貌/背景/能力/备注，取数与「人物状态」区**同一口径** `charInfoFields`）；多文档登记＝每份文档一段（标题＝`层级 · 书内位置`）；字段值超 60 字截断（完整内容看状态区／编辑弹窗），未登记者只写一行「《人物.md》里还没有这个人物的设定」。**tip 里不写「双击＝编辑／右键＝菜单」这类操作口径**——操作说明统一挪到图下方第二行图例。那条长条提示的来源是 svg 的 `<title>`（Blink 对没有自身 title 的后代会回落到最近带 `<title>` 的祖先＝悬停人物／连线时与自定义方块同时弹出两个），**现在 svg／节点／连线一律不挂 `<title>`**。
- **滚轮与缩放口径＝与场景/时间线面板一字不差（v0.4.11+ 用户要求＝「每次滚轮的值不叠加，重新计算一次」＋「参考场景面板的放缩放」）**：`Ctrl`（或 `Shift`）＋滚轮＝**以鼠标位置为不动点连续缩放**（每事件独立算一次 `zoom × exp(−deltaY×0.0015)`，夹在共用常量 `PANEL_ZOOM_MIN`(40%)~`PANEL_ZOOM_MAX`(300%)，行模式 deltaY 先 ×32）；**普通滚轮＝原生滚动画面、不缩放也不拦截**（旧版把普通滚轮当缩放＋把画面推出视野＝用户投诉「滚完找不到画面」的根因）。不动点数学＝`panel_canvas.zoomAtPointView`（先算虚拟偏移 `v＝pan−scroll`、`v′＝m−p·z′`，再回落 scroll/pan 两通道）＝**已有 node 单测逐档断言**，不再是面板内手推公式；sizer 宽高＝内容×倍率（撑出可滚动范围），虚拟平移层 `--aw-canvas-pan-x/-y` 负责「滚动用尽后继续挪视野」。
- **平移＝任意方向无限位＋找回入口常驻（v0.4.11+ 用户要求＝随意拖动；投诉＝「缩放后经常找不到画面，双击也没回来」）**：按住图面拖动＝先吃原生滚动余量、用尽后由虚拟平移层继续挪（跟场景画布同一混合口径），拖出面板外不算越界。**找回＝`CanvasPanel.resetView()`（倍率回 100%＋虚拟平移归零＋滚动回原点）**，入口四处＝头部「适应全图」按钮（图表模式才有，在「刷新」左边）、图面空白处右键菜单「适应全图／刷新」（照场景画布右键菜单）、双击图面空白处、点头部**倍率标签**（`Math.round(zoom×100)%`，100% 时隐藏，点它＝复位）。画布三层元素常驻不随重渲染销毁＝复位永远不会「写到已脱离文档的旧 svg 上」（旧版「双击没反应」的成因在结构上消除，也不再需要靠重画图兜底）。拖完松手紧随的 click/dblclick 由画布设施在容器捕获阶段吞掉（面板不再自记 `dragged` 标志）。
- **「人物状态」区（图表模式图下方）＝恒定高度＋多文档逐条展开项＋只能手动拖动改大小（v0.4.11+ 用户要求）**：**该区绝不自己变大变小**——选中谁、内容多少都不改变它的高度（超出就在区内滚动），因此点人物圆圈时图不会被挤得一跳一大截；**同一人物在多层／多份《人物.md》里登记＝每个文档一个展开项**（用户要求原话＝「人物在多个文档时，每个文档一个展开项」）＝一份登记一条折叠头「▸ 层级 · 书内路径 ＋ 打开文档 ／ 编辑」，**默认全部折叠**＝点开哪条看哪条（可同时展开多条），再点同一条收起；展开后是该文档的字段块（块内不重复文档位置）；换选别的人物全部回到折叠。整条折叠头是热区，但点上面的「打开文档」/「编辑」走各自动作、不翻展开态。**要改大小只能拖它上缘那条分隔条**（上下拖，限位＝最少 56px、且给图面至少留 120px；高度会话内保持、重启回落默认 150px）。另外**单击选中不再重建整张图**（旧口径会重跑力导向＋重建 DOM＝图与区一起跳），只换状态区内容＋给节点加选中描边，节点位置与大小全不变；改中心人物/筛选/切模式才重排图面。

- **「线型说明」图例行＝可折叠帮助行（v0.4.11+ 用户要求）**：图表下方第二行图例默认**收起**＝只留「线型：实线=进行中 · 虚线=铺垫中 · 点线=已结束」一句＋▸ caret；**单击整行**点开/收起（▾/▸），点开才显示「加粗＝多处登记」与滚轮缩放/拖动平移/双击适应全图/右键菜单/倍率标签/悬停看设定等操作口径；收起的意义＝行高还给图面（图尺寸＝固定行之外剩余高度，切换走整帧重排自动涨缩），倍率/平移/选中人物都不丢；细节见 [l3-relationship-view.md](./l3-relationship-view.md) ⑮。

- **面板尺寸跟随（v0.4.11+ 起交给画布设施）**：窗口/分屏/侧栏拖拽/移动端抽屉改变大小时＝`CanvasPanel` 自带观察器（`watchElementSize`，防抖 120ms）先 `apply()` 重算 sizer 与滚动限位；**宽度真的变了才重画图**（`onResize` → `renderGraph`＝图按新的画布可视区重新取尺寸与布局，与场景面板按宽度重排同理），纯高度变化不重渲染。**缩放倍率与已摆好的位置保持不动**（不自动缩放、不自动居中）。卡片列表本来就直接随容器伸缩。场景/时间线面板同一口径（只重算画布尺寸与滚动范围，宽度变化才重排内容）。
