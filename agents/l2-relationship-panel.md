# L2 · 人物关系面板

## 模块概要

- **v0.1.9+ `RelationshipView`（人物关系面板）同属常驻 ItemView 家族，v0.2.0+ 头部带「添加人物」**：注入快照 getter + **可选 `onAddCharacter` 写动作**（展示仍只读；切书/切章入口一律留在写字台与命令面板，业务逻辑/弹窗/落盘都在 main.ts，面板只回调不持有业务实现）、UI 建在 onOpen 的 contentEl、onClose 只管 `edgeTipEl.remove()`（tip 挂 document.body）；**头部＝「卡片 / 图表」分段切换按钮 + 筛选框 + 「添加人物」（未选小说时 disabled）+ 「刷新」**（不显示工作目录行与小说列表，未选小说/未设工作目录时在主体区给引导文案）；两种展示方式（`mode`，**默认＝图表**——v0.4.8+ 初值由 `list` 改 `graph`；会话内保持不落盘）共享同一份 `lastSnap`——卡片走 `renderTree`、图表走 `renderGraph`（**纯手写 SVG，不得引入 d3 等图形依赖**），切换与筛选只重渲染主体区而**不重建头部**，避免输入焦点/光标丢失；图表的高亮/布局全本地计算（`buildGraph` 聚合 + `focusGraph` 邻接高亮；`graphNodeEls`/`graphEdgeEls`/`graphAdj` 每次重渲染重建）；**v0.4.4+ 图表布局与连线重做**：①不再把人物等分在一个圆环上（登记顺序＝随机排布、主次不分、主角找不着），改**退火式力导向**（`forceLayout`）——枢纽（＝连线最多的人物，通常就是主角）摆到**画布中央偏上**（`hubUp`，即用户要的「把主角向上提」）、与其至亲聚在中心、次要人物被推到外圈，两轴摊满画布并做硬碰撞消解使圆点互不压着；②人物**按连线数分级**——圆点半径与角色名字号都随关系多少变大（`nodeRadius`/`labelFontSize`），枢纽另加 `.is-hub`（实心描边更粗）并最后绘制以叠在最上层；③连线一律画**向上拱的弧线**、不画直弦（每条边从起点往上方兜一圈再接到终点，走向一眼可追；端点按各自节点半径裁到圆周外、竖直弦向右拱、靠顶边的边自动变平不顶出 viewBox），默认半透明细线、悬停那条才提亮到不透明，角色名带描边光晕（`paint-order:stroke`）以免被线压住；**v0.4.8+ 按住拖动期间不响应悬停**——鼠标已按下起拖后扫过节点/连线不再触发变色高亮、也不弹边 tip，松手（真拖过）时自动清掉残留高亮）；布局与弯曲几何都是纯计算，集中在 `src/graph_layout.ts` 并带单测——调观感的旋钮：`CURVE_RATIO`/`CURVE_MIN_BOW`/`CURVE_MAX_BOW`（弯曲度）、`COLLIDE_GAP`/`LABEL_ROOM`（疏密）、`hubUp`（主角上提幅度）、`centerName`（改居中人物，＝面板 `graphCenter` 传入；非空且在点集内＝钉正中、忽略 hubUp）。**滚轮缩放 + 拖动平移**（v0.2.0+ 已移除摘要行下方的「缩小 / 放大 / 重置视图」缩放条，缩放只用滚轮）：档位 `GRAPH_ZOOMS`〔0.5/0.75/1/1.25/1.5/2/3〕，`graphZoom` 与 `graphPan`〔屏幕像素偏移〕均会话内保持不落盘，`applyView()` 只写 `svg.style.transform = translate(pan) scale(zoom)`——**布局尺寸不变**（`width:100%`、`height:auto`、`max-height:70vh`），靠 viewBox 让图形与角色名一起等比缩放、不重算布局、不重建 DOM，`transform-origin: center` 令缩放围绕图心；滚轮用 `zoomAt(dir, mxView, myView)`：接 viewport 坐标、内部经 `getBoundingClientRect()` 换算到 svg layout 偏移（与 `ec = clientWidth/2` 同坐标系——早期版本把 viewport 像素与 layout 像素混算，z≠1 时"鼠标不动点"会漂移）后以鼠标位置为不动点反求 pan（公式 `pan' = m - ec - k·(m - pan - ec)`，`k = z'/z`），保证缩放前后**鼠标下的图点屏幕位置不变**；滚轮在 svg 上 `wheel` 监听（`{passive:false}` + `preventDefault` 防冒泡触发主滚动条），`deltaY` 累计 `|>=50|` 时按符号切档（上滑=放大、下滑=缩小，闭包 `wheelAcc` 在切档后清零），已达档位边界时切档早退故累加器不会"卡"；`applyView` 内用 `treeEl.clientWidth/Height` 与 `svg.clientWidth/Height × zoom` 收敛平移量（`clampNum`），**图不会被拖出视野找不回来**。拖动 = svg 上的 `pointerdown` + document 级 `pointermove/pointerup`（拖出面板也跟手，松手即解绑），位移 >3px 记 `dragged` 并在捕获阶段 `stopPropagation` 吃掉随后的 click，避免「拖到一半松手」误打开角色/关系文档（未拖动的单击照常放行）；`.aw-st-tree.is-graph` 改为**裁剪**（`overflow:hidden` + flex 纵向收缩，图例不会被裁到面板外）——**面板不出滚动条**，放大后被裁掉的部分靠拖动查看，故重渲染不再需要保持 `scrollTop/scrollLeft`，空态文案由 `placeholderFor` 两处共用；开合与筛选是纯展示态（`lastSnap` + 本地重渲染，不读盘）；整卡与图表连线**双击**打开来源文档（`getLeaf().openFile`；v0.2.0+ 由 click 改 dblclick，单击不触发以免误开）；**v0.4.9+ 人物上的两套交互（用户要求）**＝**双击人物＝只弹人物编辑弹窗**（v0.4.9+ 用户要求＝**此外无任何别的响应**：不顺带选中/重绘整图、也不选中文字——故「单击＝选中」压 220ms 由 `pickCharLater` 落地、双击到达即 `cancelCharPick`，`onClose` 也清定时器；旧 v0.4.8「双击＝以该人物为中心重画」已移入右键菜单）＋**右键人物＝人物菜单**（`openCharMenu` 一份实现三处挂载＝图表节点 `contextmenu`、「人物状态」区每块 `contextmenu`、卡片模式关系卡里的角色名 `bindCharMenu`；**顺序照用户要求固定**＝**编辑人物「X」排第一** → 改名「X」（复用 v0.2.x+ 已有的 `onRenameCharacter`＝main.ts `renameCharacterFlow`）→ 打开来源文档（该人物《人物.md》，未登记回退关系文档）→ 设为中心人物（已是中心者变「恢复默认中心」）→ 新增人物 → **删除人物「X」恒排最后**（前五项共用 `setSection("aw-rel-char")`＝组内不画分隔线，删除用 `setSection("danger")`＝Obsidian 只在 section 变化处画线且该组落尾，同 `scene_view` 卡片菜单口径）；未注入写动作回调的那一项自动不出现）；`graphCenter` 会话内保持、现仅由菜单驱动（默认中心＝《人物.md》身份/备注标了「主角/主人公」的角色钉**画布正中**，无标注回退连线最多者居中枢轴——`forceLayout` 参 `centerName`）；**编辑弹窗＝`modals.CharacterEditModal`（main.ts `openEditCharacterDialog`）**＝人物级别（可换层，见下）＋姓名（改名走 `renameCharacterTo` 全书同步替换＋备份）＋八个设定字段，命令「管理人员 → 编辑信息」与面板「编辑」链接共用同一弹窗（代码重用）；**删除走 `deleteCharacterByName`**（确认框 → `manager.deleteCharacter` 连带清理场景引用，命令与面板共用）；「人物状态」区每块另有「编辑」链接（悬停 title＝`docLocationLabel(scope, sourcePath, snap.storyDir, REL_SCOPE_WORDS)`＝`书籍级 · 案头资料/人物.md` 一类书内位置）——图表**单击节点＝选中**：底部固定「人物状态」区显示该角色在《人物.md》的设定信息（层级标签＋「打开文档」＋身份/年龄/性别/性格/外貌/背景/能力/备注字段行、未填项跳过，同名多层登记逐层各一块，《人物.md》无记录时提示用「添加人物」补录；× 清除，`selectedChar` 会话内保持；拖后伪点击被捕获阶段拦截不误选）、选中节点 `.is-sel` 强调描边，分组头右侧「打开文档」仍为单击、须 `stopPropagation` 以免连带触发开合；容器类直接复用 `.aw-status-view` + `.aw-st-top/.aw-st-tree`（字体/滚动布局同写字台），专属样式只用 `.aw-rel-*`，勿另造容器布局样式。

## 引用索引（相关文档）

- **面板尺寸跟随（v0.4.9+）**：窗口/分屏/侧栏拖拽改变大小时，图表模式的图面会**按新视口重算可拖范围**（平移限位），**缩放倍率与你摆好的位置都不动、不自动居中也不自动适应**；卡片列表本来就随容器伸缩。画布类面板（场景/时间线）同一口径：只重算画布尺寸与滚动范围，宽度真变化才按新宽度重排内容（时间线换行/层级、场景自动布局）。首次打开场景面板的「适应全图」不受影响（仍只在打开时做一次）。
