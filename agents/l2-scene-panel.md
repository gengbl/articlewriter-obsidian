# L2 · 场景面板

## 模块概要

自定义面板「场景」（view type `articlewriter-scenes`，命令 `scene-panel`＋ribbon `map`）：把当前小说**书级《案头资料/场景.md》/ 卷《文档/场景.md》/ 章节目录《场景.md》三层**的场景条目汇总成**卡片画布**展示，支持拖动摆放位置（位置落盘回《场景.md》）、面板内增删改场景、大场景包含小场景（父子）。

## 行为约定（按实现批次）

- **卡片展示（步骤 1，已实现）**：主体区每张卡片＝场景名（`title` 字段优先、回落 `## <scene_id>` 标题名）＋场景 id（与显示名不同时才显示）＋来源层级标签（书籍级／卷 · X／章 · 第N章 Y）＋父场景标注（`⊂ 父名`；父 id 找不到时注明「未找到父场景」）＋描述＋角色 chips＋备注行。头部＝筛选框（场景名/标题/描述/备注/角色/父场景全字段匹配）＋刷新按钮；汇总行「共 N 条：书籍级 X · 卷级 Y · 章级 Z」（筛选时「匹配 X 条（共 Y 条）」）。**双击卡片**打开来源《场景.md》。卡片顺序＝文档枚举序（书级 → 各卷 → 各章）。三层《场景.md》改动由 vault 事件防抖自动刷新（同人物关系/时间线面板）。空态按「未设工作目录 / 目录下无小说 / 未选当前小说 / 无场景（给写法教学）」分级引导。
- **卡片画布与拖动位置（步骤 2，已实现）**：主体区＝CanvasPanel 画布（Ctrl|Shift＋滚轮以鼠标为不动点缩放、空白处左键平移、普通滚轮原生滚动、头部倍率标签点击复位）。卡片绝对定位：坐标＝场景 `- 位置：x,y` 字段；**未设位置的按父子树嵌套自动排布（不落盘）——子场景排在父卡片内部下方（缩进递归），顶层块自上而下排**。**鼠标左键按住卡片拖动**（仅鼠标、越 5px 阈值才激活；触屏保持原生滚动）：**整组语义＝被拖卡片连同其全部子孙场景一起移动**（保持包含结构），拖动中组内卡片实时平移＋高亮，松手把整组新布局坐标（÷缩放倍率、保留 2 位小数）一次写回各自场景块的 `- 位置：x,y` 行（main.ts 按来源文档合并、一次落盘）——任一场景旧坐标校验不符（文档被外部改过）则整组拒绝并提示点「刷新」；成功 Notice（单条「已将「名」移到 (x, y)」／多条「已移动「名」及其 N 个子场景」）＋面板**立即**重读刷新按新坐标重建（写盘后主动刷新——插件自写文件不产生文件改动事件，不能靠自动刷新）；原地释放不写回；松手后 400ms 吞掉 click/dblclick 防误开文档。双击卡片仍打开来源文档。筛选＝隐藏未命中卡片（保留命中者坐标）。汇总行固定在面板底部（不参与缩放平移）。
- **面板增删改（步骤 4，已实现）**：头部「＋ 场景」＝书级新增（无当前小说时禁用）；卡片底部悬停动作组＝✎ 编辑／🗑 删除；卡片右键菜单（触屏长按同）＝编辑场景／添加子场景／打开来源文档／删除场景。编辑与新增共用 **`SceneEditModal`**（场景名＝`## id` 块锚＝显示名——独立的「显示名」输入已删（v0.4.7：场景名即显示名；旧文档 `- 标题：` 行仍照常解析展示、编辑未触碰原样保留）；新建必填、非法字符〔`\ / : * ? " < > |`〕或空内联报错不关闭；编辑态只读防引用悬空／描述／角色下拉多选（候选＝三层《人物.md》）／备注／正文多行（写盘 ```text 围栏）／父场景下拉／**关联场景下拉多选**（候选＝其它场景去自身，`sceneRelatedOptions`；写盘 `- 关联：甲、乙`，空＝删行；卡片渲染「⇄」chip、点击打开目标场景来源文档、解析不到置灰划掉；**关联场景之间画线**＝点线强调色 `.aw-scene-rel-edge`（`relEdgePathD` 几何就近选边：竖向不交叠走顶/底、并排走左右、近水平走两底下垂弧；拖动实时重算），与层级短划虚线区分，底部汇总行带线型图例）。写回＝`insertSceneBlock`（追加书级《案头资料/场景.md》文末，文件不存在按「# 场景」起底自动创建）／`updateSceneBlock`（只改该块，**未触碰字段与创建时间、章节、未知自由行保留原行**；正文给出才替换围栏）／`deleteSceneBlock`（整块删含正文，`ConfirmModal` 二次确认〔禁 `window.confirm`〕）。成功 Notice＋vault 事件防抖自动刷新；定位失败（文档被外部改过）提示点「刷新」后重试。
- **大小场景（步骤 5，已实现）**：`- 父场景：<id>` 表达包含。编辑弹窗「父场景」下拉候选＝全部场景去重（显示名口径），**排除自身＋全部后代**（沿父链闭包展开，防父子成环）；选「（无 · 顶层场景）」＝删除该行。卡片右键「添加子场景」＝新建弹窗预填该父、写回**与父同一文档**。画布上父子用**虚线曲线**相连（连接边按相对位置动态选：子在下＝父底边中点→子顶边中点，子整体在父上方＝反向（父顶边→子底边），贝塞尔曲线，SVG 底图画在卡片下层；筛选后两端都可见才连线；**拖动卡片时连线实时跟随重算连接点与接入边**，松手落盘后整图刷新校准；父 id 在快照里找不到时卡片标注「未找到父场景」）。**只连真有 `- 父场景：` 关系的场景**：父解析＝**同一文档优先**→全局文档序首个（跨文档同名不误连），再走父链防环（成环者断链按顶层渲染、不连线不成组）。有可见子场景的父场景另有**包含框**（圆角虚线矩形衬在卡片下层，框＝**含父卡片在内**的整棵子树包围盒＋外扩；拖动任一成员实时重算包围盒，包含关系视觉始终成立）。**包含框是纯衬底（v0.4.7+）**：不拦截指针——**任何空白（含框内）按住拖动＝画布平移视野**，不改任何坐标；整组挪动＝**拖任一卡片即整组移动**（不必非得点住框或父卡片）。自动布局下子场景天然排在父卡片内部下方（嵌套递归），用户可整组拖动散开。
