# L2 · 时间线面板

## 模块概要

- **时间线面板 `TimelineView`（v0.2.x+）同属常驻 ItemView 家族**：以展示为主、唯一写动作是「拖动更新时间点」经 vault.adapter.read/write 写回源《时间线.md》标题行（见下）——构造仅注入快照 getter（main.ts `getTimelineSnapshot()`），无其它写动作回调；头部＝筛选输入框＋「刷新」按钮（不显示工作目录行与小说列表，未选小说时主体区给引导文案）；主体把各层条目合并为单一按时间点升序的纵向时间轴（`.aw-tl-list` 左边线＋`.aw-tl-item` 圆点），每条＝时间点徽章（md_docs.timelineTimeText，年-月-日规范形式）＋来源层级标签 `.aw-tl-src`＋人物 chips＋事件文本。**相邻条目的垂直间隔按时间差成比例拉开**（时间比例布局）：非筛选渲染趟中每条创建前由 pushTlSpacer 算本条与上一条已渲染条目时刻之差 Δ（tlPrevMs 随同步 DFS 逐条推进；rows 全局时间升序 → 渲染顺序恒为非降序 → Δ≥0），Δ≤90 天时按基准比例尺 TL_PX_PER_DAY＝5px/天换算出间隔块 `.aw-tl-spacer`（定高纯留白 div、插在当前条目所在容器内该条目之前——跨嵌套容器边界同样成立；list/kids 竖线自动贯穿），Δ＞TL_SPACER_MAX_DAYS＝90 天时压成定高 `.aw-tl-skip` 时间跳跃标记行（居中「⋯ 约 N 年 ⋯」小字，防公元前之类的孤立极端点把画布拉爆），整体长度≈最早到最晚的时间总长×比例尺＋各行高度；同日多条直接堆叠不加空档，折叠掉子树后其后的间隔即等于该段真实流逝时长（留白＝故事里跳过的时间）；画布缩放时随内容等比变化。时刻换算 tlEpochMs＝Date.UTC(年份截断, 月−1｜缺省一月, 日｜缺省一号)，极端超范围年份 NaN 退化为「年×365 天」近似；筛选模式 tlSpacingOn=false 改紧凑堆叠（命中稀疏不成比例）。**事件层级＝标题深度**（`#`=一级、`##`=二级、`###`=三级，最深 ######，三层文档同一规则）：面板按「父＝其前最近一条级别更小的条目」把合并行列表嵌套成轮廓树（buildTree 栈算法，无更小级别前驱者为根），子事件渲染在 `.aw-tl-kids` 容器（再缩进一级＋自己的竖线）；条目带 `lv-<级别>` 类（≥5 归入 lv-5）按级别区分圆点大小/颜色与正文强调——**圆点颜色＝同级标题色**（Obsidian 核心 `--hN-color` 变量、随主题走〔如 Solarized 六级标题同色则圆点亦同色〕，经 color＋currentColor 实现以兼容核心默认值 inherit；旧版 Obsidian 未定义该变量时回落旧配色 红/强调/绿/黄/灰），一级最大圆点＋加粗正文、二级基准、三级起逐级缩小、五级最小＋正文弱化（styles.css `.aw-tl-item.lv-* .aw-tl-dot`）。**圆点为真实元素 `.aw-tl-dot`**（替代旧 `::before` 伪元素）：**鼠标悬停条目任意位置（含圆点）时 Tip 显示该条目的描述内容**（`- 描述：` 的详细描述、可多行；经 Obsidian `setTooltip`（aria-label 驱动自绘 `.tooltip`，类 `aw-tl-tip`，styles.css 覆盖为窄幅小字）呈现——条目与圆点同挂一份，避免小圆点悬停落空回退到别的提示；无描述的条目不挂 Tip；双击定位的提示文字不占 Tip）；有子事件的圆点可点击、切换该条目的折叠状态（collapsedIds Set 记 id、重渲染不清零、切书重置；折叠后条目尾显示「（已折叠 N 条子事件）」提示且跳过子容器）；**双击**条目经 openAt 打开其来源文件并 locateHeading 定位到该时间点标题行（任意深度 ATX 标题、优先条目级别精确匹配退而任意级别同时间点、按解析值比对兼容未补零写法、250ms 重试一次、移动端降级仅打开）；**拖动更新时间点**（仅非筛选比例视图由 renderNode 经 attachTlDrag 挂载、鼠标左键专用——触屏保持原生滚动手势）：按住条目沿轴上下移动越过 5px 阈值才激活（未越界＝普通点击/双击，语义完全不受影响；pointerdown stopPropagation 使本手势优先于画布平移独占），期间整棵子树块（条目行＋紧随的 `.aw-tl-kids` 容器）各元素施加 translateY 实时平移（屏幕位移÷缩放倍率→布局 px）、**条目自身的时间徽章（.aw-tl-time）实时 setText 立即显示新时间点**（styles.css 以主题强调色标出）、光标旁浮标 `.aw-tl-draglbl`（挂 rootEl——zoomEl 有 transform 会破坏 position:fixed）只给增减天数差（布局 px 再按 TL_PX_PER_DAY 基准比例尺折算 Δ 天，不重复日期）；松手徽章还原原值、Δ≠0 → commitTlMove 写回——新时间点精度跟随原写法（shiftTlPoint：含日→按天日期运算、只含月→按 ~30.44 天/月吸附到月〔月份索引算术对负年份正确〕、纯年份→按 365 天取整），写回走 md_docs `rewriteTimelineEntryTime`（原文「注释掩码 maskCommentSpans＋srcHeading 标题行全文匹配＋文档内出现序号 srcOrdinal」定位、旧值反解校验通过才替换为 timelineTimeText 规范值，任一环节失败返回 null → 放弃并 Notice 提示刷新重试，防快照过期误写）；vault.adapter.write 成功后 Notice＋立即 refresh()（vault modify 事件的 schedulePanelRefresh 防抖兜底、busy 标志去重）；有效拖拽结束置 tlSuppressClickUntil，由 zoomEl 捕获阶段吞掉紧随 click/dblclick（防拖完误开文档/误切折叠）。筛选模式不挂载（紧凑布局下位移无比例语义）；**拖动后若未触发重渲染前再次拖同一条目会因旧值校验失败而安全中止**。汇总行给扁平命中数（非筛选视图的汇总行末尾另附「跨度」＝最早到最晚总时长：末行−首行的天数经 formatTlSpan 人读化——不足 90 天显「N 天」、不足一年显「N 个月」、否则按年＋月近似）；有内容但零有效条目的文档在列表下方给可点击提示（openFile helper 打开检查格式）。主体区为画布模式——.aw-st-tree.aw-tl-body **overflow:auto**（touch-action: pan-x pan-y）：**普通滚轮/滚动条/触屏原生滚动**（内容放得下时冒泡滚动页面）、**Ctrl|Shift＋滚轮**才以鼠标位置为不动点缩放 0.4×–3×（passive:false；不动点换算 scroll′=p·z′−m，p=(scroll+m)/z）、左键按住拖动平移＝驱动容器 scrollLeft/scrollTop（document 级 pointermove/up、>3px 记 dragged 并在捕获阶段吃掉拖后 click/dblclick 防误开文档/误切折叠）；内部 .aw-tl-sizer 宽高＝内容×缩放（JS 设置）撑出可滚动范围、.aw-tl-zoom 绝对定位其中（宽度＝视口宽、transform scale origin 左上角），汇总行固定在画布外底部 .aw-tl-sumrow，头部倍率标签 ≠100% 时显示、点击复位（tlZ 重渲染不清零、平移即原生滚动位置天然保持）。空态区分「未选择小说」与「尚无时间线文档」（附三层放置位置、日期格式与 #/##/### 级别提示）。渲染陷阱同族（UI 建进 onOpen 的 contentEl、onClose 置 built=false 以便重开重建；规范原文见 [l3-view-rendering.md](./l3-view-rendering.md)「常驻 ItemView 渲染陷阱」）。样式 `.aw-tl-*`。
