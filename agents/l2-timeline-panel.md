# L2 · 时间线面板

## 模块概要

- **时间线面板 `TimelineView`（v0.2.x+）同属常驻 ItemView 家族**：**v0.3.3+ 合并时间轴与大事件——由「以展示为主」升级为完全可编辑的事件流面板**（原「事件树面板」退场，其新增/编辑/删除/完成切换全部并入本面板；旧《大事件列表.md》退场留档，插件不再读写）。构造注入快照 getter（main.ts `getTimelineSnapshot()`）＋人物候选 getter（`getTimelineCharOptions()`），面板自持全部 vault 读写、无其它写动作回调；写回一律经 md_docs 块级写函数落**条目来源所在的《时间线.md》**（书级＝`案头资料/时间线.md`／卷级／章级），定位失败一律 Notice 提示「请点『刷新』后重试」。头部＝倍率标签＋筛选输入框＋「＋ 事件」（根级新增）＋「刷新」按钮（不显示工作目录行与小说列表，未选小说时主体区给引导文案）；主体把**书/卷/章三层**条目合并为单一按时间点升序的纵向时间轴（`.aw-tl-list` 左边线＋`.aw-tl-item` 圆点），每条＝时间点徽章（md_docs.timelineTimeText，年-月-日规范形式）＋**事件名徽章**（标题行「时间点＋空格＋事件名」的事件名部分；旧「纯时间点」标题＝无名条目不渲染）＋done 时「✓ 已完成」徽章＋来源层级标签 `.aw-tl-src`＋人物 chips＋事件文本＋「影响：…」一行＋**关联 chip**（`- 关联：` 里的其它事件名：命中当前时间线同名事件→点击跳到该条目所在文档并给面板内目标条目 1.2s 高亮；未命中置灰不可点＋悬停说明）。汇总行「共 N 条：书籍级 X · 卷 Y · 章 Z｜已完成 N｜跨度 …」；筛选（人物/事件/事件名子串）只渲染命中条目及其祖先链、改紧凑堆叠，汇总行改「匹配 X 条（共 Y 条）」。**相邻条目的垂直间隔按时间差成比例拉开**（时间比例布局）：非筛选渲染趟中每条创建前由 pushTlSpacer 算本条与上一条已渲染条目时刻之差 Δ（tlPrevMs 随扁平渲染趟逐行推进；扁平数组已按 (年,月,日) 升序 → 渲染顺序恒为非降序 → Δ≥0），Δ≤90 天时按基准比例尺 TL_PX_PER_DAY＝5px/天换算出间隔块 `.aw-tl-spacer`（定高纯留白 div、插在 list 内该行之前（扁平兄弟行序列，无嵌套容器边界；list 竖线自动贯穿）），Δ＞TL_SPACER_MAX_DAYS＝90 天时压成定高 `.aw-tl-skip` 时间跳跃标记行（居中「⋯ 约 N 年 ⋯」小字，防公元前之类的孤立极端点把画布拉爆），整体长度≈最早到最晚的时间总长×比例尺＋各行高度；同日多条直接堆叠不加空档，折叠后隐藏的结构后代被跳过、其前后显示行之间的间隔即等于两者真实时差（留白＝故事里跳过的时间）；画布缩放时随内容等比变化。时刻换算 tlEpochMs＝Date.UTC(年份截断, 月−1｜缺省一月, 日｜缺省一号)，极端超范围年份 NaN 退化为「年×365 天」近似；筛选模式 tlSpacingOn=false 改紧凑堆叠（命中稀疏不成比例）。**事件层级＝标题深度**（`#`=一级、`##`=二级、`###`=三级，最深 ######，三层文档同一规则）：面板按「父＝**同一文档内**其前最近一条级别更小的条目」把每个《时间线.md》的条目各自挂成轮廓树（buildOutlineTree 栈算法**逐文档调用**、跨文档不挂父——否则章文档首条会挂到前一文档末条名下破坏 addChild/delete 的文档内子树锚点语义；无更小级别前驱者为根），**渲染＝扁平序列**（v0.3.3+ 折叠修复）：各文档树深度优先扁平化为 TlFlatNode{node,depth,ancestors} 后按 (年,月,日) 稳定升序逐行输出到 `.aw-tl-list` 下（无 `.aw-tl-kids` 嵌套容器），缩进＝item padding-left 按深度类 `tl-d<min(depth,6)>`（CSS 变量 --tl-d × --tl-indent＝22px/级；**层级视觉通道**——v0.3.3+ 视觉增强：圆点不再恒钉主轴，**落在本行深度列**（dot left＝calc(--tl-d×--tl-indent−10px)＋translateX(-50%)，depth 0＝主轴中心；--tl-guide-start＝--tl-indent−10 故深度 k 行圆点圆心恰在导引列 k）；attachTlGuides 给每行/间隔块生成前 depth 个通高竖导引线 `.aw-tl-branch-line`（列 k 横坐标＝--tl-guide-start＋(k-1)×--tl-indent，styles.css nth-child(1)–(6) 映射＝列号）、depth≥1 行加肘形接线 `.aw-tl-elbow`（父级列横拉到本行圆点、压在圆点圆心线 top:11px）、有子事件行加子列（depth+1）短桩 `.aw-tl-branch-stub`（圆点下缘垂到行尾与下方同列线接续）；spacer/skip 同样挂通高导引线（二者 position:relative）——时间留白里层级通道不断）——**行显示顺序恒为时间升序，层级只体现在缩进/层级通道与折叠归属**；条目带 `lv-<级别>` 类（≥5 归入 lv-5）按级别区分圆点大小/颜色与正文强调——**圆点颜色＝同级标题色**（Obsidian 核心 `--hN-color` 变量、随主题走〔如 Solarized 六级标题同色则圆点亦同色〕，经 color＋currentColor 实现以兼容核心默认值 inherit；旧版 Obsidian 未定义该变量时回落旧配色 红/强调/绿/黄/灰），一级最大圆点＋加粗正文、二级基准、三级起逐级缩小、五级最小＋正文弱化（styles.css `.aw-tl-item.lv-* .aw-tl-dot`）。**圆点为真实元素 `.aw-tl-dot`**：**鼠标悬停条目任意位置（含圆点）时 Tip 显示该条目的描述内容**（`- 描述：` 的详细描述、可多行；经 Obsidian `setTooltip`（aria-label 驱动自绘 `.tooltip`，类 `aw-tl-tip`，styles.css 覆盖为窄幅小字）呈现——条目与圆点同挂一份，避免小圆点悬停落空回退到别的提示；无描述的条目不挂 Tip；双击定位的提示文字不占 Tip）；有子事件的圆点可点击、切换该条目的折叠状态，且行内在时间徽章之后另有**折叠标识 `.aw-tl-caret`**（时间徽章 `.aw-tl-time` 以负 margin 拉回本行圆点右后侧、紧贴圆点显示，caret 排其后再让出徽章位置；折叠标识 caret 字号再大一半（1.3em）、取级别色变量 `--tl-lv-color`＝本级圆点同色（lv-N 类定义在条目上、二级走 --h2-color 缺省，圆点与 caret 共用同一变量（单一来源）；▾＝展开中／▸＝已折叠，点击与圆点共用同一 toggleKids 闭包切换、Tip 按当前态给「有子事件，点击折叠／已折叠 N 条子事件，点击展开」，pointerdown/dblclick 均 stopPropagation 不进拖动与双击定位手势）（collapsedIds Set 记 id、重渲染不清零、切书重置；**折叠隐藏＝全部结构后代行**——扁平时间序里某后代即使排在别的大事件之后也一并隐藏，判定＝该行 ancestors 任一命中 collapsedIds；折叠后条目尾显示「（已折叠 N 条子事件）」提示＝countSubtree−1 由 renderBody 传入）；**双击**条目经 openAt 打开其来源文件并定位到该时间点标题行（任意深度 ATX 标题、优先条目级别精确匹配退而任意级别同时间点、按解析值比对兼容未补零写法、250ms 重试一次、移动端降级仅打开）；**拖动更新时间点**（仅非筛选比例视图由 renderRow 经 attachTlDrag 挂载、鼠标左键专用——触屏保持原生滚动手势）：按住条目沿轴上下移动越过 5px 阈值才激活（未越界＝普通点击/双击，语义完全不受影响；pointerdown stopPropagation 使本手势优先于画布平移独占），期间该条目行＋其全部**已渲染**结构后代行（collectTlDescendantEls 沿轮廓树 children 递归查 nodeEls——被祖先折叠的后代不在 DOM 天然跳过，时间上四散的后代逐行收集）各元素施加 translateY 实时平移（屏幕位移÷缩放倍率→布局位移，再按**条目自身精度单位**的灵敏度折算为 Δ 步数：含日＝每 5px 一天（复用比例尺 TL_PX_PER_DAY）、只含月＝每 50px 一月、纯年＝每 50px 一年——TL_DRAG_PX_PER_UNIT，不能按 5px/天折算年条目否则 1 年要拖 1825px）、条目时间点徽章实时变为目标时间点、浮标只显示「±N 年/月/天」；松手才写回：steps≠0 且按原精度算出的新时间点（含日→日级日期运算、只含月→整月加减、纯年→整年加减）≠ 原值→ 经 `rewriteTimelineEntryTime` 只改写该条目标题行的时间点（定位失败防快照过期误写）→ Notice「已将「…」移至 <新时间点>（来源标签）」＋刷新面板；拖动距离不足一个精度单位则视同原地释放、还原不写回。空态给格式教学：每条一个标题块（标题＝时间点＋空格＋事件名，只写时间点＝无名条目；字段行 `- 人物：`／`- 完成：是`／`- 事件：`／`- 描述：`／`- 影响：`／`- 关联：`），也可用头部「＋ 事件」直接新建。
- **事件编辑能力（v0.3.3+ 自事件树面板并入，交互语义一致、写入目标改为三层《时间线.md》）**：条目行尾**悬停动作组**＝＋添加子事件／✎ 编辑／✓○ 完成快速切换／🗑 删除（CSS 悬停显现；动作按钮不进入拖动改时手势）；**右键条目**（触屏长按替代）出菜单＝编辑事件／添加子事件／添加同级事件／标记为已完成（未完成）／在编辑器打开／删除。新增与编辑共用 **EventEditModal**：字段＝**时间点**（必填，须能被 parseTimelineTime 解析成 `120`／`120-06`／`120-06-15` 一类写法，非法只内联报错、不关弹窗）／**事件名**（可留空＝无名条目）／**人物**（下拉多选，候选＝当前小说全部人物名）／**已完成**（勾选＝写回 `- 完成：是`，取消勾选＝不写该行）／**事件**（多行 5 行高）／**影响**（多行 2 行高）／**关联**（下拉多选，候选＝当前时间线既有事件名、排除自身）。**描述不在弹窗编辑**（v0.3.3+ 后期移除该控件）：提交时原样透传 initialValues.desc——编辑保留条目既有 `- 描述：` 内容、新增为空，面板悬停 Tip 显示不受影响。**级别与插入位置口径**：「＋ 事件」＝根级新增（level 1，写**书级** `案头资料/时间线.md` 文档末尾，文件不存在则自动创建）；「添加子事件」＝level＝父＋1（封顶 6＝标题深度上限）、插到该条目**整棵子树末尾**；「添加同级事件」＝level＝该条目级别、插到其整棵子树之后；均写回该条目所在文档。**删除**＝ConfirmModal 二次确认后经 `deleteTimelineBlock` 落盘：有子事件时**整棵子树一起删**（确认文案注明条数），无子事件只删该条目自身块；编辑只替换自块、保留全部子节点。**完成切换**＝编辑弹窗勾选或悬停 ✓○ 一键翻转，只增删该条目的 `- 完成：是` 一行。写回成功后 Notice＋面板自动刷新（失败保持原状并提示刷新）；条目缺来源定位信息（面板加载后源文档已变化）时各写动作一律提示先点「刷新」。
- **共用设施（v0.3.1+ 重构抽出）**：轮廓树栈算法与画布缩放/平移已抽出为 `src/outline_tree.ts`（`buildOutlineTree`/`countSubtree`）与 `src/panel_canvas.ts`（`CanvasPanel`，`--tl-transform` 仍由时间线传入），上文 buildOutlineTree/setupCanvas/applyTlView 语义不变；v0.3.3+ 事件树面板退场后当前仅时间线面板使用（实现细节见 [l3-timeline-view.md](./l3-timeline-view.md)）。
