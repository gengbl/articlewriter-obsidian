- **事件编辑能力（v0.3.3+ 自事件树面板并入，交互语义一致、写入目标改为三层《时间线.md》）**：条目**动作组**＝＋添加子事件／✎ 编辑／✓○ 完成快速切换／🗑 删除（**v0.4.7+ 位置改为事件内容下方独占一行**——不再浮在条目右上角，悬停条目才显现；动作按钮不进入拖动改时手势）；**右键条目**（触屏长按替代）出菜单＝编辑事件／添加子事件／添加同级事件／标记为已完成（未完成）／**打开来源文档**（v0.4.9+ 文案由「在编辑器打开」统一）／删除。新增与编辑共用 **EventEditModal**：字段次序最前是**级别**（v0.4.9+ 用户要求＝事件要看得见「在哪份文档」、新增时要能选写到哪）＝新建时下拉列出当前所选时间线下的各层文档（按**书级 → 卷级 → 章级**排，文案＝`层级词 · 书内路径`＝`书级 · 案头资料/时间线.md`／`卷级 · 书稿/…/文档/时间线.md`／`章级 · 书稿/01-初见/…-时间线.md`；候选＝快照 `docs`，章级只列已落盘的文档，默认值＝旧口径＝书级／当前泳道已有文档）；编辑已有事件与「添加子事件／同级事件」＝该行**只读**、值＝**该事件所在位置**（禁用单项下拉，同场景弹窗）。其余字段＝**时间点**（必填，须能被 parseTimelineTime 解析成 `120`／`120-06`／`120-06-15` 一类写法，非法只内联报错、不关弹窗）／**事件名**（可留空＝无名条目）／**人物**（下拉多选，候选＝当前小说全部人物名）／**已完成**（勾选＝写回 `- 完成：是`，取消勾选＝不写该行）／**详情**（**v0.4.11+ 唯一正文内容字段**，多行 5 行高，原「事件」框已删、旧 `- 事件：` 内容解析时并入并回填这里）／**影响**（多行 2 行高）／**关联**（下拉多选，候选＝当前时间线既有事件名、排除自身）。**详情在弹窗编辑**＝预填既有详情、可改可清空，提交写回用户输入值〔空＝删除详情〕；**卡片上不内联显示**，只在鼠标悬浮的 Tip 里出现（左对齐、保留换行）。**级别与插入位置口径**（两个「级别」要分清：弹窗里的「级别」行＝**写进哪份文档**；条目结构里的级别＝**标题深度** `#/##/###`）：「＋ 事件」＝根级新增（标题深度 1，写**弹窗「级别」下拉所选那份**文档末尾，默认＝书级 `案头资料/时间线.md`，文件不存在则自动创建）；「添加子事件」＝level＝父＋1（封顶 6＝标题深度上限）、插到该条目**整棵子树末尾**；「添加同级事件」＝level＝该条目级别、插到其整棵子树之后；两者都**不跨文档**＝级别行只读、写回该条目所在文档（时间线的父子按同一文档内的标题序列成立）。**删除**＝ConfirmModal 二次确认后经 `deleteTimelineBlock` 落盘：有子事件时**整棵子树一起删**（确认文案注明条数），无子事件只删该条目自身块；编辑只替换自块、保留全部子节点。**完成切换**＝编辑弹窗勾选或悬停 ✓○ 一键翻转，只增删该条目的 `- 完成：是` 一行。写回成功后 Notice＋面板自动刷新（失败保持原状并提示刷新）；条目缺来源定位信息（面板加载后源文档已变化）时各写动作一律提示先点「刷新」。
- **多时间线合并绘制（v0.4.7+）**：面板的数据源不再只有《时间线.md》——**凡文件名以「时间线」开头的文档都进面板**：默认那份命名 `时间线.md`，其它按 `时间线-***.md`（如《时间线-战斗线.md》），放在与默认时间线**同一层容器**（书级＝案头资料／卷级＝卷「文档」目录／章级＝章节目录）即自动并入。识别与命名解析纯函数在 md_docs：`isTimelineDocName`（`时间线.md` 或 `时间线-.+\.md`）、`timelineLaneOf`（`时间线-战斗线.md`→泳道名「战斗线」，`时间线.md`→「默认」，并剥掉旧容器前缀 `01-初见-`／`卷名-` 兼容旧命名）。`story_manager.readTimelineDocs` 每容器枚举全部时间线文档（含卷根 `<卷名>-时间线***.md`、历史残留 `<卷名>-undefined` 兜底），每条一份 TimelineDocSource、带 `lane`；缺默认文档的容器仍给候选路径＋空文本（写回时自动创建）。`mergedTimelineText`（提示词【时间线】块）同样覆盖全部泳道，出现第二条泳道时按泳道分组并加「【时间线：<泳道名>】」标题行。
- **泳道视觉与筛选（v0.4.7+）**：各泳道**按时间合并进同一条时间轴**（同一文档内的父子结构不变、跨文档不挂父），每条泳道一种配色（`tlLaneStyle`：色表索引＝laneIndex % 10，默认泳道＝中性灰；CSS 类 `.tl-l<n>` 给时间徽章描边上色），非默认泳道的条目另挂彩色名称 chip（`.aw-tl-lane-tag`）。底部汇总行下出「时间线」图例（`.aw-tl-legend`：色点＋名称＋条数，点击＝只看该泳道／再点恢复全部），头部另有「时间线」下拉（`≥2` 条泳道时才出现，选择＝只绘制该泳道）；「＋ 事件」写入**当前所选泳道**的文档（未筛选＝书级《时间线.md》），汇总行「共 N 条」随可见集合变化。
- **树挂分支＝唯一渲染（v0.4.9+ 用户要求＝「按向下生长的树挂事件」；后续确认＝默认即树挂、去掉「显示方式」下拉——旧「时间主线」扁平趟与 buildFlatRows/肘形接线/短桩全部退场）**：
  - **向下生长的树**：一级事件按时间升序排在主轴上；**凡有子事件者，从它自己的圆点处引出一条「侧向时间线」**＝一条**分叉弧线** `.aw-tl-branch-out`（横线自圆点圆心线出针、横穿一个列距、以随列距放大的圆角**尽早下弯**）；弯过去的那条列线（`.aw-tl-branch-line`＝2px 宽、0.6 不透明度的真时间线）就是这批子事件的侧向时间线，**子事件的圆点正落在这条列线上＝挂在侧线上**；**v0.4.11+ 侧线不再垂直到底**——分叉弧线与各层列线在转折后按 6° 缓慢向右下倾斜（行与留白块随子树根的距离逐段右移、导引线同角 skew 接续），子事件圆点跟着所在行一起右移、始终落在线上，根事件仍钉在主轴上；**相邻行之间按真实时差成比例留白**（v0.4.11+ 改为整条列表共用的全局时间游标＝各级共用同一条时间尺度，Y 值只由时间决定）。子事件若还有子事件＝从它自己的圆点再弯一根更深一层的弧线，逐层同构（数据侧级别封顶 6＝最多五层侧枝）。
  - **横向布局（v0.4.9+ 用户要求＝子时间线横向延伸更远、卡片固定宽）**：树挂视图的**列间距不再固定 22px**——「子时间线连同其下所有更低一级的时间线」合计**摊满面板可视宽度的 2/3**（按本次实际画出的层数均摊；只有一层侧枝就摊到很大一截，不再挤在主轴旁边），同时保证最深一层的卡片不越右缘（放不下则宁可横向滚动，列距下限 28px）；面板拖宽/分屏/窗口缩放会自动按新宽度重算。**事件卡片不占满整宽**＝固定宽 240px（各深度一律同宽、更紧凑，长文本在卡片内换行），且**卡片左缘就从它所在那条时间线（主轴/侧线）的 X 轴起**——卡片＝挂在时间线上的小卡，圆点压在卡片左上角，不再是通宽色带。
  - **挂父与行渲染**：同一份挂父口径（按 `sourcePath` 连续段逐文档 `buildOutlineTree`、跨文档不挂父）、同一个条目行渲染（内容/徽章/动作组/右键菜单/折叠 caret/悬停 Tip 与旧主线视图完全一致）
  - **时间顺序（v0.4.11+ 用户要求＝Y 值按每个事件的时间安排）**：一级事件与各级子事件一起走 `flattenOutlineOrdered` **全局时间升序**——父事件 A 的子事件若晚于一级事件 B，B 插到 A 与该子事件之间；不会出现时间晚的在上、时间早的在下（子事件时间早于父事件的数据异常也严格按时间排在父事件之上）。层级只由深度列表达，不再让整棵子树插队；同刻条目保持文档先序（父先于子）。
  - **筛选与折叠语义**：筛选＝忽略折叠、按 `subtreeHas` **整支剪枝**（本节点与全部后代都不命中＝整支不画，不会留下一条不命中事件带着空侧枝占屏；命中条目的祖先链随支路自然出现）；折叠＝点圆点/caret 隐去它下面整棵侧枝，行尾留「已折叠 N 条子事件」提示，折叠中的事件**不再引出分叉弧线**。双击编辑、关联 chip、泳道配色、图例、汇总行口径全部不变；**拖动改时（v0.4.11+）＝被拖事件连同其全部子事件一起平移**——平移单位取被拖事件的精度（含日按天、只含月按月、纯年按年），各子事件保持自身精度（月末自动夹到合法日期），一次批量写回同一份《时间线.md》，Notice 报告「连同 N 条子事件同步平移」；任一条定位失败则整批不写、提示刷新重试。
- **被其它面板跳入定位（v0.4.8+）**：场景面板卡片「🕐」区（`- 事件：` 挂的时间线事件）点击＝main.ts 把时间线面板带到前台再调 `TimelineView.revealEvent(事件名)`＝按事件名（同关联 chip 的名字口径）把该条目行**滚动进视口＋闪烁高亮**；目标行被搜索词/泳道筛选过滤或祖先折叠隐藏＝**自动清筛选＋展开全部折叠**后重渲染再找回；时间线里没有同名事件＝弹提示。事件名匹配不到通常＝时间线里改名，此时场景侧 `- 事件：` 的名字不会自动跟随（改名级联未实现）。
- **面板尺寸跟随（v0.4.9+）**：窗口/分屏/侧栏拖拽改变面板大小时**不自动缩放、不自动居中**——只按新视口重算画布尺寸与可滚动/可拖动范围，**宽度真变化才重渲染内容**（条目按新宽度换行、层级列重排；纯高度变化不重渲染）。`ItemView.onResize` 与 ResizeObserver 走**同一套 120ms 防抖**（`CanvasPanel.notifyResize()`），场景/时间线/人物关系三个面板口径一致，共用实现＝`panel_canvas.watchElementSize`。
- **共用设施（v0.3.1+ 重构抽出）**：轮廓树栈算法与画布缩放/平移已抽出为 `src/outline_tree.ts`（`buildOutlineTree`/`countSubtree`）与 `src/panel_canvas.ts`（`CanvasPanel`，`--tl-transform` 仍由时间线传入），上文 buildOutlineTree/setupCanvas/applyTlView 语义不变；v0.3.3+ 事件树面板退场后当前仅时间线面板使用（实现细节见 [l3-timeline-view.md](./l3-timeline-view.md)）。**v0.4.3+ 尺寸自适应**：时间轴面板在大小变化时（拖侧栏、分屏、窗口缩放、移动端抽屉开合）自动重算画布尺寸并重渲染内容与布局——用 ResizeObserver 观察画布容器、防抖后先 apply 画布尺寸，宽度真变化才用缓存快照重渲染（不重新读盘，缩放/滚动/折叠状态保持）。
