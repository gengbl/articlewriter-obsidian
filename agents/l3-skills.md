陷阱（书籍级特有）：

1. **读写通道与全局 SKILLS/ 相反**：`案头资料/Skill/` 在书目录下属真书路径，可安全走 `manager.readDoc`/`promptReader`（orderRefDocSpecs 注入的文件即经 promptReader 读取）；只有全局 `<work_dir>/SKILLS/` 必须绕 manager（见上条陷阱 1）。
2. **勿与「自动化建书技能」混线**：`book_skill.ts`/`BookSkillCreateModal`/`cmdCreateBookSkill`（`auto_book: true`、案头资料/ 根下技能文件）是完全不同的功能，符号名相近（BookSkill* vs bookSkill*/BookSkillPhase*），解析路径互不相干。
3. **防双份注入同规则**：编写文章阶段（PHASE_WRITING）正文族上下文装配恒 `skipSkills: true` 且不传 bookSkill opts，书籍技能只经 writerSystemPrompt→skillsBlock 进 system prompt 一次。
4. `deskDocsPath` 依赖书布局（案头资料 文件夹名可随旧格式迁移），bookSkillsDir 只经它拼路径，不要硬编码「案头资料」。

## 数据格式（系统级）

- ref_docs 条目三形态：内置 key（`book_info` 等）｜`file:<vault 路径>`｜`skill:<技能名>`（v0.3.0+）。
- 技能文件：`<work_dir>/SKILLS/<name>.md`，内容自由 Markdown，建议起始 `# 技能名` + 要点列表；无 frontmatter、无解析约定，注入只剥起始标题行。

## 陷阱（改代码前确认）

1. **绝不经 manager**：`story_manager.storyNameOfPath` 把 work_dir 第一级目录当书名——`readDoc("SKILLS/x.md")`/`writeDoc` 会对 "SKILLS" 触发 `ensureLayout` 旧格式迁移，把技能文件搬进 `案头资料/`/`书稿/`。技能读写只走 `app.vault.adapter`。
2. **防双份注入**：编写文章阶段（PHASE_WRITING）技能只经 writerSystemPrompt→skillsBlock 进 system prompt；上下文装配必须保持 `skipSkills: true`。若新增正文族装配调用 orderRefDocSpecs 且清单可能含 skill 条目，显式决定 skipSkills。
3. **chat 面板拿不到技能**是设计使能：chat 装配走编写文章阶段默认清单 + skipSkills。
4. **默认清单里的技能只有一条**：`PHASE_REF_DOC_DEFAULTS[PHASE_WRITING]` 含 `skill:网文高频禁用词清单`（v0.3.6+ 禁用词 Skill 化定案）；阶段 0 另含方法论技能 `skill:世界观生成框架`（v0.3.7+，见「WRITING_PHASE_LABELS」条）——除此之外勿再往默认清单塞技能，其余保持纯 opt-in。注意默认条目仅对从未保存过该阶段 ref_docs 的配置生效。
5. SKILLS/ 读写发生在 vault adapter 层，Obsidian 文件监听/索引正常可见；`listStories` 只认含 `故事状态.md` 的目录，SKILLS/ 安全。
